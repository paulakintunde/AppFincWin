## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app -> plan-refresh | Signed-in caller; may only refresh their own household |
| cron -> plan-refresh sweep | Shared secret from vault |
| operator -> plan-grant | Grants free access; highest-value endpoint |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-27 | Elevation | plan-grant called by a user | mitigate | Own secret PLAN_GRANT_SECRET, constant-time compare; user JWT is not accepted |
| T-09-28 | Spoofing | plan-refresh names another user | mitigate | Caller id only from auth.getUser(); body never read for identity |
| T-09-29 | Denial of service | Refresh spam hits RevenueCat limits | accept | Client calls only at foreground and after purchase/restore (09-10 throttles to once per 60 s) |
