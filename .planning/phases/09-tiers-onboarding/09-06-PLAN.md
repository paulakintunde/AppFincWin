<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Internet -> plan-webhook | Anyone can POST; only RevenueCat holds the HMAC secret |
| plan-webhook -> RevenueCat REST | Secret API key leaves only to api.revenuecat.com |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-22 | Spoofing | Forged webhook grants access | mitigate | HMAC-SHA256 over `${t}.${raw}`, constant-time compare, 300 s window; and state comes only from a re-fetch with the secret key |
| T-09-23 | Tampering | Replayed or reordered events | mitigate | Unique rc_event_id; re-fetch per event; idempotent plan_apply |
| T-09-24 | Information disclosure | Email or attributes stored/logged | mitigate | scrubEvent before insert; logs carry type and result only |
| T-09-25 | Information disclosure | Secret keys in git | mitigate | Function secrets only (set in 09-08); fixtures contain no keys; gitleaks runs in CI |
| T-09-26 | Denial of service | Slow processing makes RevenueCat retry | mitigate | 200 returned before work via EdgeRuntime.waitUntil; daily reconcile catches dropped deliveries (09-05/09-07) |
</threat_model>
