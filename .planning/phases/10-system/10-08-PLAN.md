New API (exact):
```ts
export type WalletKind = 'paypal' | 'wise' | 'revolut';
export interface WalletLine { index: number; currency: string; localDate: string; description: string; grossMinor: number; feeMinor: number; netMinor: number; externalId: string | null; pairKey: string | null; kind: 'payment' | 'conversion' | 'fee-only'; balanceMinor: number | null }
export type WalletReadError = 'missing-column' | 'unreadable';
export type WalletRead = { ok: true; wallet: WalletKind; lines: WalletLine[]; skipped: number } | { ok: false; wallet: WalletKind; error: WalletReadError; missing?: string[] };
export function detectWallet(header: readonly string[]): WalletKind | null;
export function readWallet(text: string): WalletRead | null; // null = not a known wallet -> generic import
export interface WalletFeeLine { forIndex: number; currency: string; localDate: string; magnitude: number } // expense in "Fees"
export interface WalletTransferPair { fromIndex: number; toIndex: number; fromCurrency: string; toCurrency: string; feeIndex: number | null }
export interface WalletDrafts { wallet: WalletKind; drafts: StatementDraft[] /* one per currency */; feeLines: WalletFeeLine[]; transferPairs: WalletTransferPair[]; currencies: string[] }
export function walletToDrafts(read: Extract<WalletRead, { ok: true }>): WalletDrafts;
```
Sign rule: grossMinor/netMinor signed (outflow negative); feeMinor is a magnitude >= 0; invariant netMinor === grossMinor - feeMinor for outflows and grossMinor - feeMinor for inflows (fee always reduces the balance). Draft rows carry gross; feeLines carry fee; so per currency sum(gross) - sum(fee) === sum(net).
Skip rules: Revolut State != 'COMPLETED'; PayPal Status not 'Completed' or Balance Impact 'Memo'; Wise rows with empty Amount.
Personal-data rule: description is the merchant/description cell only; never payer/payee names, emails, account numbers or card digits.
