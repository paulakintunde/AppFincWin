  table public.reviewer_allowlist(email text primary key check (email = lower(email) and char_length(email) <= 254), user_id uuid null references auth.users(id) on delete set null, note text not null default '' check (char_length(note) <= 80), created_at timestamptz not null default now()); RLS on; revoke all from anon, authenticated; grant select to supabase_auth_admin.
  function public.is_reviewer_email(p_email text) returns boolean — security definer, set search_path = ''; execute to service_role only.
  function public.hook_before_user_created(event jsonb) returns jsonb — security definer, stable, set search_path = ''. If event->'user'->'app_metadata'->>'provider' = 'email' (or event->'user'->'identities' is empty and email is set with no external provider) and lower(event->'user'->>'email') is not in reviewer_allowlist: return jsonb_build_object('error', jsonb_build_object('http_code', 403, 'message', 'Sign-up is not available.')).   Verify the exact event payload shape against Supabase's "Before User Created hook" docs (Context7 or WebFetch supabase.com/docs/guides/auth/auth-hooks/before-user-created-hook) before writing the function; record the source in the SUMMARY.
Function contract (exact): POST /functions/v1/reviewer-signin, body { email: string, password: string } (both <= 254 / <= 200 chars). Responses: 200 { ok: true, access_token, refresh_token, expires_in }; 401 { ok: false, error: 'invalid' } for not listed OR wrong password OR malformed body (identical body); 429 via tooManyRequests. Not-listed path waits the same fixed 400 ms as the password path to keep timing uniform. verify_jwt = false.
