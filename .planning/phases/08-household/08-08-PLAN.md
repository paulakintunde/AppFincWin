<interfaces>
RESEARCH Pattern 6 sketch:
```ts
export type Decision = 'drop' | 'hold' | 'apply';
export function reconcile(eventVersion: number, cacheVersion: number | undefined, hasPendingWrite: boolean): Decision {
  if (cacheVersion !== undefined && eventVersion <= cacheVersion) return 'drop'; // echo or stale
  if (hasPendingWrite) return 'hold';        // server will reject the queued write: conflict path
  return 'apply';
}
```
Facts (supabase.com/docs/guides/realtime/postgres-changes): events are authorised per subscriber by RLS; DELETE events bypass RLS and carry only primary keys; table must be in publication `supabase_realtime`; one `eq` filter per subscription.
Existing: src/data/sync/versionChain.ts (in-memory), src/data/sync/failedWrites.ts, src/data/sync/writeErrors.ts ('conflict' never retried), apply_patches expectedVersion refusal names `updated_by`.
Docker 29.7.2 available; local stack via `npx supabase start` (Realtime needs the full stack, not only `db start`).
