<feature>
  <name>Household split, weights, colours and member names</name>
  <files>src/engine/household/{lineSplit,weights,colours,memberLabel}.ts and tests</files>
  <behavior>
    splitLine(total, rule, participants, payerIndex):
    - participants: readonly { key: string; included: boolean; weight: number }[] in household join order; payerIndex points into it.
    - even, 3 included, total 1000 -> [334, 333, 333] (first in join order gets the extra unit).
    - even, 2 of 3 included -> excluded member gets 0.
    - weight with weights [60, 40, 0], total 1001 -> [601, 400, 0]; a 0% member always 0.
    - weight where every included weight is 0 -> { ok: false, reason: 'split_weights_zero' }.
    - amount with amounts [700, 301] and total 1001 -> exactly those; amounts not summing to total -> { ok: false, reason: 'amounts_not_total', leftToAssign }.
    - mine -> payer gets total, others 0 (no owing).
    - fewer than one included non-payer for even/weight -> { ok: false, reason: 'no_other_member' } (UI: at least one other person stays ticked).
    - negative totals (refunds) mirror signs.
    - Property (fast-check): for every ok result, sum(parts) === total, no part has the opposite sign to total, excluded members are 0, result deterministic.
    rebalanceWeights(current, index, next):
    - [50, 50] set index 0 to 70 -> [70, 30]; [40, 30, 30] set 0 to 60 -> [60, 20, 20]; others scaled proportionally with allocate (largest remainder), total always 100.
    - when all other weights are 0, the remainder goes to them evenly via allocate over equal weights.
    - setting the only positive weight to 0 -> { ok: false, reason: 'last_positive' } (D-30).
    - next outside 0..100 or non-integer -> RangeError.
    - evenWeights(n) -> allocate(100, n ones), e.g. 3 -> [34, 33, 33].
    - Property: every ok result sums to 100 and every entry is in 0..100.
    nextFreeColour(taken) -> lowest of 0..5 not in taken, or null when all six are taken.
    memberLabel(member, viewerId):
    - member: { userId: string | null; displayName: string | null; nameHidden: boolean; colourKey: number; left: boolean }
    - userId === viewerId -> { kind: 'you' }.
    - userId null -> { kind: 'former' } (account deleted, D-29).
    - nameHidden or empty displayName -> { kind: 'colour', text: MEMBER_COLOUR_NAMES[colourKey] }.
    - otherwise { kind: 'name', text: displayName }.
    - left true adds `left: true` to name/colour results (UI renders "Sam (left)").
    - MEMBER_COLOUR_NAMES = ['Green', 'Rust', 'Slate', 'Ochre', 'Plum', 'Teal'] (UI-SPEC order).
  </behavior>
