## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-00-10-01 | I | Session at rest | mitigate | AES-256-CTR via aes-js; key in SecureStore (`WHEN_UNLOCKED_THIS_DEVICE_ONLY`); only ciphertext in AsyncStorage (ACC-12) |
| T-00-10-02 | I | CTR nonce reuse | mitigate | Fresh 16-byte CSPRNG IV per write, stored with the ciphertext; test asserts differing ciphertexts for equal plaintext |
| T-00-10-03 | T | Ciphertext malleability (CTR has no MAC) | accept | Tampering needs local device access that already defeats app sandboxing; a corrupted blob is discarded (returns null) and Supabase rejects any mangled token server-side |
| T-00-10-04 | I | Residual data after sign-out | mitigate | wipeDeviceData clears every registered SecureStore key and every `fincwin:` AsyncStorage key, and runs subsystem handlers (D-15) |
| T-00-10-05 | S | Weak randomness | mitigate | react-native-get-random-values (CSPRNG) imported before any crypto use; never Math.random |
