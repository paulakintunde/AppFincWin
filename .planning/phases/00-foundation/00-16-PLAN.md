    - scrubMessage('Invalid amount 123.45 for "Tesco Metro"') returns 'Invalid amount <n> for <str>'
    - scrubMessage('user jane@example.com failed') returns 'user <email> failed'
    - scrubMessage strips anything after 200 chars and redacts runs of 4+ digits, decimals, currency-symbol amounts (£12, $3.50, 12,00 €) and quoted substrings
    - scrubStackFrame keeps filename, function, line and column, and drops any `vars`/locals
    - errorReporter: initErrorReporting() constructs its own client (not the analytics singleton) with personProfiles 'never' (or the SDK equivalent), no identify ever called, enableSessionReplay false, and stays active after analytics.disable()
    - captureError(new Error('x 42')) sends a scrubbed message
  </behavior>
  <action>
1. `scrub.ts`: pure functions `scrubMessage(msg: string): string` and `scrubStackFrame<T extends object>(frame: T): Partial<T>` implementing the behaviours. Redaction order: emails, quoted strings, currency amounts, numbers, then truncation.
2. `errorReporter.ts`: `initErrorReporting(): void` and `captureError(error: unknown, context?: { area: 'auth' | 'theme' | 'sync' | 'boot' | 'unknown' }): void`. The context is a finite union, so no free text can pass. For PostHog: a second `new PostHog(key, { host: 'https://eu.i.posthog.com', personProfiles: 'never', enableSessionReplay: false, captureAppLifecycleEvents: false, errorTracking: { autocapture: { uncaughtExceptions: true, unhandledRejections: true, console: [] } } })`, using the SDK's actual option names. The installed SDK's before-send hook runs scrubMessage/scrubStackFrame. If no hook exists, wrap captureException and drop autocapture in favour of a global `ErrorUtils.setGlobalHandler` wrapper that scrubs first. This client never calls optOut, identify or reset (D-18: legitimate interest, disclosed in the privacy policy; re-verified at Compliance). The provider is chosen by `getEnv().errorTracking`.
3. Source maps: follow PostHog's current React Native/Expo instructions. The expected shape is a `metro.config.js` using PostHog's metro helper (e.g. `getPostHogExpoConfig`) wrapping `getDefaultConfig(__dirname)`, plus an EAS build hook or `posthog-cli sourcemap upload` that uses `POSTHOG_PERSONAL_API_KEY`/`POSTHOG_PROJECT_ID` from EAS env (add them as secret-visibility EAS vars in the preview environment). If a new devDependency is needed (e.g. `@posthog/cli`), install it (package.json is in this plan's files) and note it in the SUMMARY.
4. Spike trigger: in `index.ts`, export `maybeFireSpikeError()`. It throws `new Error('FINCWIN_SPIKE_ERROR 12345')` 3 seconds after boot only when `process.env.EXPO_PUBLIC_ERROR_SPIKE === '1'`, a literal access so it inlines. It is removed in Task 3.
