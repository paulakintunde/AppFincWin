## Pattern Assignments

### `src/engine/parts/expandParts.ts` (engine utility, transform)

**Analog:** `src/engine/insights/categories.ts` (the reader that sums per category) and RESEARCH.md Pattern 1 for the shape.

**Import and boundary rule** (categories.ts L1-12): engine files import only other engine files (`../money/...`, `../decide/v3/types`). Never `db/`, `state/`, `services/`, `ui/`, `react`. Pass `category_parts` in as plain data.

**Core pattern to replace in each reader** (categories.ts L38-49):
```typescript
export function spendByCategory(months: readonly V3Month[], include: readonly string[]): ReadonlyMap<string | null, bigint> {
  const out = new Map<string | null, bigint>();
  for (const m of inScope(months, include)) {
    for (const l of m.lines) {
      if (l.status !== 'paid') continue;
      if (l.role !== 'spending' && l.role !== 'refund') continue;
      const amount = BigInt(Math.abs(l.amount));
      out.set(l.categoryId, (out.get(l.categoryId) ?? 0n) + (l.role === 'spending' ? amount : -amount));
    }
  }
  return out;
}
```
Change: loop `expandParts(l)` and use each `CategoryAmount.categoryId` and `.amount` instead of `l.categoryId` / `l.amount`. Gap rows come out as `categoryId: null` (Uncategorised, UI-SPEC owner answer). Use `RESEARCH.md` L213-230 `expandParts` verbatim as the body. Home-currency conversion of parts uses `allocate(homeAmount, partWeights)` through the new `allocateWithZeros`, never per-part conversion.

**usage.ts** (L1-20, `UsageRow { amountHome, status, isTransfer, isRefund }`): `categoryUsage(rows, cap)` takes already-category-filtered rows. The caller that builds `UsageRow[]` for one category must feed it the part amount for that category (use `expandParts` then filter by `categoryId`), so `categoryUsage` itself need not change.

### `src/engine/split/allocateWithZeros.ts` (engine utility, transform)

**Analog:** `src/engine/split/allocate.ts` L18-52.

**Constraint** (allocate.ts L19-24): TS `allocate` throws `RangeError` for weight `<= 0` while SQL `hh_allocate` accepts zeros (migration 20261122000600 L33-60: "zero weights get 0 ... all weights 0 is 22023"). Do NOT loosen `allocate`. Wrapper: filter positive weights, call `allocate`, re-insert zeros at original indexes; all-zero throws `RangeError` (mirrors SQL 22023). Export from `src/engine/split/index.ts` (currently `export { allocate } from './allocate';`).

**Test pattern** (`__tests__/allocate.test.ts` L1-25): `import fc from 'fast-check'`, `minorUnits(...)` helper, `describe/it` with literal arrays, then a property test that the sum equals the total. Add a parity test against the SQL cases the same way.

### `supabase/migrations/<date>_receipts_bucket_and_table.sql` (migration, file-I/O)

**Analog:** `supabase/migrations/20261011000100_statement_uploads_bucket.sql` (whole file).

**Bucket + insert policy pattern to copy:**
```sql
insert into storage.buckets (id, name, public, file_size_limit, allowed_mime_types)
values ('statement-uploads', 'statement-uploads', false, 10485760, array['application/pdf'])
on conflict (id) do update
  set public = false, file_size_limit = excluded.file_size_limit, allowed_mime_types = excluded.allowed_mime_types;

create policy "statement uploads: owner inserts own folder"
```

**Table RLS pattern** (`20261122000600_household_splits.sql` L114-121, copy for `transaction_receipts`):
```sql
alter table public.transaction_splits enable row level security;
create policy "read splits of visible lines" on public.transaction_splits for select to authenticated
  using (household_id in (select public.user_household_ids())
    and exists (select 1 from public.transactions t
                 where t.id = transaction_splits.transaction_id and (t.is_shared or t.created_by = (select auth.uid()))));
revoke all on public.transaction_splits from anon;
revoke insert, update, delete, truncate on public.transaction_splits from authenticated;
grant select on public.transaction_splits from authenticated;
```
`transaction_receipts` select policy uses the same visibility but a private line has no household requirement for its owner: `t.created_by = (select auth.uid()) or (t.is_shared and t.household_id in (select public.user_household_ids()))`. ```sql

```sql
grant execute on function public.stale_statement_uploads(interval, integer) to service_role;
select cron.schedule('statement-uploads-purge-hourly', '17 * * * *', $$ select net.http_post(
```
