Table (exact):
```sql
create table public.transaction_receipts (
  id uuid primary key,                                   -- client-generated (idempotent retries)
  transaction_id uuid not null references public.transactions(id) on delete cascade,
  household_id uuid not null,                            -- copied from the line by add_receipt; lets the household realtime channel filter on household_id (no FK: follows transactions.household_id)
  group_id uuid not null,                                -- = id for a single photo/file; shared by the pages of one scan
  page_no smallint not null default 1 check (page_no between 1 and 10),
  uploaded_by uuid references auth.users(id) on delete set null,   -- D-19: shared-line receipts outlive the uploader
  object_path text not null unique,                      -- '<line owner uid>/<transaction id>/<id>.<ext>', built server-side
  kind text not null check (kind in ('photo','file','scan')),
  mime_type text not null check (mime_type in ('image/jpeg','image/png','image/webp','application/pdf')),
  bytes integer not null check (bytes > 0 and bytes <= 5242880),
  created_at timestamptz not null default now(),
  unique (group_id, page_no)
);
create index transaction_receipts_tx on public.transaction_receipts (transaction_id);
create table public.receipt_purge_queue (object_path text primary key, queued_at timestamptz not null default now(), attempts int not null default 0);
```
RPC contracts (exact):
```sql
public.add_receipt(p_id uuid, p_transaction uuid, p_group_id uuid, p_page_no int, p_kind text, p_mime text, p_bytes int) returns jsonb
  -- ok: {"ok": true, "object_path": text, "already": boolean}
  -- refusals: not_found | too_many_receipts | too_many_pages | too_big | bad_type | object_missing
public.receipt_object_path(p_id uuid, p_transaction uuid, p_mime text) returns text   -- for the client to know where to upload before add_receipt; same predicate as add_receipt; null when the caller cannot edit the line
public.remove_receipt(p_group_id uuid) returns jsonb       -- ok: {"ok": true, "transaction_id": uuid, "removed": int}; refusals: not_found
public.remove_all_receipts(p_transaction uuid) returns jsonb -- ok: {"ok": true, "removed": int}; refusals: not_found
public.pending_receipt_purges(p_limit int) returns setof text   -- service_role only: queued paths first, then orphan objects older than 1 hour with no row
public.ack_receipt_purges(p_paths text[]) returns int           -- service_role only: deletes those queue rows
public.prune_receipt_rows_without_objects() returns int         -- service_role only: D-23 restore step; deletes rows whose object no longer exists
```
Extension from mime: image/jpeg -> jpg, image/png -> png, image/webp -> webp, application/pdf -> pdf.
Editable-line predicate (used by add/remove/object_path and the insert policy): `t.deleted_at is null and (t.created_by = auth.uid() or (t.is_shared and t.household_id in (select public.user_household_ids())))`.
