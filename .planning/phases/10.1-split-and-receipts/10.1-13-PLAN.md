Algorithms (exact):
- itemsToParts: net_i = price_i - discount_i; receipt-level `discounts` spread over net_i by allocateWithZeros(discounts, net_i) and subtracted; group remaining amounts by categoryId in first-appearance order; drop zero groups; then if tax + tip > 0 append { categoryId: taxTipCategoryId ?? lineCategoryId, amount: tax + tip, label: 'taxTip' }; multiply every amount by lineSign; return null if fewer than 2 parts.
- itemShares: for each item, people must be non-empty ('empty_item') and in members ('unknown_member'); net = price - discount split by allocateWithZeros(net, people.map(() => 1)) in the item's people order; itemTotals per member; E = tax + tip - discounts; if E != 0 and every itemTotal is 0 -> 'no_items'; extras = E === 0 ? zeros : allocateWithZeros(E, itemTotals in members order) (negative E splits on magnitude, as allocate does); total = items + extras.
- suggestItemCategory: g = guessCategory({ name: itemName, amount: -1 }, ctx); if g.categoryId !== null and g.source !== 'income-default' -> 'item'; else if storeName, g2 = guessCategory({ name: storeName, amount: -1 }, ctx) with the same rule -> 'store'; else none.
