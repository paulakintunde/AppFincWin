# Phase 10.1 Plan 25: Scan entry points Summary

"Scan a receipt" now sits right after "Add expense" in the FAB quick menu, the screen-reader actions and You > Add, at level 2 only. It goes through the add-transaction write gate, so a locked plan shows the lock mark and the "needs a plan" sheet. It opens a capture choice (photo, image file, scan). The picked files go to the scan sheet in 'new' mode as the picked `LocalReceiptFile` objects, so the outbox byte cap sees their real size. Nothing is written before "Add this line", and the picked cache copies are deleted whenever the flow ends. On a line's Receipt sheet, "Read this receipt" downloads the stored image pages to the cache (a page still in the outbox is used where it is). The Receipt sheet then closes and the scan sheet opens for that line in 'existing' mode. The downloaded copies are deleted when the scan closes.

## Deviations from Plan

2. **[Rule 3] `defaultPickFileDeps(types?)`** in `src/services/receipts/pickFile.ts` takes an optional type list. The default is unchanged (image or PDF). The chooser asks for `['image/*']`. A PDF that still arrives is deleted and the chooser shows "That file type isn't supported".

6. **If no page downloads** (offline, signed link refused), "Read this receipt" closes the Receipt sheet and opens nothing. There is no new error copy. Noted for the owner check below.
