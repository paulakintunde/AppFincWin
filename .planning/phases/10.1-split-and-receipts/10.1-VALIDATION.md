## Execution Preconditions

- **Phase 10 must be merged to main before 10.1 execution starts.** Plans 05, 11, 12, 14, 17, 20, 22 and 23 build on Phase 10 code (newest `apply_patches`, alerts SQL, delete-account, wipe and write queue, TransactionSheet, ExportScreen).
- **Database-verify plans run one at a time.** Plans that run `supabase db reset` / `supabase test db` (05, 06, 14, 16, 30 and any plan touching `supabase/`) share one local Docker stack; execute them serially even when they share a wave.
- Jest is `~29.7.0` in this repo (CLAUDE.md's stack table says 30.x; the repo pin wins).

## Sampling Rate

- **After every task commit:** quick command for the touched module + lint; the pgTAP file for any migration being edited.
- **After every plan wave:** `npm run test:engine`, `npm test` (touched folders), `npm run test:deno`, lint, `npm run check:cache-version`, `npm run check:icons`.
- **Before `/gsd-verify-work`:** full suite green; scoped mutation run on `src/engine/parts` and `src/engine/receipt`.
- **Max feedback latency:** 120 s for quick checks (owner rule: no full local coverage per plan; full runs at wave/milestone boundaries).
