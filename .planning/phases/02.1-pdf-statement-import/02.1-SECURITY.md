> Per-phase security contract: threat register, accepted risks, and audit trail. ## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Phone to Storage (`statement-uploads`) | Authenticated client uploads a PDF into its own folder; no client read/list/delete | Raw bank statement PDF (highly sensitive) |
| Phone to `read-pdf-statement` | Caller JWT verified at gateway and in-function; service role used only after the ownership check | Object path, optional PDF password; positioned text returned |
| `read-pdf-statement` to Storage | Service-role download then remove in `finally` | PDF bytes (transient) |
| pg_cron to `purge-statement-uploads` | Own shared secret, `verify_jwt = false`; service role Storage API | Count-only; object names never logged |
| Statement content to analytics/logs | Allow-list builders only (D-14, D-15) | Layout fingerprint booleans/literals; log metadata |
| Phone to Postgres (IMP-05) | Insert-only provenance columns, generated `conversion_source`, RLS per household | Foreign amount/currency, fee link |
| Developer machine to production | Preflight-guarded push and deploy from the merged main checkout | Migrations, function secrets |
