```typescript
import type { StatementDraft } from '../types';
import type { PdfExtraction } from './types';
import type { LayoutFingerprint } from './layoutFingerprint';
export interface PdfDraftOptions {
  accountCurrency: string;                       // D-12: used when the PDF shows no currency
  exponentFor(code: string): number | null;
  dayFirst: boolean;                             // region default for ambiguous numeric dates
  decimalMark: '.' | ',';                        // region default when notation is ambiguous
  today: string;                                 // 'YYYY-MM-DD' (D-27 question only)
  yearOverride: { section: number; year: number } | null;
}
export interface PdfDraft { draft: StatementDraft; yearQuestion: [number, number] | null; sectionLabel: 'checking' | 'savings' | 'card' | null }
export type PdfDraftResult = { kind: 'drafts'; drafts: PdfDraft[] } | { kind: 'unreadable'; fingerprint: LayoutFingerprint };
export function pdfToDrafts(extraction: PdfExtraction, opts: PdfDraftOptions): PdfDraftResult;
```
Algorithm: lines = groupLines(pages); spans = findSections(lines); segments = spans.length >= 2 ? each span's lines prefixed with the lines before the first section (so period/summary preamble applies to every section) : [all lines]. Per segment: table = assembleTable(segment); null -> failure 'no_table' (roles []); zero rows -> failure 'no_rows' (table.roles). If no segment yields rows -> `{ kind: 'unreadable', fingerprint: buildLayoutFingerprint({ failedStep, pageCount, roles }) }` from the first failure; otherwise drafts for the readable segments in file order.
Per readable segment:
1. Notation: `inferNumberNotation(allNumericTexts)` (amount/debit/credit/candidate/balance cells + summary texts); 'ambiguous' -> `notationFor(opts.decimalMark)`; 'mixed-grouping' -> its notation + warning 'mixed-grouping'.
2. Currency: every numeric text containing '£' -> 'GBP', '€' -> 'EUR' (only when all symbol-bearing texts agree), else null; row currency = detected ?? accountCurrency; exponent = exponentFor(that) ?? 2.
3. Amount per row by amountColumn: 'amount' -> parseNotatedAmount marker; 'debit'/'credit' -> magnitude from the parse, marker 'dr'/'cr' ('cr' parsed in a debit cell or 'dr' in a credit cell -> 'conflicting-markers'); 'both-columns' -> magnitude |credit − debit| via BigInt, marker 'cr' when credit > debit else 'dr', rawAmount `${debit} | ${credit}` sliced to MAX_RAW_CELL, issue 'pdf-ambiguous-column'; 'between' -> learned = learnDebitDirection(samples from clearly placed debit/credit rows whose previous and current balances exist, step = balanceStep(prevSigned, curSigned, magnitude)); step = balanceStep(prev, cur, magnitude); both non-null -> 'dr' when step === learned else 'cr'; otherwise marker 'none' + 'pdf-ambiguous-column'; headerless candidates -> pickByDelta(prev, cur, magnitudes) -> that magnitude with marker step > 0 ? 'plus' : 'minus' (positive means "the balance went up"; the format profile decides what that means, D-53); a single candidate without a usable balance -> its own notation marker; otherwise 'pdf-ambiguous-column' with the first candidate. Signed balances are markerSign(balanceMarker) * balanceMagnitude; `prev` is the previous row's balance or the stated opening for the first row. Parse errors map: 'too-large' -> 'amount-too-large', 'conflicting-markers' -> 'conflicting-markers', any other -> 'bad-amount' (magnitude null); magnitude 0 -> 'zero-amount'.
4. Balance: parseNotatedAmount(balanceText) -> balanceMagnitude/balanceMarker/rawBalance; failure -> 'bad-balance'.
5. Dates: parsePdfDate per row; numeric rows resolved with numericOrder over all numeric dates (row + period tokens): 'DMY'/'MDY' -> that; 'ambiguous' -> dayFirst ? 'DMY' : 'MDY' plus 'pdf-ambiguous-date' on those rows; 'invalid' -> 'bad-date'. 'no-date' rows reuse the previous row's parts with 'pdf-no-date' (no previous -> localDate null + 'bad-date'). period = parsePeriod(summary.periodLine, dayFirst); assignYears(parts, period ?? { start: null, end: null }, { today, firstRowYear: yearOverride?.section === index ? yearOverride.year : null }); outOfPeriod -> 'pdf-ambiguous-date'; unparseable dateText -> 'bad-date'.
6. Description: descriptionParts.join(' ') whitespace-collapsed, sliced to MAX_DESCRIPTION; empty -> 'empty-description'; 'wrapped' -> 'pdf-wrapped-description'.
7. Stated figures: openingText/closingText -> StatedBalance { magnitude, marker, asOf: period?.start / period?.end ?? null, raw }; availableText -> `available`; limitText -> statedLimit magnitude. accountHint: section 'card' or summary.cardHint -> 'card'; section checking/savings or bankHint -> 'bank'; else null. balanceLabel: availableLabel -> 'available' else null. labels: debit+credit roles -> 'debit-credit-columns'; 'dr-cr-markers' only when EVERY amount-column row's marker is 'dr' or 'cr' (Phase 2's inferProfile treats that label as deciding the sign outright, so a card with CR on payments only must not claim it — its sign is decided by reconciliation and the payment-row phrase instead); availableLabel -> 'available-balance-label'; statedLimit -> 'limit-label'; any balanceMarker 'od' -> 'od-marker'. warnings: summaryLinesRemoved -> 'summary-lines-removed'. layoutSignature `pdf|${mode}|${roles.join(',')}|${notation.decimal}` sliced to MAX_LAYOUT_SIGNATURE. source 'pdf', externalId null, trnType null, periodStart/periodEnd from period, rows indexed 0..n−1 in file order.
Never throw for content; no console; no parseFloat/Number() on amount text. Append `export * from './toDraft';` to pdf/index.ts. RED then GREEN.
