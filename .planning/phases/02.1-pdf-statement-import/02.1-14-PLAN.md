foreign.ts (pure; imports only ../money and ./types):
```typescript
export interface ForeignOpts { notation: NumberNotation; exponentFor(code: string): number | null }
export const FOREIGN_SYMBOLS: Readonly<Record<string, string>>; // 'US$':'USD','C$':'CAD','CA$':'CAD','A$':'AUD','AU$':'AUD','NZ$':'NZD','€':'EUR','£':'GBP' — bare '$' and '¥' deliberately absent (ambiguous)
export function parseForeignNote(text: string, opts: ForeignOpts): ForeignAmount | null;
export type OfxForeignInput = { kind: 'currency' | 'origcurrency'; trnAmtMagnitude: MinorUnits; accountExponent: number; curRate: string | null; curSym: string | null };
export function foreignFromOfx(input: OfxForeignInput, exponentFor: (c: string) => number | null): { chargedMagnitude: MinorUnits; foreign: ForeignAmount } | null;
export function foreignFromColumns(amountCell: string, currencyCell: string, rowCurrency: string, opts: ForeignOpts): ForeignAmount | null;
export function impliedRate(charged: { magnitude: number; exponent: number }, foreign: { magnitude: number; exponent: number }): string;
```
parseForeignNote: one anchored scan per pattern, with no nested quantifiers: `CODE AMOUNT`, `AMOUNT CODE` or `SYMBOL AMOUNT`, where CODE is 3 upper-case letters (case-insensitive input) and AMOUNT goes through `parseNotatedAmount(…, opts.notation, exponent)`. Any '@ …' rate text is ignored, because the implied rate is always computed from the stored figures (D-33). Unknown code (exponentFor null), parse failure or zero -> null.
foreignFromOfx: per the OFX 2.x spec, CURRATE is the ratio of CURDEF currency to CURSYM currency (account units per foreign unit). 'origcurrency': TRNAMT is already in CURDEF -> foreign = TRNAMT / CURRATE. 'currency': TRNAMT is in CURSYM -> charged = TRNAMT x CURRATE. Do all arithmetic in bigint: `parseRate(curRate)` (try/catch -> null; <= 0 -> null), scale by 10^exponent differences, `divideHalfUp`. Results above MAX_ABS_AMOUNT_MINOR or zero -> null. The direction is pinned by the CAD/USD cases above; plan 02.1-15's reconciliation test on a CURRENCY fixture confirms it end to end.
impliedRate: `num = BigInt(charged.magnitude) * 10n ** BigInt(foreign.exponent) * 10n ** 4n`, `den = BigInt(foreign.magnitude) * 10n ** BigInt(charged.exponent)`, `q = divideHalfUp(num, den)`, then format q / 10^4 with trailing zeros (and a trailing '.') trimmed.
Barrel: `export * from './foreign';` in src/engine/statement/index.ts. RED commit, then GREEN.
