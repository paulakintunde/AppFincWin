## Where the PDF is read

| Option | Description | Selected |
|--------|-------------|----------|
| Server, Supabase Edge Function | Upload to private Storage, read in Deno, return rows to the phone. Breaks D-17 for PDFs only | |
| On the phone | Nothing uploaded; D-17 holds. Risk: parsing performance in Hermes on the iPhone XR | |
| Separate worker service | e.g. a Python container. Best parsing, but a new vendor, region and DPA | |
| You decide after research | Research compares the options against real statements | ✓ |

**Tie-break:** on-device if it's good enough ✓ (other options: best accuracy wins; fewest new vendors wins)
**Region if uploaded:** same project region, us-west-2 ✓ (other options: EU region for EU users; you decide)
**"Good enough" bar:** reconciles and reads in under about 10 s on the iPhone XR for about 10 pages ✓ (other options: reconciles at any speed; you decide)
**Upload consent:** one-line notice on every import ✓ (other options: ask once and remember; no extra step)
**Offline and server needed:** say so, nothing queued ✓ (other option: queue and read later)
**Size limit:** about 25 pages / 10 MB ✓ (other options: one statement period only; you decide)
**Entry point:** file picker only ✓ (other option: picker plus share sheet)
**Plan gating:** available to all for now, Phase 9 decides ✓ (other option: mark as Pro)
