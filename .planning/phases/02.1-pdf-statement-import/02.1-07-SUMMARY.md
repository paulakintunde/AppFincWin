# Phase 02.1 Plan 07: Generic layout reader Summary

Pure-engine PDF table reader: positioned text to lines, cells, header anchors and column placement (layout.ts); raw rows with wrapped/no-date/between/both-columns flags, statement figures, sections and a headerless fallback (rows.ts); strict validation of the server response; an anonymous layout fingerprint; and a Jest + typecheck guard keeping the engine and Edge Function wire contracts identical.
