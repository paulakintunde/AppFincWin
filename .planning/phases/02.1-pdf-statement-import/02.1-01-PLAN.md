```js
export const HELVETICA_WIDTHS; // per-1000-em widths: digits 556, ' ' 278, ',' 278, '.' 278, '-' 333, '(' 333, ')' 333, '/' 278, ':' 278, '@' 1015, '£' 556, upper-case letters 667 (use 722 for C D H N R U, 778 for G O Q, 833 for M, 944 for W, 611 for E F L T Z, 278 for I, 500 for J), lower-case 556 (222 for i j l, 278 for f t, 333 for r, 500 for c k s v x y z, 833 for m, 722 for w), any other char 556

export interface PageSpec { texts: { str: string; x: number; y: number; align?: 'left' | 'right' }[]; shapes?: string[] } // shapes = raw PDF path operators
export function writePdf(pages, opts = { encrypt: null | { userPassword: string; ownerPassword: string } }): Buffer;
```
PDF 1.4, A4 (MediaBox [0 0 595 842]), one shared font object `<< /Type /Font /Subtype /Type1 /BaseFont /Helvetica /Encoding /WinAnsiEncoding >>`, font size 9 for every text. Each text item is its own `BT /F1 9 Tf 1 0 0 1 <x> <y> Tm (<str>) Tj ET` so pdf.js emits one text item per cell; `align: 'right'` means x is the right edge (render at x − textWidth). Strings escaped (`\\`, `\(`, `\)`); non-ASCII chars written as WinAnsi octal escapes ('£' -> `\243`). Content streams uncompressed. Objects numbered in write order; xref entries exactly 20 bytes (`%010d 00000 n \n`); trailer `/Size /Root` and always `/ID [<hex16><hex16>]` with a fixed ID derived from the fixture name (md5 of the name) so output is deterministic. Header line `%PDF-1.4` followed by `%\xE2\xE3\xCF\xD3`.
Encryption (test fixture only — the reader side never hand-rolls crypto; pdf.js decrypts): PDF Standard Security Handler, /V 1 /R 2, 40-bit RC4, P = -44. PAD = hex `28BF4E5E4E758A4164004E56FFFA01082E2E00B6D0683E802F0CA9FE6453697A`. pad(pw) = (pw bytes + PAD) first 32 bytes. O = RC4(md5(pad(owner))[0..5], pad(user)); key = md5(pad(user) ‖ O ‖ P as 4-byte little-endian (D4 FF FF FF) ‖ ID[0])[0..5]; U = RC4(key, PAD). Each content stream is encrypted with RC4(md5(key ‖ objNum 3 bytes LE ‖ gen 2 bytes LE)[0..10]) (strings live only inside content streams, so no other object needs encryption). Encrypt dict `<< /Filter /Standard /V 1 /R 2 /O <hex> /U <hex> /P -44 >>` referenced from the trailer. RC4 hand-written (KSA + PRGA, ~12 lines); md5 via `createHash('md5')`.
