Rules for chooseMonthLayout:
- rowWidth <= 0 or longWidth <= 0 (not measured yet) → { name: 'long', icons: 'inline' }
- inlineRoom = rowWidth - arrowsWidth - iconsWidth - gap; longWidth <= inlineRoom → long/inline
- else shortWidth > 0 and shortWidth <= inlineRoom → short/inline (D-55 step 1)
- else icons 'below' (D-55 step 2); name = longWidth <= rowWidth - arrowsWidth ? 'long' : 'short'
Cases: Pixel-9-like (rowWidth 368, arrows 104, icons 124, gap 8; long 110) → long/inline; long 130, short 80 → short/inline; 320pt (rowWidth 276; long 110, short 70) → below with name long (110 <= 172); rowWidth 276, long 200, short 150 (2x text) → below/short; unmeasured → long/inline; boundary equality (longWidth === inlineRoom) → long/inline.
formatMonthShort('2026-10','en-GB') → 'Oct 2026'; ('2026-09','en-GB') → 'Sept 2026'; ('2026-09','en-US') → 'Sep 2026'. compactMonthLabel('2026-10','2026-09','en-GB') → 'Oct'; ('2025-10','2026-09','en-GB') → 'Oct 2025'. Neither ever uses String.slice on a month name (D-54, Phase 3 L3).
