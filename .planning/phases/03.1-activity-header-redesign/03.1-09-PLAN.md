Create `FilterChipRow.tsx`:
```tsx
export interface FilterChipProps { model: FilterChipModel; onOpen: () => void; onRemove: (kind: FilterKind) => void; labelRef?: React.Ref<View> }
export function FilterChip(...)  // plain View (not accessible) + label Pressable + × Pressable
export interface FilterChipRowProps {
  leading: React.ReactNode;                       // the DisplayChip
  leadingFocusRef: React.RefObject<View | null>;  // DisplayChip's ref (focus target when no chips remain)
  chips: readonly FilterChipModel[];
  onOpenFilters: () => void;
  onRemove: (kind: FilterKind) => void;
  onClearAll: () => void;
}
export const CLEAR_ALL_FROM = 3; // D-67
```
FilterChip layout: outer `View` row, `minHeight: space.touchMin`, `borderRadius: radii.pill`, `backgroundColor: colors.fill1`, `overflow: 'hidden'`, with the accent tint view first; label `Pressable` (`accessibilityRole="button"`, label `t('activity.filterChip.openA11y', { label: model.label })`, `paddingLeft: space.gapMd`, `justifyContent: 'center'`, `minHeight: space.touchMin`, pressed opacity `PRESSED_OPACITY`) containing `Text` label role in `colors.accent` with `numberOfLines={1}`; × `Pressable` (`accessibilityRole="button"`, label `t('activity.filterChip.removeA11y', { label: model.label })`, `minWidth: space.touchMin`, `minHeight: space.touchMin`, centred, pressed opacity) containing `<CloseGlyph color={colors.accent} />`. The × sits inside the chip's own height, so `overflow: 'hidden'` never clips its hit area (RESEARCH: Chip clip note).
FilterChipRow: `const items = <>{leading}{chips.map((c, i) => <FilterChip key={c.kind} model={c} labelRef={setRef(i)} onOpen={onOpenFilters} onRemove={handleRemove(i)} />)}{chips.length >= CLEAR_ALL_FROM ? <Chip label={t('activity.filter.clearAll')} onPress={onClearAll} /> : null}</>`. When `chips.length >= CLEAR_ALL_FROM` wrap in `<ScrollView testID="filter-chip-scroll" horizontal showsHorizontalScrollIndicator={false} contentContainerStyle={{ gap: space.gapSm, paddingRight: space.screenH, alignItems: 'center' }}>`; otherwise `<View testID="filter-chip-row" style={{ flexDirection: 'row', flexWrap: 'nowrap', alignItems: 'center', gap: space.gapSm }}>`.
Focus after removal: keep refs in `useRef<(View | null)[]>([])`; `handleRemove(i)` stores `pendingFocus.current = i` then calls `onRemove(kind)`; a `useEffect` on `chips` (length change) reads `pendingFocus.current`, resets it to null, and calls `focusAccessibility(refs.current[i] ?? refs.current[chips.length - 1] ?? leadingFocusRef.current)` — i.e. the chip now at the removed index (the next one), else the last remaining chip, else the Display chip. Comment cites UI-SPEC "Removing a filter moves focus to the next chip, or to the Display chip".
Tests (`FilterChipRow.test.tsx`, async RNTL in `ThemeProvider`, mock '@/shell/a11yFocus' with `focusAccessibility: jest.fn()`): every behavior above; use `rerender` to simulate the parent removing a chip.
