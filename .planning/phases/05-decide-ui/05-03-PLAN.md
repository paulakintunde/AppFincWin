1. `public.decide_checks`:
```sql
create table public.decide_checks (
  id uuid primary key,                                                    -- client-generated (MON-08)
  household_id uuid not null references public.households(id) on delete cascade,
  created_by uuid not null default auth.uid() references auth.users(id) on delete cascade,
  updated_by uuid references auth.users(id) on delete set null,
  kind text not null default 'buy' check (kind in ('buy', 'invest')),
  name text not null default '' check (char_length(name) <= 80),
  inputs jsonb not null default '{}'::jsonb check (jsonb_typeof(inputs) = 'object' and pg_column_size(inputs) < 32768),
  status text not null default 'open' check (status in ('open', 'bought', 'waiting', 'passed')),
  furthest_step smallint not null default 1 check (furthest_step between 1 and 5),
  last_seen_state text check (last_seen_state is null or last_seen_state in ('fits', 'adjust', 'no', 'missing')),
  last_seen_basis text check (last_seen_basis is null or last_seen_basis in ('logged_months', 'first_read_rough_figures')),
  reopened_from uuid references public.decide_checks(id) on delete set null,
  decided_at timestamptz,
  verdict_at_decision text check (verdict_at_decision is null or verdict_at_decision in ('fits', 'adjust', 'no', 'missing')),
  estimate_day_one bigint check (estimate_day_one is null or abs(estimate_day_one) <= 10000000000000),
  estimate_monthly bigint check (estimate_monthly is null or abs(estimate_monthly) <= 10000000000000),
  wait_monthly bigint check (wait_monthly is null or wait_monthly between 0 and 10000000000000),
  ready_by date,
  broke_line boolean not null default false,
  is_sample boolean not null default false,
  deleted_at timestamptz,
  version integer not null default 1,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  constraint decide_checks_kind_matches_inputs check (not (inputs ? 'kind') or inputs ->> 'kind' = kind),
  constraint decide_checks_decision_shape check (
    (status = 'open' and decided_at is null)
    or (status = 'bought' and decided_at is not null and estimate_day_one is not null and estimate_monthly is not null)
    or (status = 'waiting' and decided_at is not null and wait_monthly is not null)
    or (status = 'passed' and decided_at is not null))
);
create index decide_checks_owner_idx on public.decide_checks (created_by, household_id) where deleted_at is null;
```
   Triggers: `fill_decide_check` (before insert): `new.created_by := coalesce((select auth.uid()), new.created_by); new.updated_by := new.created_by;`. `guard_decide_check` (before update): pin `new.id/household_id/created_by/created_at/reopened_from/is_sample := old.*`, `new.updated_at := now()`, and `if old.status <> 'open' and (new.inputs is distinct from old.inputs or new.name is distinct from old.name or new.furthest_step is distinct from old.furthest_step or new.kind is distinct from old.kind) then raise exception 'decide_checks: a decided check is read-only' using errcode = '42501'; end if;`. `kind` is NOT pinned: step 1 lets the user switch purchase and investment while the check is open (05-14), and the client writes `kind` and `inputs` (whose `inputs.kind` carries the same value) in one update; the `decide_checks_kind_matches_inputs` check keeps the two consistent (23514 on a mismatch). Plus `set_version` (bump_version) and `set_updated_by` triggers.
   RLS: `create policy "own decide checks" on public.decide_checks for all to authenticated using (created_by = (select auth.uid()) and household_id in (select public.user_household_ids())) with check (created_by = (select auth.uid()) and household_id in (select public.user_household_ids()));`
   Grants: `revoke all on public.decide_checks from anon; revoke insert, update, delete, truncate on public.decide_checks from authenticated; grant select on public.decide_checks to authenticated; grant insert (id, household_id, kind, name, inputs, furthest_step, last_seen_state, last_seen_basis, reopened_from) on public.decide_checks to authenticated; grant update (kind, name, inputs, furthest_step, last_seen_state, last_seen_basis, deleted_at) on public.decide_checks to authenticated;` (`kind` is updatable only while open, enforced by guard_decide_check)
