  <behavior>
withoutCheckWrites(source, checkId, links, replaced):
- written = links with check_id === checkId, source 'written', deleted_at null; rowIds = their 'transactions' targets; seriesIds = their 'recurring_series' targets; debtIds = their 'debts' targets ∪ ids of source.debts with check_id === checkId
- rows and upcomingRows: drop every row whose id is in rowIds or whose recurring_series_id is in seriesIds (materialised occurrences of a written series go too)
- balances: for each dropped row with status 'paid' whose original_currency equals its account's currency, balances[account_id] −= original_amount (an outflow of −26_000 adds 26_000 back); a dropped paid row in another currency leaves the balance and is noted in the SUMMARY (Go ahead writes in the account's currency, so this does not arise from 05-20)
- series: drop ids in seriesIds; when `replaced` is set, a series whose id is in replaced.seriesIds and whose end_date === replaced.endedOn gets end_date null (Go ahead set that date, 05-20 endSeries; a replaced line was a live open-ended bill when picked — assumption recorded in SUMMARY)
- debts: drop ids in debtIds; paymentLinks and writtenRowLinks (D-40, 05-06): drop entries with check_id === checkId
- attached links, other checks' links, and deleted links remove nothing; every other field is passed through by reference; the input is never mutated (deep-frozen fixture in the test)

useBoughtCheckComputation(row, inputs):
- row null, inputs null, or row.status !== 'bought' → { status: 'idle', computation: null } (open, waiting and passed checks use 05-30's computeCheck path; nothing was written for waiting or passed)
- reads useDecideSnapshot(), useDecideLinks(userId, householdId, [row.id]) and useOtherChecks(row.id); while either query loads → 'loading'; an error → 'error'
- replaced = { seriesIds: inputs.replaces.map((l) => l.seriesId).filter(nonNull), endedOn: inputs.needBy ?? localDateIn(new Date(row.decided_at), timeZone) }
- computation = useMemo(() => computeCheck(buildDecideSnapshot(withoutCheckWrites(source, row.id, links, replaced)), inputs, stack.otherChecks), [source, links, inputs, stack]) — recomputed on every snapshot change (D-15), never stored
  </behavior>
