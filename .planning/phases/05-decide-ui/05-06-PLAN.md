buildDecideSnapshot(source: SnapshotSource): SnapshotResult
- currency = homeCurrency; asOf = today (04 alignment open item 5: the check date is today, not "When you need it")
- every row: home amount via homeAmountFor; null → excluded and meta.unconvertedRows += 1; amount = |home|; direction = sign (negative → 'out'); status, isRefund (is_refund), transferId (transfer_id), seriesId (recurring_series_id), categoryId passed through; deleted rows excluded
- counted-elsewhere series (one predicate, used for bills AND lines): `elsewhere = coveredSeries ∪ savingsSeries`, where `coveredSeries` = the `series_id` of every live loan|other debts row that yields a DebtRecord (that payment is the DebtRecord's `minimumPayment`, which the engine already counts in `debtPayments`), and `savingsSeries` = live series whose category builtin_key is 'Savings' (their rows already feed monthlySaving). Without this, a loan Go ahead (05-20: a debts row with minimum = plan.monthly AND a Debt-category payment series) would be counted twice, once as a debt minimum and once as a smoothed bill, and a Savings series would count as spending and as saving
- lines: rows whose `recurring_series_id` is in `elsewhere` are omitted (whatever their category); outflows in the builtin 'Savings' category that are not transfer legs are omitted from lines (they enter monthlySaving); outflows in builtin 'Debt' that are not transfer legs and belong to no series are omitted only when the snapshot has at least one DebtRecord from a debts row (otherwise kept as spending so nothing silently disappears — judgment recorded in SUMMARY); rows of a Debt-category series that no debt covers stay, so the engine pairs them with their bill
- months: one MonthRecord per fullMonthFlags key (newest first or oldest first, consistent; the engine picks the newest 6 full months, 04 D-09)
- bills: live series with amount < 0, (end_date null or end_date >= today) and id NOT in `elsewhere` (Savings-category series and debt-covered series are never bills; a Debt-category series that no debts row names stays a bill); latestAmount = |projectionHomeAmount(amount, currency)| (series with no conversion skipped and counted); confirmed: true (every stored series is user-created or accepted, 04 D-25); lastPaidDate = latest local_date among that series' rows with status 'paid' or 'skipped', else null
- cashOnHand (and `cash` on every result) = sum of projectionHomeAmount(balance, account.currency) over live (archived_at and deleted_at null) accounts of kind cash|checking|savings; meta.accountCount = their number
- debts: each live debts row of kind loan|other → DebtRecord { id, balance: home, minimumPayment: home, secured, apr: apr ? percent(apr) : null }; plus each live credit|loan account with a negative balance and no loan|other debts row pointing at it → DebtRecord { id: account.id, balance: |home balance|, minimumPayment: 0, secured: false, apr: the account's card-kind debts row apr (percent) or null } and meta.derivedDebts += 1; card-kind debts rows never create a DebtRecord of their own (they only supply the APR and minimum terms for the credit account's balance and for cards)
- cards: each live credit account → CardChoice { accountId, name, record: { id: account.id, apr: (card debts row apr) ? percent(apr) : null, minimumTerms: (row has all three min fields) ? { minimumPercent: percent(min_percent), interestAdded, floor: home(min_floor) } : marketTerms, currency } } where marketTerms = minimumTermsFromDefaults(MARKET_DEFAULTS[market]) with the floor converted to home (null if no market or no conversion)
- dealerCap = market ? projectionHomeAmount(MARKET_DEFAULTS[market].dealerCap) : null
- marketKeyFor(region): 'US' → 'US', 'CA' → 'CA', 'GB' → 'UK', anything else (incl. null) → null
- monthlySaving = half-up average over the full months used (newest ≤ 6 full months) of: transfer legs INTO savings accounts (direction in, transfer_id set, account kind 'savings', paid) + Savings-category outflows that are not transfer legs; monthlyInvesting = same for transfer legs into 'investment' accounts; 0 when no full month
- expenseLines: per category (null category → lineId 'uncategorised') half-up average monthly paid outflow over the full months used, excluding transfer legs; cuttable = false for builtin Housing, Savings, Debt, Tax
- limits from settings: reserve, investingFloor, savingFloor as numbers (null stays null); dsrLine = dsr_line ? percent(dsr_line) : null; unsecuredIncomeMultiple = unsecured_multiple; spareFloor null; when settings.currency is set and differs from homeCurrency, the three money limits are treated as null (defaults) — never converted at an invented rate
- basisOverride = settings.basis_override; scope = { kind: 'personal' }; householdSpending = null (D-18: household scope hidden until Phase 8); projectionReturn = null (the per-check rate is applied by computeCheck, D-07)
- kind: 'logged' when ≥1 month is full; else 'rough' when settings.rough_income and settings.rough_spending are both non-null (figures { currency, cash, monthlyIncome, monthlySpending }); else 'none'
- meta.fullMonths, meta.expenseLinesThisMonth (outflow rows dated in today's month), meta.debtCount (DebtRecords)
- money is integer minor units throughout; averages use bigint half-up division (engine/money `divideHalfUp`), never `/` on floats
