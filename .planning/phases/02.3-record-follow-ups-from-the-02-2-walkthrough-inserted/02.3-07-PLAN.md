## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device storage | identity list persists across sign-out on a possibly shared phone |
| native Google SDK -> app | silent sign-in may return whichever account the SDK has cached |
| app -> Supabase auth | ID token exchange |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02.3-07-01 | Spoofing | continueWithGoogle | mitigate | Silent result used only when its email equals the tile's (case-insensitive); otherwise SDK signOut + chooser; unit-tested |
| T-02.3-07-02 | Information Disclosure | remembered list | mitigate | Name/email/provider only, max 3, per-tile Remove, AsyncStorage (removed on uninstall), never in analytics/Sentry; privacy paragraph drafted |
| T-02.3-07-03 | Information Disclosure (tokens) | storage | mitigate | No token field in the stored type; session tokens stay in the existing encrypted session store, wiped on sign-out as today |
| T-02.3-07-04 | Tampering | stored JSON | mitigate | parseRemembered validates version, provider, email shape and lengths; anything else -> empty list |
