# Phase 02.3 Plan 16: Rules in import and paste Summary

User and household category rules now drive statement-import and paste-a-list categories with the same precedence as manual entry (personal > shared > learned > keywords > income default).

## What changed
- `PreviewInput` gained optional `personalRules` / `sharedRules`, passed into the guess context in `buildPreview`.
- `useStatementImport.goReview` reads `fetchCategoryRules` via `attempt()`; a failed read, or any failure resolving rules, degrades to no rules and the import proceeds.

## Tests
