# Phase 02.3 Plan 14: Rules management UI Summary

Rules list screen, add/edit/remove sheet, Categories entry row and `/category-rules` route, built on the 02.3-09 rule hooks.

## What was built
- **RuleSheet**: keyword, category (picker without Uncategorised, system categories excluded), scope chips for new rules and a fixed scope row on edit. Validation after first Save: empty, over 60 characters, no category, duplicate normalised keyword in the same scope (excluding the edited rule). Add and edit show Undo toasts; remove shows a destructive toast with no confirm.
- **RulesScreen**: "Just me" then "Shared with household", A-Z by keyword, category glyph, unresolved shared rules shown as "{name} · not in your categories" with slate glyph. Empty, loading, error (Try again) states; cached rows survive a failed refetch.
- **CategoriesScreen**: Rules row with count or entry sub-label, pushes `/category-rules`.
- **CategoryPicker**: `hideUncategorised` prop.
