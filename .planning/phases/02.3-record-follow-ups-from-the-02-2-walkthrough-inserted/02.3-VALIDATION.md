| **Estimated runtime** | quick ~30–180 s per folder on this machine; full ~10 min |

## Sampling Rate

- **After every task commit:** quick run on the touched folder + `npm run typecheck`
- **After every plan wave:** full suite on the integration branch (+ pgTAP for SQL waves)
- **Before `/gsd-verify-work`:** full suite green with engine coverage thresholds, then the device walkthrough
- **Max feedback latency:** ~180 seconds per task
