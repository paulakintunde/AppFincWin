## Shared Patterns

### RPC refusal contract
**Source:** `20261125000200:70-73, 94-102` (SQL) and `src/db/householdMembers.ts` `callRpc` / `RpcResult`
**Apply to:** every new RPC and every `src/db` wrapper. SQL returns `jsonb_build_object('ok', false, 'reason', '...')`; only a missing session raises. Wrapper doc comment lists reasons. Hook turns `!res.ok` into `throw new Error(res.reason)`.

### SECURITY DEFINER hygiene
`language plpgsql security definer set search_path = ''`, fully qualified `public.` names, `(select auth.uid())` or `public.hh_uid()`, `revoke execute ... from public, anon` then `grant ... to authenticated` (helpers: revoke from all clients, as `hh_common_household` at `:62`).

`20261125000200:35-52`; clients get `grant select` only. Classify every `household_id` table in pgTAP 102.

Integer minor units via `minorUnits` / `MinorUnits` from `src/engine/money/types`; engine files import only `../money`, sibling engine modules (`plan.ts:5-12`). 100% branch coverage (`jest.engine.config.js`); SQL money maths must match `check:money-mirror`.

### Comment convention
`// 08.12-NN (JSA-xx, D-xx): ...` at the top of every new file and edit site (CLAUDE.md "Comments cite the plan and decision").
