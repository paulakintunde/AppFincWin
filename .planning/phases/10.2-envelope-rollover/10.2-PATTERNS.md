### `src/engine/categorize/rollover.ts` (utility, transform)

**Analog:** `src/engine/categorize/usage.ts` (58 lines, pure, integer minor units, header comment cites decisions)

**Header + purity pattern** (usage.ts L1-2): `// Category usage and cap maths. CONTEXT D-04/D-06 ... // Pure: no I/O, no framework imports.` Copy this: no imports from db/state/ui/react; `categorize` is a 100% branch folder.

**Shape to copy** (usage.ts L4-20, 55-58): plain exported interfaces + plain exported pure functions, `readonly` array inputs, null for "no cap", no classes.
```typescript
export interface CategoryUsageResult { count: number; spent: number; cap: number | null; over: number; state: CategoryUsageState; unconvertedCount: number; }
export function crossesCap(spentBefore: number, spentAfter: number, cap: number | null): boolean {
  if (cap === null) return false;
  return spentBefore < cap && spentAfter >= cap;
}
```
Apply: `carryChain({limit, startMonth, throughMonth, spentByMonth}) -> readonly CarryMonth[]` with `effective = Math.min(2*limit, Math.max(0, limit + prevEffective - spent))`. Spend comes from `categoryUsage(rows, cap).spent` per month (do not re-sum; "Don't hand-roll"). Month stepping via `addMonths`/`monthOf` from `@/engine/time` (pure, already used by `useCategoryMonthUsage`). Reject non-integer or negative limits with `RangeError` (as `assertEditable`/`assertIconKey` style in mutations). Add `export * from './rollover';` to `index.ts` (existing barrel: builtins, guessCategory, usage, rules).

**Tests:** copy `usage.test.ts` structure (L1-30): `import fc from 'fast-check'`, small `row()` factory, `describe` per function, table cases. Property file follows `src/engine/insights/__tests__/categories.property.test.ts` (`import * as fc`, fixed `SEED`, `fc.assert(fc.property(...))`). Cases 1-10 from RESEARCH table become the unit table; properties: `0 <= E <= 2L`, carried in `[-L, L]`, monotone non-increasing in spend.
