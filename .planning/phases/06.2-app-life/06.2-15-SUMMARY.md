# Phase 06.2 Plan 15: You grouped like L04, with the Haptics switch Summary

The You screen now has the L04 groups: Add, Money, Appearance, Alerts and feel, Privacy and data, Account. Every row has one 36 accent tile and its word. The Accent, Font pairing, Week starts on, Home currency and Region rows show their current setting. A Haptics switch, on by default, turns off every haptic at once.

## What was built

- **HapticsRow** (D-21, D-28): a 36 accent tile (`haptics` icon) beside the shared `ToggleRow`. The label is "Haptics" and the hint is the L04 line. It reads `useHapticsEnabled()` from plan 03's store. Turning the switch off calls `setEnabled(false)` and makes no haptic. Turning it on calls `setEnabled(true)`, then `hapticTick()` (D-20: a switch), so the tick gets through the gate. A screen reader reads it as "Haptics, switch, on/off". It is the only row in "Alerts and feel".
- **YOU_ROW_ICON**: `Record<YouRowId, IconName>`, type-checked against the set. Final choices:

  | Row | Icon |
  |-----|------|
  | expense, income | add |
  | transfer | transfer |
  | importStatement | import |
  | newCheck | checkBuy |
  | activity | view |
  | accounts | accounts |
  | categories | categories |
  | history | history |
  | goals | savings |
  | weekStart | calendar |
  | homeCurrency | accounts |
  | region | view (no globe icon in the set) |
  | accent | accent |
  | font | font |
  | haptics | haptics |
  | analytics | privacy |
  | connection | connected |
  | signOut | signOut |

- **YouScreen**:
  - The Add rows keep their hints and quick-action handlers, and now have a tile and the arrow. Their minimum height is now 52.
  - The Money navigation rows and Sign out use `Row`, with the tile, the word and the `arrowRight` glyph.
  - Week starts on, Home currency and Region keep their own components, refs, testIDs and focus-scroll behaviour, with the tile beside them.
  - The Accent row shows the colour name, with the swatches still below it. The Font pairing row shows the pairing name, with the choices still below it.
  - The Connection rows (ConnectionStatus and SyncStatusLine) moved into Privacy and data, with the `connected` tile.
  - Sign out stays in plain ink words. No red text was added.
  - No Face ID, PIN lock, Alerts, Delete account or Download my data row was added.
- **SettingsGroup**: the heading is now `SectionHeader`, with no icon (D-06, D-24).
- **Group-title keys**:
  - New `appLife.you.groups.*` keys are used for every group title.
  - The plan-04 words already matched L04, so `src/i18n/locales/appLife/you.ts` needed no edit.
  - The old `you.record.section` and `you.section.*` keys are no longer used by YouScreen. `copyStatus.ts` still lists them; they were left in place.
