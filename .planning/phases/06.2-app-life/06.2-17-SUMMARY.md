# Phase 06.2 Plan 17: Category icon_key Summary

Custom categories can now store an icon name from FincWin's own set in a new nullable `categories.icon_key` (server camelCase shape check, owner-only grants, Undo-replayable through apply_patches), carried through the row type, select list, add/edit hooks with an ICONS allow-list, optimistic cache, export manifest, and a cache version bump 9 -> 10.

## Tasks

**Task 1 (ffa035b9): migration + pgTAP.** `20261115000100_category_icon_key.sql`:
- `alter table public.categories add column icon_key text;`
- `categories_icon_key_shape check (icon_key is null or icon_key ~ '^[a-z][A-Za-z0-9]{1,31}$') not valid;` then `validate constraint`
- `grant insert (icon_key)` and `grant update (icon_key)` on categories to authenticated (RLS unchanged: owner-only, system rows excluded)
- `apply_patches` re-issued verbatim from `20261114000100_decide_answered_undo.sql` (all 261114 lines kept). Only two lines differ, marked 261115: `'icon_key'` in the categories allowlist, and `when 'categories.icon_key' then 'text'` in the type map. Checked with a line diff: no other change. Needed because editing a category records an undo step that `undo_replay` runs through `apply_patches`; without the allowlist an icon Undo would fail with "unknown column" (the same bug 20261114000100 fixed for decide_settings).
- pgTAP 98 (13 assertions): has_column, nullable, valid insert + read-back, emoji / space / 33 chars / upper-case first letter rejected (23514), owner change + clear, apply_patches patch applied + stored, another user's update affects 0 rows.

**Task 2 (abc18778): client.** CategoryRow `icon_key?: string | null`, NewCategory/CategoryPatch accept it, CATEGORY_COLUMNS selects it, CATEGORY_INSERT_KEYS / CATEGORY_PATCH_KEYS include it. `useAddCategory` takes `iconKey`, `useEditCategory` takes `iconKey` (undo before-value = `row.icon_key ?? null`); both call `assertIconKey` and throw RangeError before any write for anything that is not null or a key of ICONS (`hasOwnProperty`, so `toString` / `__proto__` are refused too). Optimistic add row carries icon_key; edit spreads the patch into the cache. Export manifest categories list has `'icon_key'`. `CACHE_SCHEMA_VERSION = '10'` with comment, lock refreshed with `node scripts/check-cache-version.mjs --update`.
