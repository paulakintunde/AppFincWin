## Proposed doc edits (owner to accept or change in the PR)

CLAUDE.md, Design fidelity bullet (new text):

> **Design fidelity**: the §2 token set plus the seven Decide state colours (… unchanged list …) is the palette, with one owner-approved family added in Phase 06.2: four pale page tints, one per theme colour (`pageTint` in `src/theme/tokens.ts`), contrast-tested. The state colours appear only in badges, verdict cards and amounts, always with a symbol and a word, and each pair must pass the tests in `src/theme/contrast.ts`. The §2 type scale is complete; card item names and row amounts use the `bodyStrong` role (body size at weight 600). Depth comes only from the page tone (the theme colour's page tint; `canvas` #F6F4EE is the fallback), white `surface` cards, and the three shadow tokens in `tokens.ts` (`card`, `edge`, `fab`); `inkFaint` text never sits on the page tone. No gradients, no other shadows, no other added colours. Icons come only from FincWin's own set (`src/ui/icons`, generated from the 06.2 boards; `npm run check:icons`); no third-party icon set and no emoji. Sizes use six spacing steps (4/8/12/16/22/28), two row heights (52/64) and two icon tiles (36/48). The prototype's restraint is deliberate.
