# Phase 06.2 Plan 18: Empty states (D-24, L05) Summary

Every in-scope empty screen now shows one 48 icon tile, one heading, one sentence and at most one button. The empty Activity month uses the first-entry animated icon, which plays once.

## What was built

- **Activity empty month (L05):** the first-entry tile plays once (MilestoneIcon `firstEntry` inside a 48 accent-tint tile). It shows the still icon under Reduce Motion or on a build without the Lottie player. Below it are the heading "Nothing in {month} yet." and the board sentence. There is exactly one Pill: "Clone {month}" when an earlier month has lines (`monthTools.hasEarlier`), otherwise "Add a transaction", which opens the app-wide entry sheet. "Paste a list" stays as a quiet text link (`accessibilityRole="link"`, minHeight 44). The block is a Reanimated view with `exiting={FadeOut 150 ms}`, so when the first row arrives the card fades out in 0.15 s. Under Reduce Motion, `exiting` is undefined and the card leaves at once. Plan 11's NewRowWash already fades the just-saved row in.
- **Activity no-match:** the `search` tile, "Nothing matches." / "Try a different search, or set the filter back to All." and one "Clear search" button. The button clears the term (`vm.setTerm('')`), sets the filter to `EMPTY_FILTER` and clears a debt chip through `onClearDebt`.
- **CR-01 guard unchanged:** a failed or offline-uncached read still never shows the empty month. This is tested for both error and offline.
- **Coming up (HOME-03):** a payBills tile, "Nothing outstanding in {month}." / "Bills you add as monthly show here before they are due." and one "Add a bill" button that calls `openEntry`. The card's outer layout and shadow are unchanged (D-02).
- **History:** `icon="history"`, same words, no button.
- **Past decisions:** `icon="checkBuy"` only. The signed keys and words are unchanged, and the existing Back to Decide pill is kept.
