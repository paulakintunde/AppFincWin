# Phase 06.2 Plan 08: Milestone Lottie files and MilestoneIcon Summary

Five milestone animations generated straight from the board drawings by a new `build-lottie.mjs` (svgpath for arcs), each 72 frames at 60 fps that end on the still Glyph, played once through a new `MilestoneIcon` that sets the theme colour at runtime.

## What was built

**Task 1 (36d9d36e): Lottie builder**
- `scripts/icons/build-lottie.mjs` reads `icons.generated.json` and writes one file per milestone:
  - goalReached and debtCleared -> stateFits
  - importDone -> import
  - firstEntry -> firstEntry
  - safetyNetLocked -> stateSafetyNet
- Geometry: `svgpath(d).abs().unarc().unshort()`, then M/L/H/V/C/Q/Z become Lottie vertices with tangents relative to each vertex. Z merges a closing point that sits on the start. rect becomes `rc` (rx gives the roundness) and circle becomes `el`. Stroke width, round caps and round joins are copied from the drawing. Any unknown tag or attribute, or a missing `fill`, stops the build with an error.
- Motion (taken from the L07 CSS):
  - The `back` layer fades from 0 to 45 opacity over frames 0-18, ease-out.
  - Strokes on the `front` layer draw once with a trim path from 0 to 100 over frames 27-51, ease-out.
  - Fills on the `front` layer fade from 0 to 100 over frames 27-45.
  - The safety net shackle moves on y from -3.2 to 0 over frames 30-60, using cubic-bezier(.2,.8,.3,1).
  - The last frame is held until frame 72.
- Each file has v 5.7.0, fr 60, ip 0, op 72, a 24x24 size, and two layers in the order `front`, `back`. The files are 2-space JSON with LF endings.
- New scripts:
  - `npm run icons:lottie` writes the files.
  - `check:icons` now runs both the board-extract check and `build-lottie --check`, which fails when a committed file differs from a fresh build (CRLF is normalised).

**Task 2 (85187a24): MilestoneIcon**
- `MilestoneIcon({ name, color, size = 48, testID })` renders `AnimatedIcon` with the right source and still icon, and passes `colorFilters` set to `color` for both the `back` and `front` layers.
- `MilestoneName` is exactly the five names. `MILESTONE_NAMES` is exported.
- A header comment lists the D-19 exclusions: spending, a "fits" answer, streaks, account deletion, household joined, welcome, export.
- `AnimatedIcon` gets an optional `colorFilters` prop that it passes to the Lottie view. No other behaviour changed.

## Deviations from Plan

1. **The safety net shackle has no trim path.** The plan says front strokes draw, but the L07 board gives the shackle `.lf-shackle` only and no `.lf-draw`. So the shackle is drawn from the start and only closes, as on the board. The keyhole still fades in like the other front fills.
2. **The JSON is loaded with `import`, not `require`.** The behaviour is the same and it is typed, so the lint rule needs no disable.
3. **New devDependency `svgpath` ^2.6.0**, added with `npm install --save-dev svgpath` as the plan says. It is used only at build time.
