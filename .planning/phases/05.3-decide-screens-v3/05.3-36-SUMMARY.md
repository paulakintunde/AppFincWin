# Phase 05.3 Plan 36: Saved-plan rows, Past decisions and Envelopes Summary

SavedPlanRow (stored answer_v3 chip, Changed chip, D-13 refund line, unfinished rows with Undo delete), a v3 DecisionsScreen, and two V3Gate routes (decisions, envelopes) with a `titleKey` prop on PotsScreen.

## What was built
- `SavedPlanRow({ row, live, without })`: refundHint then savedPlanRow. Saved row is one Pressable with the UI-SPEC label, opens `answerHref`. Line 2 is the stored chip in its tone colour, or the `coveredBy` copy when the stored readyBy is a month. Changed chip (warnTint/warn1) when live differs; refund line when refundHint is true. Unfinished row: "Unfinished" in inkMuted, opens `purchaseHref`, DeletableRow delete calls `abandon(row, 'deleted')` and shows the existing Undo toast.
- `DecisionsScreen`: `useChecksV3`, bought and passed rows newest first (decided_at, else updated_at). Bought: "Bought · date"; passed: "You kept {price}" and "Not buying · date"; D-13 line; empty "Nothing decided yet". No old-engine helpers imported.
- Routes: thin files to `DecisionsRoute` / `EnvelopesRoute`, both inside V3Gate. Envelopes renders PotsScreen (inside GoalTagEditProvider) with `titleKey="decide.v3.ui.home.envelopes"`; default title unchanged.
- fitAllow entries for both new files (price figure scales, item wraps).

None to behaviour. No new copy keys were needed (all home.* and decisions.* keys existed).
