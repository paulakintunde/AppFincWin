# Phase 05.3 Plan 109: Decide sticky header in flow Summary

UAT gap 31 closed in code: Decide home's pinned header now takes its own layout space (opt-in `compactInFlow`), with a status-bar backdrop so nothing scrolls under the status bar.

## What changed
- `useTabRootChrome`: `compactInFlow` option; measures the compact header (onLayout), compensates the scroll offset by its height on show (via layout report) and on hide (scrollTo, animated false); hysteresis: show above threshold, hide below threshold minus header height. Returns `compactInFlow` and `compactVisible`.
- `TabRootScreen`: column of [status backdrop (height = top inset, canvas), in-flow compact header while visible, ScrollView, overlay]. Without the option the tree is unchanged.
- `CompactHeader`: `inFlow` and `onLayout` props (relative position, no inset in padding, no animated opacity).
- `HomeScreen`: `compactInFlow: true` in the shared header props. Only file outside the shell that opts in.
