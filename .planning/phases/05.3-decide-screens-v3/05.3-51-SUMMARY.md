# Phase 05.3 Plan 51: Spoken money, whole amounts and the Unspent date Summary

TalkBack now hears "4,865.09 dollars" on every host because formatMoneyA11y no longer depends on ICU's currency-name part order; worked-out lines keep each amount and its sign on one line; the Unspent sheet shows "Oct 3, 2026" instead of "2026-10-03".

## What changed

- **F7a** `formatMoneyA11y`: the number comes from `Intl.NumberFormat(locale, fractionOpts)` on the absolute decimal string; the currency word comes from `SPOKEN_NAMES` (USD at a USD home drops "US "), else `isoCurrency(code).name`, else the code. Tests pin USD/CAD/GBP/EUR, 150,228,286.09, singular "1 dollar" / "1 euro", "1.00 dollars", negatives, an unlisted ISO code (AED), an unknown code, and a spy that makes `formatToParts` return the Android order ("Dollar" first) with no effect on the output.
- **F3** `SixMonthBars`: new exported `unbreakableAmount(minor, money)` strips the zero-width break hints that `useV3Format().money` adds, turns plain spaces into no-break spaces and joins a minus to the figure with U+2060. Used by the per-month list lines (2.0x), the column figures, the typical-month line and the largest line. Visible characters are unchanged; the spoken group label is unchanged.
- **F7b** `UnspentSheet`: the local `date()` uses `formatLocalDate(iso.slice(0, 10), locale, 'medium')`, so en-CA no longer gives YYYY-MM-DD and a timestamp-shaped value still reads as its day.

## Deviations from Plan

1. **[Rule 3 - Blocking] Typecheck error in the new spy test.** The first version of the `formatToParts` mock typed its parameter as `number | bigint`, which TS rejects. Fixed with `Parameters<typeof real>[0]` in c3067361.
2. **Test file name.** The plan names `src/features/decide/setup/__tests__/UnspentSheet.test.tsx`; the sheet's tests already live in `unspent.test.tsx`, so the en-CA date test went there (with a `useDeviceLocale` override mock) rather than a new file.
3. **Negative wording.** The truth gives "minus 4,865.09 dollars" as the spoken form. The output is "−4,865.09 dollars" with U+2212, which TalkBack reads as "minus"; writing the English word into the engine string was not done, to keep the engine locale-neutral and existing caller tests stable.
