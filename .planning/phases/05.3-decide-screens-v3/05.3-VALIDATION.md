## Sampling Rate

- **After every task commit:** the quick command for the touched folder plus `npm run typecheck`.
- **After every plan wave:** the full suite command. If `src/features/decide/dev/__tests__/shadowExport.test.tsx` fails under load, re-run it alone before calling it red.
- **Before `/gsd-verify-work`:** full suite green; shadow D-14 gate and I28 back-test green after D-12; pgTAP green; owner checkpoints recorded (D-12 approvals if any new fit, D-15/D-16 migration push, Pixel walkthrough).
- **Max feedback latency:** 60 s for the quick command.
