# Phase 05.3 Plan 33: In-check answer bodies (unspent, extra money, income pattern, expected income) Summary

Four `(props: AskBodyProps) => JSX.Element` bodies that save straight away through the 05.2 mutations, each with an Undo toast and no toast on a null (nothing changed) save.

## What was built
- **UnspentBody**: UnspentSumCard plus "That's right" (confirms `sum.total`) and "Use my own figure" (MoneyInput, "Save figure"), both through the existing exported `useUnspent().confirm`; toast `unspentConfirmed`. No change to 05.2 files was needed.
- **UnexplainedBody** (D-50): four ChoiceCard rows -> `useSaveUnexplainedAnswer({ amount: question.params.amount, use, at: today })`, uses `spare | envelope_or_goal | set_aside_for_bill | someone_elses`; toast text `decide.v3.ui.check.saved` ("Saved").
- **IncomePatternBody** (D-34): `steady | variable | seasonal` -> `useSaveSetupStep({ labelKey: 'incomePatternSaved', patch: { income_pattern, income_pattern_confirmed: true } })`.
- **ExpectedIncomeBody** (D-35): caption "Expected money in for {Month}", Save disabled until a figure is typed, `useSaveDecideAnswer({ kind: 'expected_income', month: question.months[0], amount, at })`; "and N more months" line.
- Tests: 12 payload tests plus the unspent tests, and a 16-cell matrix (4 bodies x 320/402 dp x 1.0/2.0) with `expectFits`. fitAllow is empty (no fixed heights, line limits or overlays).
