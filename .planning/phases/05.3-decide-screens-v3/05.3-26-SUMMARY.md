# Phase 05.3 Plan 26: Funding strip, change tiles, not-ready card Summary

The funding strip, the three change/meta components and the D-06 not-ready checklist card are built with tests.

## What was built
- `FundingStrip({ model })` takes the 05.3-19 model (null renders nothing). 16-high bar, flexGrow by amount, accentHalf is opacity 0.5 on the accent, dashed is a 1.5 inkSoft1 dashed outline; legend with 10x10 dots and bold amounts. The bar and legend are hidden from assistive tech; the block label is built from heading + parts with `moneyA11y` through `stripA11y`/`stripPart`. Fades in once over DURATION.progress unless reduced motion. Envelope ids resolve to names via `useV3Format().flat`.
- `ChangedSinceOpenedTile` (polite live region, `announceForAccessibility` once per distinct sentence), `ChangedSinceSavedTile`, `SavedAnswerLine` (variant `saved` or `last`). Tiles take the 05.3-20 `ChangeTile` model and render nothing when `show` is false.
- `NotReadyCard({ readiness, thisMonth, onReady })`: rows from `notReadyRows`, each row one pressable group "{title}. {reason}. {button}", stacked layout, secondary-style button look. Activity rows `router.navigate('/activity')`; envelopes row `pushOnce(ENVELOPES_HREF)`. `onReady` fires once on the rows-to-none transition; `decide_not_ready_shown {first, count}` fires once on first show.
