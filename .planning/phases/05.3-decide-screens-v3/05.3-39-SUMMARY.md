# Phase 05.3 Plan 39: v3 Decide home assembly Summary

The v3 Decide home is assembled in `HomeScreen`, with the D-20 "Something changed?" row reusing the 05.2 sheet. The tab root is not switched to it yet (that is 05.3-43).

## What was built

- `HomeScreen`:
  - Header: the shipped title and eyebrow from `decide.setupPage.*`, plus a 44 px "Decide settings" button left of the avatar. The button is three ink dots, so no new icon set. The compact header gets the button and the avatar.
  - Order: setup status card (only while setup is not started or a needed step is unanswered), `MonthBarCard`, `RefineCard`, `CheckCard` when ready, `NotReadyCard`, `EnvelopeGrid`, Saved plans, Unfinished checks, `SomethingChangedRow`, the Past decisions row, and the `legal.decideFooter` line.
  - Month card: passes `unspentStaleDays` from `useUnspent().view` when its kind is `stale`.
  - Not-ready slot: `NotReadyCard` stays mounted and returns null at zero rows, so its ready transition fires `onReady`. That announces "Decide can check a purchase now." once, and `CheckCard` appears.
  - Data: everything comes from `useChecksV3` (`home`, `byId`, `withoutRefunds`). Saved rows are `status='waiting'`. Unfinished rows are `open` rows with a name or a price. The Past count is `bought` plus `passed`. Envelopes are plain pots from `usePotsRead`.
  - States: skeleton while loading, the shipped error copy with Try again when there is an error and nothing cached.
- `SomethingChangedRow`:
  - A surface row with a line2 border, ink text and a chevron, at least 44 high. It is not an accent pill.
  - It opens the real `SomethingChangedSheet`. A pick goes through `targetOf` with the same inputs Decide settings uses (`useSettingsData`, `isNeeded('pay')`, `fullMonthsOfRecords`). A route pick calls `pushOnce`. An emergency pick opens `EmergencyFundSheet`. Closing returns screen-reader focus to the row.
  - `usePickChange` was not needed, and the settings screen is untouched.
- fitAllow: geometry entries for `HomeScreen.tsx` (5) and `SomethingChangedRow.tsx` (1).
