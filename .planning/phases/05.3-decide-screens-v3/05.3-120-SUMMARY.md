# Phase 05.3 Plan 120: Named own-option History labels Summary

History now names own-option changes ("Your own option added · Bike", "Your own option renamed · Road bike", "Your own option removed · Bike") instead of "Setup answer saved". This closes UAT gap 37. It uses three new letter-only undo label keys, so no migration is needed.

## What changed

- `src/engine/undo/types.ts`: `UNDO_LABEL_KEYS` now includes `ownOptionAdded`, `ownOptionRenamed` and `ownOptionRemoved`. Only the constant changed. There are no engine logic changes.
- `src/i18n/locales/en.ts`: `undo.label.*` gets the named forms and `undo.labelUnnamed.*` gets the forms without a name.
- `src/features/decide/v3/check/useOwnOptions.ts`: `add` saves `ownOptionAdded` with the trimmed name as `stepTitle`. `commit` now receives its label key from the caller: rename and setBase pass `ownOptionRenamed`, remove passes `ownOptionRemoved`. It also passes `stepTitle: name`.
- `src/features/record/history/UndoToastHost.tsx`: `DECIDE_TOAST_LABEL` maps savedToast, renamedToast and removedToast to the new keys. The toasts keep their own words and their Undo.
