# Phase 05.3 Plan 84: Manage own options Summary

A quiet "Edit your own" link under the kind chips and the purpose choices opens a list of the user's own options; each can be renamed (a kind can also change what it counts like) or removed after a confirmation, each as one undoable save.

## Commits
- 1cc25d2f: model hook (rename, remove, setBase, itemRows) and pure `setOwnItemTypeBase`
- 8cf5d80a: OwnOptionsListSheet, EditOwnLink wiring, OwnOptionSheet prefill, copy, tests

## Notes
- The pure model lives in `src/features/decide/snapshot/v3/ownOptions.ts` (re-exported by `v3/model/ownOptions.ts`), so `setOwnItemTypeBase` was added there. Its tests are in `src/features/decide/v3/model/__tests__/ownOptions.test.ts`.
- `rename` takes an optional base so renaming and re-basing a kind are one save, one Undo step (two sequential saves would overwrite each other from the same stale row).
- Remove only sets `deletedAt` (today's local date); stored checks still show the name read-only, open checks fall back to General.
- Link is hidden when read-only or when no own option of that kind exists. Closing the list after a remove.
- Analytics: no events are emitted for these actions (the add path emits none either), so no names can leak.
