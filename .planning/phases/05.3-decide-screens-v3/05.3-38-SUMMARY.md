# Phase 05.3 Plan 38: Lower half of the answer screen Summary

Facts card, action bar with "Check another price" (D-19), the D-13 refund tile, the needs-input card (D-17) and the links, with D-11 proven.

## What was built
- `FactRows`: surface card, rows min 52 with 1px line1 separators. Figure rows use the figure rule (one line, shrink to 0.8) and stack under rule S; negatives are danger with a minus sign. Sentence rows are s13_5 inkDim, `quoted_differs` in warn1. The covered-by row shows its "based on your typical pace" sub-line. Params are formatted through `useV3Format` (money, months, dates, ids to names). The D-11 sentence comes from the model key, so no node holds "9999" (test walks every text node and a11y label).
- `AnswerActionBar({ result, row, onBought, onPlan, onNotBuying })`: two pills (min 48) with exactly one filled accent per the `actionBar` model, then "Not buying it" and "Check another price" as 44-high text buttons. Padding 12 / 16 / max(inset, 12), 1px line1 top border, canvas fill. Pills stack under rule S.
- `RefundHintTile({ show, row })`: one pressable element, a11y "With the refund, this could fit now. Check again. Starts a new check."; press reopens and opens `answerHref(newId)`.
- `NeedsInputCard`: bullet lines, "Help me check this" primary only when `helpOffered`, "Update my records instead" always.
- `AnswerLinks`: outlined accent 1.5 instead row (not for needs_input or band 1), whole-plan row when a total is passed, underlined ink worked-out link.

**2. Wording.** The plan test said "October left after this"; the shipped copy guard bans "left", so the row reads "October remaining after this".
**3. Extra file.** Added `AnswerLinks.test.tsx` (the plan lists no test file for AnswerLinks but its behaviours need one).
**4. Emergency fund "untouched" sub-line.** The model gives no sub for `emergency_untouched`; the UI adds the existing `factRow.untouched` key for that row.
**5. RNTL async.** `fireEvent` must be awaited in this RNTL version, otherwise overlapping act() leaks into the next test.
