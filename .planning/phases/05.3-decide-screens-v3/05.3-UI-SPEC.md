# Phase 05.3 — UI Design Contract (Decide screens v3)

> Visual and interaction contract. Generated by gsd-ui-researcher, to be verified by gsd-ui-checker.
>
> **This file extends `05.2-UI-SPEC.md` and `05-UI-SPEC.md` (and through them `03-UI-SPEC.md`); it does not replace them.** Anything not stated here is inherited unchanged: theme tokens, `space` / `size` / `radii`, the closed type scale, the `Sheet` engine, `ToastView` / `UndoToastHost`, the sync line, the FAB rules, reduced motion, the shipped Decide kit (`ChoiceCard`, `CheckRow`, `StateChip`, `WarningCard`, `LabelValueRow`, `SegmentedToggle`, `CustomValueChips`, `InfoButton`, `FigureStrip`, `MoneyInput`, `RateInput`, `ConfidenceChip`), the text-fit rules R6 of 05 (rules H, W, T, F, G, N, C, S, Seg, O, P, U, E) and the Decide copy guard (DCU-09).
>
> **Sources.** Decisions D-01..D-15 from `05.3-CONTEXT.md` (locked). Screens, numbers and layout from the Calm Ledger mockup (`Main.dc.html`, boards App01-App11 and Ans01-Ans09; Setup00-16 are 05.2 and out of scope). Answer wording from the shipped catalogue `decide.v3.*` in `src/i18n/locales/en.ts` (the engine copy contract). Judge precedence and codes from `00-UPGRADE-PLAN.md` §5.3. Bands and layers from `00-REBUILD-PLAN-v3.md` §5. Refine cards from `00-DECIDE-SETUP.md`.
>
> **Two precedence rules.** (1) **The build theme wins over the mockup.** Bold pairing (Archivo Black display, Archivo body), live accent (default green), 26 radius cards, 22 side padding, five-tab bar. Every mockup colour, size and radius outside the closed set is mapped to a token below. (2) **The shipped copy catalogue wins over mockup wording** for every answer code, notice, fact, missing item and readiness item (`decide.v3.verdict|notice|fact|missing|readiness.*`). The mockup supplies layout, order and figures only. Where the mockup words something the catalogue does not have, this file says so and lists it under "Open questions for the owner".
>
> **Platform note:** React Native / Expo SDK 57, no shadcn, no CSS. `StyleSheet` plus `useTheme()`, `textRole()`, `src/theme/*`. CLAUDE.md fidelity rule holds: **no new colour, gradient, shadow, type size, weight or icon set.** `noRawColours.test.ts` must keep passing. Glyphs (back chevron, check mark, sliders, chevron, card glyph) are hand-drawn `react-native-svg` shapes as elsewhere.

**Yardstick figures (Sam, October, day 18 of 31):** $4,000 in; $2,705 out so far; $870 still to come; **on track to leave $425**; typical month $425; low month (September) $50; unspent money $2,400; emergency fund $9,000; envelopes Holiday $1,500 and Car repairs $1,000; saved plans Sofa $4,000 and Used car $27,000 (6.9% over 60 months, $450 fees, running costs $390 a month). Examples in this file use them.

Mockup-to-role map: 52 to `netWorth`; 44 to `amountDisplay`; 30 / 27 / 26 to `heading` (the tab-root title is the shipped header); 24 / 22 / 20 to `heading` for figures and screen titles, `sheetTitle` for sheet titles; 17 / 16 to `sheetTitle`; 15 / 14 to `body` or `s13_5`; 13 to `label`; 12 to `meta`; 12 upper-case to `eyebrow`; 11 to `tabLabel`.

- **Scaling:** body and labels scale to 2x and wrap or stack. **Capped at 1.3x** (`maxFontSizeMultiplier`): `netWorth` and `amountDisplay` figures, the answer hero title, the plan total, funding-strip and month-bar figures, the three home figures.
- **Numbers never break across lines:** every currency figure goes through `useMoneyFormatter` and `heroAmountText` with `numberOfLines={1}` (rule N) and `adjustsFontSizeToFit` `minimumFontScale 0.8` for figures only; the label wraps, the figure does not. Counts and units join with U+00A0 in the catalogue (rule U): "{{months}} months", "{{rate}}% a year".
- **Stack rule (rule S, `shouldStack`)**: window under 360, text scale over 1.3, or (label/value rows) value longer than 16 characters. Every side-by-side pair in this file says what it becomes.

## Accessibility and quality rules

- **Fit (rules R6):** every screen and sheet is checked at **320 and 402 dp wide, font scale 1.0 and 2.0** (and the Pixel density matrix: `wm density` 430 / 540 plus `font_scale`), plus TalkBack driven through the `uinput` virtual touchscreen. Fixed bars stay visible at 2.0x; the body scrolls. Reflow table:

| Element | Default | Stacks / reflows under rule S |
|---|---|---|
| Item + Price | 3 : 2 row | each full width |
| Payment plan grid | 2 columns | 1 column |
| Three home figures | 3 columns | 3 full-width label / figure rows |
| Facts figure rows, plan rows, worked-out rows | label left, figure right | label above, figure below |
| Answer action bar | two buttons side by side | two full-width buttons |
| Not ready rows, refine card buttons | text left, button right / two buttons side by side | text above, full-width buttons |
| Purpose chips | 2 columns | 1 column |
| Years chips | 4 up | 2 x 2 |
| Six-month bars | 6 columns | 3 columns, then a list |
| Envelope tiles | 2 columns | 1 column |

- **No broken numbers:** all currency goes through `heroAmountText` / `useMoneyFormatter`, one line; the label wraps, the figure never splits. Tests at 2.0x assert the hero title amounts, the home figures, the facts figures, the plan figure and rows, the funding legend, tag chips and saved-plan prices.
- **TalkBack / VoiceOver:** every control is a real button, radio, checkbox, switch or input with a label; titles are headers and take focus on arrival; the hero is one polite live region (debounced); funding strip, month bar, mix bar and six-month chart have text equivalents (example above); the `AskCard` announces "Question {k} of {n}" and moves focus on each step; sheets trap focus and return it; toasts are polite with a focusable Undo; switches use `role=switch`; disabled Check announces its reason.
- **Touch targets:** 44 dp minimum (`hitSlop` for chips-in-rows and chevrons).
- **Contrast:** 4.5:1 for all text on the pairs listed above; the contrast unit test covers every answer tone; forbidden pairs listed above.
- **Reduced motion:** all entrances, the month bar and the funding strip collapse; nothing relies on motion.
- **Privacy:** no amounts or names in analytics or notifications; no screenshot block (D-09).
- **Data rules (UI-visible):** every write goes through the serial write queue, works offline, writes `undo_log`, bumps `version`, uses soft deletes, and has Undo.
