# Phase 05.3 Plan 30: How this was worked out Summary

The "How this was worked out" screen: the month line by line from workedModel over the home Evaluation, a six-month bar chart with a text equivalent, the regular payments counted, the assumptions and the legal footer.

## What was built
- Route `/decide/worked` -> `WorkedRoute` -> `V3Gate` -> `WorkedScreen`. The screen reads `useChecksV3().home/inputs`, builds a series-id -> name map from `useRecurringSeries` (never raw ids), and passes it to `workedModel`.
- Month table uses `LabelValueRow` (rule S stacking built in); deductions are prefixed with a minus; the pay row date goes through `useV3Format.date`. A 2px ink rule, then "{Month} on track to leave" in accent (danger with a minus when negative). A test asserts the figure equals monthLeft.
- `SixMonthBars`: pure `barHeights` (integer, proportional to |left|, 120 high, min 2). Normal months accent, negative danger, half/left-out months a dashed outline. The drawing is hidden from assistive tech; one accessible group reads "{Month}: {amount}, {state}" for each month. Six columns at 402/1.0, three over two rows under rule S (width < 360 or scale > 1.3), a plain visible list at scale >= 2.0. Fewer than six months show only those plus "Based on n months."
- Regular payments: confirmed by name and day, unconfirmed as "not confirmed, counted as everyday", empty text plus a "Confirm regular payments" pill that opens `/decide/setup?only=regular`.
- Assumptions (income, everyday, unspent, emergency fund, payment plans) and `legal.decideFooter`.

## Deviations from Plan
- [Rule 2 - copy] Added `worked.incomePay` and `worked.incomeRecords` to `decideV3Ui/worked.ts` to fill `{{summary}}` in "Income counted as ..."; no existing key supplied the words.
- The unspent assumption line is omitted when no unspent figure is confirmed, so Sam shows five lines and a user with no figure shows four.
- Deduction minus is drawn in the ink colour (via shared `LabelValueRow`), not inkDim; the row component has no dim tone. Cosmetic only.
- Chart month labels are the first three letters of the localized month name so six columns never wrap mid-word; the full name is in the accessibility label and the list.
- Regular rows read "around the {{day}}" with the bare day number (no ordinal), as the copy key gives it.
- The "assumeLeftOut" key is not rendered: the half-logged sentences under the chart already name those months.
