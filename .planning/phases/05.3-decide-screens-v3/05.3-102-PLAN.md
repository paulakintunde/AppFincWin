<objective>
Stop "Offline, will save" showing while the phone is online, and stop Check it from being ignored while writes are queued (UAT gap 22, major).

Root cause (verified in node_modules/@tanstack/query-core 5.103.2, build/modern/retryer.js and mutation.js): a mutation whose scope is busy cannot start (`canStart = canFetch(networkMode) && config.canRun()`, with `canRun: () => this.#mutationCache.canRun(this)`), so the retryer calls `pause()`, which dispatches `{ type: 'pause' }` and sets `state.isPaused = true`. Every write shares WRITE_SCOPE, so any draft save queued behind a slow or retrying write is "paused" while the phone is online. `saveStatusOf` in src/features/decide/v3/check/useV3CheckDraft.ts and `draftStatus` in src/features/decide/v3/model/draftStatus.ts map any paused save to 'offline', and `useCheckWritesSettled` (src/features/decide/v3/record/useCheckWritesSettled.ts) treats such a save as settled. The NetInfo side (a real false 'not reachable' from the Supabase probe in src/data/onlineManager.ts) is measured on the device by 05.3-103's recorder.
Output: a reproduction test, a shared queue-state helper, correct status words, and Check it working with a busy queue.
</objective>
