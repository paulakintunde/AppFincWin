<objective>
Make repeated reopen copies work on the client and make the failure path honest (UAT gap 21, blocker; the gap 23 reopen dates).

Root cause (verified): `useReopenCheck` (src/data/mutations/decideChecks.ts) always sets `reopenedFrom = row.id`; the unique index `decide_checks_reopened_once` refuses a second live copy (23505); `insertDecideCheck` (src/db/decideChecks.ts) then returns the existing live copy and `createCheck.onSuccess` records a redirect, but only the OLD `CheckFlowScreen` reads `useReopenRedirect`. The v3 AnswerScreen and CheckScreen do not, so the tried id never exists: Check again ends on `V3NotFound` ("This check isn't here"), and Check another price's draft save for the missing id parks a not-found failure ("The item was removed elsewhere..."). 05.3-98/99 drop the index; this plan fixes the client so it works before and after the push.
Output: redirect-following v3 screens, a copy-not-saved state, an honest failed-save reason, and a test of repeated copies.
</objective>
