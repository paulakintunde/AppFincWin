<objective>
Back's tab switch always reaches the visible tab bar (UAT gap 33, part: ignored presses).

Root cause (05.3-UAT.md round 3): TabBar.tsx:39-43 registers one shared switcher in BackHistoryProvider (`switcherRef.current = fn`) and clears it with `registerTabSwitcher(null)` on unmount. When the extra (tabs) from `router.navigate('/decide')` mounts, its TabBar takes the switcher; when it is popped, its clean-up sets null (or the ref is left pointing at the hidden navigator), so a later Back's `switchTab` drives the wrong navigator or falls back to `router.navigate('/' + tab)`, which pushes again. 05.3-114 stops the extra (tabs) being created; this plan makes the switcher safe if two tab bars ever overlap.
Output: owner-aware switcher registration and a two-tab-bar regression test.
</objective>
