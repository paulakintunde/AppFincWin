<objective>
Make History safe and accurate (UAT gap 26).

Root causes (verified):
- No back arrow: src/features/record/history/HistoryScreen.tsx renders `<Screen scroll>` with a plain title, not `DetailScreen`/`DetailHeader`.
- "Undoes 0 changes": the row hint is `rollbackRange(rows, row.id).stepIds.length` (src/engine/undo/history.ts), and `rollbackRange` stops at the first newer 'refused' step (`blockedBy`), which HistoryScreen ignores, so rows under a refused step show 0 and still offer the button.
- No refresh: `registerUndoMutations` in src/data/mutations/undo.ts invalidates the log only inside onSuccess branches 'undone'/'refused'/'blocked'; 'not-found', errors and a queued (paused) rollback leave the old list on screen.
- One tap undoes many: the row's Pressable calls `rollbackTo` directly.
- Unnamed failed entry: the rollback refusal path calls `recordRefusal(stepId, conflict, stepId)` with no label, so the parked entry has no name and reads only "Undo step".
Copy from 05.3-96: history.confirmTitle_one/_other, confirmBody, confirmAction_one/_other, keep, blocked, undoing.
