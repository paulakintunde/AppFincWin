# Phase 05.3 Plan 75: Last-day everyday rule Summary

On the last day of a month `erestOf` now returns 0, and so does the rough-figures branch, so no "Everyday still to come" is subtracted from remaining. Unspent money anchored on a last day uses the same function.

## Commits
- RED: `test(05.3-75): add failing tests for last-day erest` (4 failing as expected)
- GREEN: `feat(05.3-75): no everyday still to come on a month's last day`

## Changes
- `erestOf`: after the two RangeError guards, `if (day === daysInMonth) return minorUnits(0);`
- thisMonth rough branch: `day === n ? minorUnits(0) : ...`
- The I2 property test in `thisMonth.test.ts` now excludes day 31 from the "logged + erest >= E" floor guarantee (that guarantee is exactly what this rule removes on the last day). Retitled.
- Tests added for the behaviours in the plan. The unspent test is a regression guard: nothing can be logged after an anchor on the last day within that month, so `planned` there is unobservable through the rolled value. It asserts `erestOf(e,0,31,31) === 0` and that a November line rolls normally.
