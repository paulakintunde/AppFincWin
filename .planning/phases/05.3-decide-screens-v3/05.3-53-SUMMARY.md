# Phase 05.3 Plan 53: Decide home nudge below the main card (F9) Summary

On Decide home, the "New in your records" nudge (RefineCard) used to sit between the month card and the main card. It now comes after the check card or the not-ready card, so the main card follows the month card directly and stays above the fold at 402x1.0.

## What changed

- `HomeScreen.tsx`: the order is now SetupStatusCard, MonthBarCard, CheckCard (if ready), NotReadyCard, RefineCard, EnvelopeGrid, then the rest as before. The header comment is updated to match.
- `HomeScreen.test.tsx`: the stubs for the setup card, month card, refine card and envelopes now carry testIDs. The real CheckCard and NotReadyCard are wrapped in `check-card` and `not-ready-card` testID Views, and the wrapper renders nothing when the real NotReadyCard returns null. There are two new tests, for the ready and the not-ready state, that read the testIDs in render order. The existing full-order test now expects the check card before the refine card.
