# Phase 05.3 Plan 57: The asking not-ready card's view-model and copy Summary

notReadyGroups turns 05.3-54's named readiness items into month groups (oldest first, then one envelopes group). Each gap becomes a plain question with one-tap answer chips that map to exactly one action: markPaid, skip, a waiver, or open Activity / envelopes.

## What was built

- **notReady.ts**: `notReadyRows` and `NOT_READY_ORDER` are unchanged. New exports are `notReadyGroups`, `NOT_READY_ENVELOPE_NAMES` (3), `NotReadyAction` (the same union shape as 05.3-56's ReadinessAction), `NotReadyChip`, `NotReadyTitleParams`, `NotReadyItemView` and `NotReadyGroup`.
  - **Bills**: with a same-series lineId the chips are It was paid (markPaid), Someone else paid it (paid_by_other) and It didn’t happen (skip). Without a lineId they are I’ll record it (open activity), Someone else paid it and It didn’t happen (didnt_happen waiver). The link is Someone else always pays this (always_other).
  - **Pay**: It arrived (markPaid) or I’ll record it, then No pay this month (skip, or a no_pay waiver), then My money comes from elsewhere (income_elsewhere).
  - **Spending**: status `spending.last` with the date, or `spending.none` with the month. Chips are Open Activity and Nothing else to add (nothing_to_add { month, at: today }).
  - **Late start**: `lateStart.title` { month, date }, or `lateStart.titleNone` { month } when there is no date (W5). Chips are Start Decide from {{month}} (start_from { thisMonth }) and Open Activity.
  - **Envelopes** (D-54 exception, W10): one merged item, `item: null`, names (at most 3) plus `more`. The only chip is Open envelopes. There is no waiver and no month link.
  - **Month links**: past months get `monthCompletePast`, the current month gets `monthCompleteCurrent`. Both write month_complete { month, at: today } and carry `labelParams.month`.
  - **Fallback**: a not-ready Readiness without items gives code-only groups, one per notReadyRows row. Ready, empty or undefined gives [].
- Money stays MinorUnits and dates stay LocalDate / YearMonth. The card (05.3-58) formats them and joins `names`.
- **Copy** (`decideV3Ui/notReady.ts`): all strings use the plan's exact text. No guard flagged any string, so nothing was reworded.

## Deviations from Plan

None. The plan was executed as written. These are interpretations:

- **Envelopes with no names**: the plan does not cover this case. The title falls back to the existing `notReady.envelopes_unconfirmed` ('Link your envelopes') with no params, so the card never shows "Not linked to an account: " with nothing after it. Unnamed envelopes among named ones count in `more`.
- **Bill or pay without seriesId or date**: the engine always sets both. As a guard, such an item shows only its first chip and no link, so a waiver is never written for a blank series.
- **Code-only groups** have no month link. They exist only for fixtures without items.
- **Item key**: `kind|seriesId|date|month` (an empty string for null). The merged envelopes row uses 'envelopes' and code-only rows use the readiness code.
