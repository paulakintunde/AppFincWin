# Phase 05.3 Plan 50: Text cut off at large text sizes (F1, F2, F4, F5, F6) Summary

Header and sheet titles now wrap instead of ending in an ellipsis. Cancel never shrinks. The Emergency fund Save button sits below the scroll. On Activity, Refund is its own tag, and at 2x the figures drop under the text so the chips wrap between words.

## What changed

**Task 1: headers and the sheet header (F1, F2, F4)**
- `DetailHeader`: dropped `numberOfLines={1}` and added `minWidth: 0`. "How this was worked out" and "Check a purchase" now wrap.
- `CompactHeader`: dropped `numberOfLines={1}`. The title wraps and uses `scale="capped"`, the existing D-19 tier with a 1.3x maximum. This applies to the pinned home header and also to Activity's pinned header, which the screenshots showed as "Activity …".
- `SheetHeader`: the plain-title branch now gets `flexShrink: 1`. The row has a `gapMd` gap. The Cancel Pressable has `flexShrink: 0`, so Cancel is always whole and the title wraps.
- `useTabRootChrome.tsx` needed no change, because the fix lives in `CompactHeader`.

**Task 2: Emergency fund and Activity (F5, F6)**
- `EmergencyFundSheet`: the actions (Save and Remove) moved out of `SheetScroll` into a pinned `View` with `flexShrink: 0` and testID `emergency-fund-actions`. The scroll shrinks to the space the capped sheet leaves, so Save is always on screen.
- `ActivityRow`:
  - The ` · Refund` nested Text is gone from the one-line sub line. Refund is now a `Tag` with tone `refund`, an accent word, in the tags row.
  - The tags row wraps (`flexWrap: 'wrap'`).
  - Above font scale 1.3 the card becomes a column: the main press, then the figures, then the chips, each at full width.
- `RefundHintChip`, `IncomeTagChip`: added `maxWidth: '100%'`. No fixed width, so long labels wrap between words.

## Deviations from Plan

**1. [Rule 2 - Correctness] Activity rows stack their figures at large text sizes**
- **Found during:** Task 2
- **Issue:** The chips broke letter by letter because the text column was squeezed to about 50 dp at 2x by the amount column, which never shrinks. Moving Refund and setting chip widths alone could not fix that.
- **Fix:** Above `STACK_FONT_SCALE`, the row stacks: figures under the text, chips across the full card.
- **Files:** `src/features/record/activity/ActivityRow.tsx`

**2. The matrix test checks the refund hint chip's 44 dp target through its hitSlop, not `expectTargets`**
- The chip has no declared height: it is about 24 dp of content plus 10 + 10 slop, a design that predates this plan. The `expectTargets` helper counts only declared heights, so it can't measure this chip.
