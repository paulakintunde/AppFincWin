# Phase 05.3 Plan 83: Own kinds and purposes on Check a purchase Summary

A user's own item types and purposes now follow the presets on Check a purchase, and a "+ Your own" entry in each group opens a sheet to name a new one, saved with Undo and selected at once.

No settings row or no user gives `not_found` and no write. No analytics event was added (the typed catalogue has no entry for it, and the plan marked analytics optional).
