# Phase 05.3 Plan 115: Owner-aware tab switcher registration Summary

Back's tab switch now always reaches the tab bar on screen: `registerTabSwitcher(fn)` returns a release that removes only that tab bar's entry, and `goBack` uses the newest live switcher (falling back to `router.navigate` only when none is left). This closes the switcher part of UAT gap 33.

## What changed

- **BackHistoryProvider.tsx**: `switcherRef` (a single shared slot) is replaced by `switchersRef`, an ordered list of `{ fn }` entries. `registerTabSwitcher(fn: (tab: TabId) => void): () => void` appends an entry and returns an idempotent release that filters out that exact entry. In `goBack`, the `switchTab` branch calls the last entry, or `router.navigate('/' + tab)` if the list is empty. `NOOP_SWITCH_MS`, `markBackStep`, and the no-op check are unchanged.
- **TabBar.tsx**: `useEffect(() => registerTabSwitcher(fn), [navigation, registerTabSwitcher])`. The returned release is the clean-up. `registerTabSwitcher(null)` is gone.
- **Mocks**: `testUtils.tsx` and `useAndroidBackHandler.test.tsx` now use `jest.fn(() => () => undefined)`. `TabBar.a11y.test.tsx` checks that the returned release is called exactly once on unmount, replacing the old `toHaveBeenLastCalledWith(null)`.
