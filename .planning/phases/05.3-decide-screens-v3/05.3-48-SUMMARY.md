# Phase 05.3 Plan 48: Refund chip looks back 12 months Summary

The Activity "Refund of your {payee} purchase?" chip now matches purchases from the 12 months before the shown month, not only the rows loaded for it.

## Decisions
- The screen runs one TanStack Query read (`queryKeys.refundCandidates`, `fetchTransactionsInRange`) from 12 months before the first day of the shown month up to today. It is enabled only when `useDecideAccess().v3` and a household exist, and the list renders without waiting for it.
- It is a screen-level query rather than the picker's own query, because the picker's window depends on a specific refund anchor; the key shape and fetcher are the same.
- `hintPurchasePool` merges loaded rows with the window, one entry per id, purchases only. `refundHintFor` is unchanged, so all 05.3-35 rules hold (live, unlinked, same currency, same payee, most recent, nothing auto-links).
