```ts
// src/engine/decide/v3/month/dueDrops.ts (pure; no I/O, no clock)
export interface DueDrops {
  readonly alwaysOther: ReadonlySet<string>;              // series ids (D-31): every occurrence, every month
  readonly keys: ReadonlyMap<string, 'paid_by_other' | 'skipped'>; // dueKey `${seriesId}|${date}` -> why
  has(seriesId: string, date: LocalDate): 'paid_by_other' | 'always_other' | 'skipped' | null; // paid_by_other wins over always_other wins over skipped
}
export function dueDrops(inputs: Pick<V3Inputs, 'asOf' | 'series' | 'waivers' | 'skipped'>): DueDrops;
```
- Waivers dated after asOf are ignored. Only paid_by_other and always_other change figures. The other waiver kinds are readiness-only.
- A skip is resolved to its series' nearest occurrence within matchWindowDays(cadence, MATCH_DAYS) of the skip date: one occurrence, earlier date on a tie. A skip with no occurrence in its window, or for an unknown series, is ignored.
- "A recorded payment still wins" is applied at each call site, because only the site knows its paid lines: first settle against the paid lines, then drop only the unsettled dues for which `has()` is not null.
