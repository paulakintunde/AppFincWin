Rule. In thisMonth, before settle(), drop a due d when any of these holds:
- (i) a skipped occurrence has the same seriesId and is within that series' match window of d.date (nearest one only);
- (ii) a paid_by_other waiver has the same seriesId and date;
- (iii) an always_other waiver has the same seriesId;
and in every case, d is not settled by a paid line. To check that, run settle() once on all dues first and keep any due it settled.
Only (ii) and (iii) go into paidByOther, with amount = |d.amount|, name = series.name ?? null and by = 'paid_by_other' for (ii) or 'always_other' for (iii) ((ii) wins when both apply).
Add ThisMonthInput fields `skipped?: readonly SkippedOccurrence[]; waivers?: readonly ReadinessWaiver[]` (absent means none). model.ts passes `inputs.skipped` and `inputs.waivers`. Ignore waivers with a date after asOf.
