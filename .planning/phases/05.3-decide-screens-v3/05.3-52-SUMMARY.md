# Phase 05.3 Plan 52: Hints in empty money fields (F8) Summary

Empty money fields now show a muted zero amount as a hint, in the field's own currency and region format. These are the New pot fields (Target, Already saved, and Each month and Goal for a bucket), the Emergency fund fields (amount, mixed amount and goal) and the payment plan card fields (Down payment, Set-up and other fees, Fee with each payment and Fee at the end). The placeholder is now drawn in inkMuted, which passes the contrast guard, and screen readers still read only the field name.

## What changed

- `MoneyInput` has a new `zeroHint` prop. When no `placeholder` is given, the empty field hints `parser.toInputText(0, currency)`, which gives `0.00` for USD, `0,00` for EUR in de-DE and `0` for JPY. A given `placeholder` still wins. The field still reports `null`, and the hint is never a value.
- The light-tone `placeholderTextColor` changed from `inkFaint` to `inkMuted`. The 05.3-44 contrast test already records inkFaint below 4.5:1 on fill1, and inkMuted passing on canvas, surface, fill1 and fill6. The dark tone keeps inkSoft2.
- PaymentPlanCard already turns a zero or missing fee into `null` (the `money()` helper), so an empty or zero fee shows the hint and never a pre-filled `0.00`. A test covers typing 25 and then clearing the field.

## Tests

- New tests:
  - MoneyInput: USD hint, inkMuted colour, label unchanged, no accessibilityValue; de-DE EUR `0,00` and JPY `0`; a given placeholder wins; no hint without `zeroHint`.
  - PotSheet: Target and Already saved.
  - Emergency fund: Goal and A set amount.
  - PaymentPlanCard: fees and deposit, fee back to the hint after clearing, More fees fields.
- Plan verify set (pots, setup, v3/layers, ui, decide/__tests__, i18n, plus theme for the contrast guard): 90 suites passed, 1 skipped; 26425 tests passed, 1 skipped.
- `npm run typecheck`: clean. `npm run lint`: 0 errors. All 1226 warnings were already there; none are in the changed files.

## Deviations from Plan

- **No i18n copy added.** `en.ts` and `decideV3Ui/layers.ts` are listed in files_modified but were not changed. The hint is a formatted zero amount, which the plan's truths allow ("'0.00' in the home currency's format"), so there was no new copy for the copy guards to check.
- **Wider than listed (consistent, low risk).** The same hint was added to the bucket "Each month" field in PotSheet, the emergency fund amount and mixed-amount fields, and the payment plan Down payment and More fees fields. These sit next to the listed fields and showed the same empty state.
- **The colour change reaches every MoneyInput caller,** not only the F8 fields: any light-tone placeholder now uses inkMuted. No existing test asserted the old colour.

UnspentSheet.tsx was not touched. The DECIDE flags were not changed. STATE.md and ROADMAP.md were not edited.
