# Phase 05.3 Plan 31: Help me check this Summary

Route, shell body and screen for five rough figures, offered only when no month is fully recorded (D-17), saved to the rough_* settings through the queued settings write.

## What was built

- `helpOffered(inputs)` is `!inputs.months.some(m => m.full)`; tested for no months, partial months, a full month and rough set with no full month.
- `settingsPatch.ts` moved to `v3/shared`; `home/settingsPatch.ts` is a single re-export line (existing importers unchanged).
- `HelpRoute` (inside `V3Gate`) shows a skeleton until inputs exist, redirects to `answerHref(id)` when `helpOffered` is false, and otherwise renders `HelpScreen`. The app route validates the id with `isUuid` and shows `V3NotFound` otherwise.
- `HelpScreen`: title, intro, five boxed `MoneyInput` fields, "From your records" note when any field was filled from this month's paid lines, fixed bottom bar with "Check with these figures" (enabled when income or spending > 0) and "Update my records instead" (opens Activity). Save writes rough_income, rough_spending, rough_saving, rough_debt, rough_invest and rough_as_of (inputs.asOf) via `stampSettingsPatch`, fires `decide_help_used` with no properties once, then `router.back()`. Offline the write is queued by the existing paused-mutation path.
- Prefill (`prefillOf`): income = paid income/other_in lines, spent = paid spending/other_out less refunds, loan payments = paid debt_payment lines for the current month; saving and investing prefill only from earlier stored rough figures (V3Line cannot split them reliably). Stored rough figures fill any field the records leave empty.

## Deviations

- The plan said prefill from `month.moneyIn / billsPaid / everydayLogged`; V3Month has only lines, so the sums are computed from line roles (above).
- No new copy keys were needed (decide.v3.ui.help.* sufficed).
- Registering the route in the (app) layout Stack is left to 05.3-43.
