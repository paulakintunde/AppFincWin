<objective>
UAT gap (step 56, cosmetic): "Dates and times read naturally in the user's locale." On the device: "the sync banner shows '12:39 a.m.' for 12:39 pm; Activity shows ISO dates like '2026-10-29'."

Root cause 1 (ISO dates): Activity passes style 'short' to `formatter.formatDate(..., 'short')` (ActivityRow.tsx lines 179 and 391, GroupHeader.tsx 31, TransactionDetailSheet.tsx 140, useActivityViewModel.ts 340, import/importUi.tsx 30). `formatLocalDate` (src/engine/money/formatDate.ts) maps it to `Intl.DateTimeFormat(locale, { dateStyle: 'short' })`. CLDR's short date for the device locale en-CA is ISO `y-MM-dd`, so the Pixel shows "2026-10-29". The 'medium' style ("Oct 29, 2026" in en-CA and en-US, "29 Oct 2026" in en-GB) is what the walkthrough and the rest of the app use. Fix at the callers; the engine function and its tests stay unchanged.

Root cause 2 (a.m. for p.m.): `whenText` in src/ui/FailedWritesSheet.tsx calls `new Date(at).toLocaleString(undefined, { day, month, hour: 'numeric', minute: '2-digit' })`. On the device (Hermes Intl, locale passed as undefined) the day-period word for the 12 o'clock hour comes out as "a.m." although 12:39 is afternoon. Node's ICU does not reproduce it, so the fix must not depend on the runtime getting the 12 o'clock period right: compute the 12-hour value and pick the period word ourselves, taking the words from formatting a known morning time (09:00) and a known afternoon time (15:00), which are unambiguous. Use the device locale (useDeviceLocale) rather than `undefined`.

Output: caller changes, `clockText`, tests.
</objective>

```typescript
export interface DayPeriodWords { am: string; pm: string; twelveHour: boolean }
type Fmt = (d: Date) => Intl.DateTimeFormatPart[];
/** The locale's period words, read from 09:00 and 15:00 (never from the 12 o'clock hour), and whether it uses a 12-hour clock. */
export function dayPeriodWords(locale: string, parts: Fmt = (d) => new Intl.DateTimeFormat(locale, { hour: 'numeric', minute: '2-digit', timeZone: 'UTC' }).formatToParts(d)): DayPeriodWords
/** "12:39 p.m." / "12:39": hour and minute computed here; only the words and the clock type come from Intl. */
export function clockText(t: { hours: number; minutes: number }, locale: string, words: DayPeriodWords = dayPeriodWords(locale)): string
```
`dayPeriodWords`: format `Date.UTC(2026, 0, 1, 9, 0)` and `Date.UTC(2026, 0, 1, 15, 0)`; `am`/`pm` = the `dayPeriod` part values ('' when absent); `twelveHour` = both are non-empty.
