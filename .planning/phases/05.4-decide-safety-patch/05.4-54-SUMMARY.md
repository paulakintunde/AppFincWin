## The plain rule (plain.ts, no engine import)

`plainShortPlan(f)` is true only when all five of these hold:

1. It is a plan with no running cost.
2. Every payment date (`planDates`) falls before asOf + 90 days.
3. The plan's monthly figure is more than the usual month leaves. `plainPlanMonthly` gives that figure: the level payment, the annuity-due payment when the first payment is today, and x 26/12 for fortnightly payments.
4. The dated path stays at or above $0 once the money above the net's size is added (`planPathLow` + above). That path takes the deposit and fees on day 0 and each payment on its own date.
5. This month's room, earlier money and money above the net cover `plainPlanTotal`.

When it holds, the answer is the one-off answer for the whole cost. `plainTier` reads such a plan as a one-off with used = the whole cost (refinement a). `plainPath` now calls `plainPathFlows` with a single flow, so every existing caller gives the same numbers.
