## Sampling Rate

- **After every task commit:** `npx jest <touched folder> --silent` + `npm run typecheck`
- **After every plan wave:** full suite + `CROSSCHECK_RUNS=1000` cross-check + Stryker on changed files
- **Before `/gsd-verify-work`:** full suite green; nightly 20,000-case run green 3 nights in a row; Stryker full run ≥ 90% (`break: 90`); owner sign-offs recorded
- **Max feedback latency:** 30 seconds (quick run)
