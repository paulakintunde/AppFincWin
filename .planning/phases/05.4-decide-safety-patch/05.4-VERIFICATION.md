## Rules for the gap-closure plans (from 05.4-43 and D-172..D-178)

- Add or sharpen a test that fails on the mutant: table cases or unit asserts. Never loosen an expected value and
  never change engine behaviour to kill a mutant.
- An equivalent or harmless mutant gets `// Stryker disable next-line <Mutator>: <reason of 10+ chars>`, at most
  about 1 in 10 of a group's survivors, each with a real reason.
- Check locally per file with `npx stryker run stryker.part.config.mjs --force --ignoreStatic --mutate <file or file:a-b>`
  (FC_RUNS=10); the slow stretches (judge.ts, incomeProfile.ts, the cash path) are cut with `scripts/mutation-shards.mjs --only`.
- Engine purity holds: tests only, no imports from db/state/services/ui/react in engine code.
- After all five land: one full run (`mutation-full`, the workflow re-run with `only`/`with_run` if parts time out),
  then set `thresholds.break` to 90 in stryker.config.mjs (05.4-43 Task 2 end state).
