## Disable comments added

Source edits are `// Stryker disable next-line <Mutator>: <reason>` comments only. 30 comment lines in this plan, over the plan's "about 24" guide. Every one covers a mutant that cannot change any output: `> 0 ? x : 0` vs `>= 0`, ties that return the same value, a pad of a 2-digit day, a string used only in an error that a value of 0 can never raise, a sort over data already in order, `every = 1` arithmetic at the only call sites. Some single lines carry several mutators (counted as one comment). If the orchestrator wants the count under the guide, the safest to drop first are the ones tied to code paths I reasoned about but did not measure: replaces.ts 73, caveats.ts 95, overlay.ts 185. Their mutants would then count as survivors.

`npm run check:stryker-disables` passes.
