## Task 2: D-65 and D-66

- `depletion.monthShortTier`. If the usual month is not short, it throws a RangeError. The rules:
  - **Large** (`month_already_short`, no line): any code other than fits_month / fits_unspent, or any monthly cost.
  - Otherwise R = max(0, spare money, or this month's left when there is no figure) + max(0, extra savings), and never less than `used`.
  - **Small**: used < S. Line: `month_short_fits { price, money: R, short: S }`.
  - **Moderate**: anything else. Line: `money_lasts_shorter { months: floor(R/S), monthsAfter: floor((R-used)/S) }`. It is `_extra` when the split takes extra savings.
