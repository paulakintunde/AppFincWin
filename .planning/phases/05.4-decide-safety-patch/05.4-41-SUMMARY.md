## How it works (plain words)

- **What is locked (later):** decide.v3 and legal.decideAnswer, decideAbout and decideIntro (LOCKED_ROOTS).
  - The hash is sha256 of the sorted [key, text] pairs, so key order does not matter.
  - signRecord(en, date) builds both files for the day the owner signs. It refuses a date that is not YYYY-MM-DD.
- **The guard (wordingSignoff.test.ts), always on:**
  - Every owner-worded key is in en.ts and inside the locked groups.
  - The 48 plan-06 keys exist and sit outside the lock.
  - Every placeholder on the page has a sample value, so every string also reads as a sentence.
- **The guard, once a signed copy exists:**
  - The locked strings must match the hash and the signed copy. Otherwise the test fails with "Decide wording changed after sign-off: run npm run wording:page and get the owner's sign-off (D-15). Changed: <keys>".
  - Until then this check is a skipped test, never a failure (D-150).
  - I checked the lock by hand with a throwaway signed copy. It passes on matching wording, fails on one changed string and names that key. I then removed the throwaway files.
- **The page writer (wordingPage.write.test.ts, WORDING_WRITE=1 only):**
  - It reads the old en.ts with `git show` and converts it with typescript.transpileModule. No new package is used.
  - Strings in the locked groups are compared with the signed copy once it exists, otherwise with the merge base. The plan-06 lines are always compared with the merge base.
  - Each string is marked New, Changed (old shown) or Same, and filled with sample values.
  - Worked answers: one per code, variant and headline. The source is the 310 saved answers first, then the approved right-answer cases for headlines those never reach.
    - Each shows the headline, title and body (month and money-left are real; a figure marked * is a sample until the 08.1 screen fills it).
    - Then the after-you-buy and bought-on lines, any missing figures, the notices and facts in the app's words (sayLine), and the first caveat.
  - The page has no scripts and uses plain styles.
