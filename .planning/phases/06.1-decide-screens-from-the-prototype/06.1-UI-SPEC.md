# Phase 06.1 (Decide screens from the prototype) - UI Design Contract

> Visual and interaction contract. The design is LOCKED by the owner's clickable prototype (06.1-CONTEXT D-01, D-18). This file does not invent a design. It maps prototype screens D01..D53 and answer boards N02..N26 onto the app's tokens (`src/theme/*`), primitives (`src/ui/*`, `src/ui/Sheet.tsx`) and the engine's copy keys (`decide.v3.*`, `legal.decide*`). It follows the structure of `06-grow/06-UI-SPEC.md`. Prototype text is in `design/decide-spec.md` and `design/decide-screens.js`; example numbers in `design/LEDGER.md`.
>
> Precedence: on words and numbers the engine's copy keys win (D-18). On tokens this file wins. On behaviour 06.1-CONTEXT wins. On layout, sizes and flow the prototype wins.

| `stateMuted` | #5A564B | (on any tint above) | none | none | Secondary text sitting on a state tint |

Rules:

1. State colours appear only in badges, verdict cards and amounts (D-16). Never as a screen background, a button fill or a row fill.
2. Every use pairs the colour with its shape and a word (UX-09, 06-UI-SPEC "colour never the only signal"). A badge without the word is a defect.
3. Text in the `short` state uses #933720, not #B4472A. #B4472A on #F8E2DA is 4.36:1, below AA 4.5; #933720 on the same tint is 6.01:1. #B4472A is used only for the `sDown` glyph stroke and bar fills (non-text, needs 3:1).
4. Money going out is `ink`, never red (Grow rule); red is only for "short" on a verdict or a negative month, always with `sDown` and the word "short".
5. Grow may use the same tokens (D-16). Grow's use of `categorySwatch.blue` for the safety net (06-UI-SPEC OQ-2) is replaced by `net` when both phases are on main, so Grow and Decide agree; the planner adds that swap as a one-line task if Grow ships first.
