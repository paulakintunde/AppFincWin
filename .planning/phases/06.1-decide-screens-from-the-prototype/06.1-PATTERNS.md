### `bigBuy.ts` (utility, transform)

```typescript
export function bandOf(whole, t) {
  if (t.bandEdges.length === 0) return { band: 15, reasons: ['band_rate_missing'] };
  ...

  let count = 0;
```

## Shared Patterns

**Source:** `src/engine/decide/v3/index.ts` (barrel). **Apply to:** every file under `src/features/decide/**` and `src/data/**`. **Source:** `computeV3.ts` `preparedV3` (WeakMap keyed on `source`, 4 variants) and `judgeCheck`. **Apply to:** all answer, stepper and sheet previews (D40 date preview, D54, D55, D56). Hold `Prepared`; call `judgeCheck` per change.

**Source:** `useT()`; `decide.v3.*` and `legal.decide*` for answer sentences, `decide.screens.*` for screen-only text. **Apply to:** every Decide string. D-18: the engine key wins over prototype words; no inline strings (copy guards).

**Source:** `useMoneyFormatter` (`@/ui/money`), `useAmountParser`, `formatMoney`/`formatMoneyA11y`, `src/engine/time`, `v3/dates`, `currencyCode`/`minorUnits` from `@/engine/money`. **Apply to:** all amounts; integer minor units, no floats, no `Date` arithmetic.

### Theme, layout, a11y
**Source:** `useTheme()`, `textRole(pairing, role)`, `fontSize`, `radii`/`space`/`size`/`useScreenInsets` (`src/theme/layout.ts`), `touchMin` 44, `Text` with `scale="capped"` for badges, `useSettledLabel` (move out of `check/` before deleting it, it is the D-56 debounced live-region).

### Queued writes with one Undo
**Source:** `decideSetup.ts`/`decideGoAhead.ts` (guardSession, writeRetryDelay, recordFailedWrite, `newStepId`, `showToast` with Undo). **Apply to:** every Decide write (flags, safety-net answer, Save for it, bought).

`home/settingsPatch.ts` (used by `data/mutations/accountUse.ts`, `decideSetup.ts`); `setup/steps/types.ts` (used by `features/income/IncomeProfileSteps.tsx`); `notifications/waitReminder` (used by `decideGoAhead`, `decideOutcome`); `perf/perfMarks` (devHarness); `shadow/DecideShadowHost` (tabs layout); `check/useSettledLabel`.
