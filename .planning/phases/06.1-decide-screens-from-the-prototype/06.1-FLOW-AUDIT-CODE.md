## 1. Buttons and taps

Shared facts behind several rows:
- `space.touchMin` is **44** (`src/theme/layout.ts:32`). Every Decide Pill, Chip, row and link uses it, so no control reaches Android's 48 dp. Only the stepper and checklist Back chevrons add `hitSlop`.
- `Pill` (`src/ui/Pill.tsx:40-48`), `Chip` and `SegmentedControl` have no pressed style and no `android_ripple`. Pressed feedback exists only on a few home rows and sheets (`OpenCheckSheet`, `SetupBanner`, `MoneyRulesCard`, etc.).
- Plan 51 measured on the Pixel 6: Check it to answer 2.6 s, stepper Next 4.3 s, setup Pay 3.6 s, write settled 11.7 s. During those times a tap gets no visible response.
- `Screen` passes `keyboardShouldPersistTaps="handled"` only with `form` (`src/ui/Screen.tsx:39`). `TabRootScreen` (`src/shell/screen/TabRootScreen.tsx:27`) and `DetailScreen` (`src/shell/screen/DetailScreen.tsx:32`) never pass it, so they use the default `"never"`. Sheets use `"handled"` (`src/ui/Sheet.tsx:477`). The stepper and the setup items use `Screen scroll form`, so they are fine.
