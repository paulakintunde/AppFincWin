## Deviations from Plan

1. **[Rule 1 - Bug] furthest_step alone would always resume at step 1.** The stepper saves `furthest_step: current.furthest_step`, so
   the column stays at the create value (1). editTarget reads the stepper's own `L0.visited_steps` with furthest_step and
   firstStepFor. Fixing the stepper's write is outside this plan's files (check/useStepCheck.ts); flagged for 06.1-58/78.
2. **[Rule 1] C-14 needs a pressable Use.** "Shows after Use is tried" cannot happen on a disabled Pill, so a missing length no
   longer disables Use; the press shows the note and writes nothing. The old test "keeps Use this plan disabled until a length is
   chosen" was replaced by the C-14 tests.
3. **Key placement.** The how-often key sits under the existing `often` group (`sheetsInput.often.need.endBeforeStart`), not a new
   `howOften` group. The Sale sheet has no name field, so it uses `sheetsCosts.need.amount`; an own kind needs only a name, so it uses
   `sheetsCosts.need.name`. The plan named these keys as "existing placeholders"; none existed, so all were added.
4. **payChosen.once not added.** The open-check sheet's only pay choice is the installment plan sheet; there is no cash choice to
   toast, so the unreachable string was left out.
5. **No Undo on the plan toast** (stepId null): useSaveCheckDraft has no undo step and the data layer is outside this plan.
6. **C-22 landed in the Task 3 commit**, not Task 2: both live in OpenCheckSheet.tsx and share the new test file.
7. **Test-only:** OpenCheckSheet now imports check/useStepCheck (stepHref, firstStepFor), which sits beside read hooks, so the new
   test stubs those reads. No runtime change.
