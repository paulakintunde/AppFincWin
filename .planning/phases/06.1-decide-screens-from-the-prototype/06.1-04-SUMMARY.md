# Phase 06.1 Plan 04: Decide screen logic helpers Summary

Three pure screen-layer rules in the new folder `src/features/decide/screens/logic/`, each with 100% coverage. The first maps each engine row to one of seven state tones and a glyph. The second is the D-09 big-buy rule, which reads the engine's band-6 edge through `bandOf` and `homeThresholds`. The third is the D-02 kind and home word reader.

Owner questions: none. D-02, D-09, D-16 and the UI-SPEC "Tone to state mapping" table already answer everything this plan touches.

## What was built

- **stateForVerdict(code, variant)** returns `{ tone, glyph }` and follows the UI-SPEC table:
  - The lookup is a frozen table keyed `code` or `code.variant`.
  - Any `month_already_short` variant gives Short.
  - A variant with no row of its own takes the tone of its code's base row in VERDICT_TABLE.
  - A code the screens do not know yet gives notYet.
  - `STATE_GLYPH` gives each of the seven states its own symbol (UX-09).
  - The test loops over `Object.keys(VERDICT_TABLE)`. Every row must have a state, a glyph and a non-empty chip key from `verdictRowFor`.
  - CMP-F14: no row with month_already_short, no_net, small_net or fits_uses_net shows as plain `fits`.
- **isLargePrice / isBigBuy (D-09):**
  - A price is large when it is in band 6 or above. Band 15 (no edges for the currency) counts as large.
  - Tests read the edge from `homeThresholds` for USD, GBP, EUR and JPY, and for a currency off the table with a given rate. The code never uses a literal 5000.
  - US$5,000 (500,000 minor units) is not large. 500,001 is.
  - `isBigBuy` is true for a car or home kind, a purchase paid over time, or a large price.
- **kindWords (D-02):**
  - Exports `readKind`, `isHomeWords` and `readsAsPlan`, plus frozen tables `CAR_WORDS`, `HOME_WORDS`, `HOME_EXCEPTIONS`, `TECH_WORDS` and `PLAN_WORDS`.
  - Matching is case-insensitive on whole words. Plan phrases such as "on a plan" match as runs of whole words, so "on a planet" does not match.
  - A home word followed by an exception word ("home theatre", "house plant") is not a home. `readKind` checks for a home first.
- **jest.config.js:** added `// 06.1: pure Decide screen rules`, which sets FULL thresholds on `./src/features/decide/screens/logic/`.
