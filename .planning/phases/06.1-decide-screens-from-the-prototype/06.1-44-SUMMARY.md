# Phase 06.1 Plan 44: Not ready card names each item (G-1 part 2) Summary

The Not ready card now starts with one short line, "Not ready yet: N things to finish". Below it, every readiness item the engine names gets its own row. Each row has one sentence (for example "Netflix, $11.99 due Oct 3, 2026, isn't in your records yet."), one fix link and the answers the engine accepts. Tapping an answer saves a readiness waiver dated today, or skips the pending line, with one Undo. The answer screen then judges again from the cache and stays where it is. "Answer from quick estimates" appears only when estimates can count, which means a person with no earlier month. For that person it is the main button. A person with records is never offered it, so the F-1 loop is closed. An envelope row offers only "Which account?", which opens EnvelopeAccountSheet (D-54). A not-ready result still shows no verdict, no figure lead and no action bar (D-52).
