# Phase 06.1 Plan 11: Engine hooks Summary

One engine hook for every screen: `useCheckEngine` judges on the Prepared that `useDecideV3` already built, so a price keystroke re-runs only `judgeCheck`; `useMonthPicture` gives the picture and past bars from the same Prepared.

## What was done
- `useDecideV3` now exposes `prepared` (same object `preparedV3` cached). Existing fields and tests unchanged.
- `useCheckEngine` memoises evaluation on (prepared, check identity); a check with quick lines goes through `judgeWithQuickLines` (plan 09, D-21), otherwise `judgeCheck`. The saved D-48 volatile-cover answer is applied when `opts.checkId` is given, as `computeV3` does. The Evaluation is held in memory only, never in a query cache.
- Tests (8 new): per-keystroke judge once with no re-prepare, quick-line routing, home kind never judged, offline cached read is ready (APP-01), network error is kind `network` and never not-found (APP-10), month picture and loading state.
