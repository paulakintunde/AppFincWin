Decisions taken here (Claude's discretion, per the audit's "the plan picks one"):
- Targets: keep `space.touchMin = 44` (the owner's prototype rule says 44 px targets, and raising it would shift every row and the
  text-fit matrix). Add `LINK_HIT_SLOP = { top: 4, bottom: 4, left: 12, right: 12 }` in pressFeedback.ts so a 44 dp link reaches 52 dp
  tall. Neighbouring links (AnswerTopBar Back at the left, New check at the right) must not overlap their slop regions.
- Ripple colour: an existing theme token (`colors.fill6` on light surfaces, `colors.surface` at low alpha is NOT allowed: no new colours).
  `android_ripple: { color: <token>, borderless: false, foreground: true }`. iOS: `opacity: pressed ? PRESSED_OPACITY : 1`.
