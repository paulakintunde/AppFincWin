The big-buy stepper now shows where you are and what you chose (named segments with tappable "✓ Kind: Car" / "✓ Price: $10,020" crumbs, display-face titles). The Android in-app edge swipe on a step now follows the stepper Back rule.

## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Plan name key needs a layer prefix**
- **Found during:** Task 3
- **Issue:** the plan said `layerAnswers['plan_name']`, but `inputsV2.layerAnswersOf` drops any key without a layer prefix, so the name would vanish on the next read.
- **Fix:** `KEY_PLAN_NAME = 'L0.plan_name'` in `check/planName.ts` with `withPlanName`; 06.1-68 is told in deferred-items.md.
- **Commit:** 74481ad1

**2. [Rule 1 - Bug] Boxed fields were invisible on the page**
- **Found during:** Task 2 (A-ST-1 cause)
- **Issue:** the field fill (`fill6`) and the page tone (`canvas`) are the same colour, so the tax box had no visible edge.
- **Fix:** the Price step groups sit in white cards as in the prototype (`cardP`), so the fill shows.
- **Commit:** 74481ad1

**3. [Rule 3 - Reuse] Existing copy keys reused instead of new ones**
- Dealer and trade-in rows use the existing `stepper.price.dealerFees` ("Dealer and documentation fees"), `tradeIn` ("Trade-in value") and `tradeInSub`, which match the D12 spec. Pay sub-lines use the existing `cashUpFront` ("{{amount}} up front") and `installmentsSummary` ("{{amount}} down · {{monthly}} a month") rather than new keys with "/mo". The plan sheet uses the existing `sheetsInput.plan.name`. No `stepper.segment.*`, `stepper.price.payOnce/payPlan.sub` or `stepper.price.oneOff.*` keys were added.

**4. [Rule 2] Swipe interceptor (routed in from 06.1-64)**
- StepFrame registers `setSwipeBackInterceptor` alongside the BackHandler while focused; release on blur/unmount. Tests cover forward path and from=answer.

**5. Scope notes**
- `sheetUi.tsx` (not in files_modified) got optional `suffix` and `selectTextOnFocus` props on `Field`; no other caller changes.
- Up front card: DS-18 takes priority over "tax row even when 0". With nothing added only the total shows; with no region a "Tax not added" line shows under the card.
- Plan chips: `other` and `car` are 12/24/36/48; laptop/camera/headphones/phone keep their shorter sets (a 3- or 6-month plan is common there).
- The trade-in row is a button to SaleSheet (writes `replaces.sale`, the same sale step 3 shows), with an Undo toast like step 3. It is not added to the Up front card figures (the engine nets the sale itself).
