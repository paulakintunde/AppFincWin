# Phase 06.1 Plan 45: Records agrees with readiness (G-1 part 3) Summary

The setup checklist and the answer screen now agree. Records is done only when the D-11 rule holds and the engine names no open readiness item. The Records page lists every open item by name, with the same fix and answers as the Not ready card. Save and close with items still open says "Records still open: N to finish." Every open checklist row now says why it is open.

## What changed

- `SetupFacts` gained `readinessOpen` and `readinessFirst`. `setupFactsFrom(..., readinessItems)` fills them, and `useSetupFacts` passes `evaluation?.result.readiness?.items ?? []`.
- `recordsItem`: done = D-11 && `readinessOpen === 0`. With open items the status is `recordsOpenItems` `{ count, asOf }` with `first` set to the item. Without open items it is the old `recordsOpen` `{ date }`.
- `billsItem` open: `billsOpen` `{ count }` ("3 bills to confirm"), or `billsNone` ("No bills found yet"). `rulesItem` open: `rulesOpen` ("No rules set yet"). The pay item is unchanged (plan 54 handles it).
- `useSetupText`: `recordsOpenItems` renders "N to finish". If a first item exists, a second line follows with that item's Not ready sentence, built with `itemSentence` from ReadinessFixList and the same keys.
- RecordsSetup: under the three checks there is a "What’s still open" group. It starts with "Envelopes and goals: N not linked" when envelopes are open, then shows ReadinessFixList.
  - An answer saves `readiness_waiver` dated today.
  - "It didn't happen" skips the cached pending line through `writes.skipLine`, or falls back to the didnt_happen / no_pay waiver.
  - Each answer shows one "Answer saved." toast with Undo.
  - A records fix pushes `/activity`. An envelope fix opens EnvelopeAccountSheet.
  - The primary label is "Done" only when the checks hold and the list is empty.
  - Save and close (primary and top-right) shows the stillOpen toast when items are open, then leaves. `leave` itself is unchanged.
- The brand-new "No records yet" variant is unchanged (tested).
