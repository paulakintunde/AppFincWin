<objective>
Build the three Everyday (level 2) sections of the Insights tab as presentational components over one shared Prepared input, plus a thin pure model that calls the engine.

Purpose: INS-02, INS-03, INS-04, INS-05 per D-12..D-15, D-21 and D-24; figures agree with Decide by construction (same Prepared, same monthBars rule).

Which parts are charts (D-24 chart colour applies): the InOutBars chart, the Left each month SignedBars chart, and the thin bar under each category row (CategoryRow's ProgressBar). Everything else here is non-chart UI and keeps the normal colour rule: section titles, StatTiles (state colour only via the StatTile status glyph + word), month chips, the change rows in This month against last (glyph + word in inkDim, never red or green, T-07-28), notes and EmptyStates.
Output: `model/everyday.ts`, `MoneyInOutSection`, `WhereItWentSection`, `MonthAgainstLastSection`, tests.
</objective>
