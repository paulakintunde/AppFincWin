  <behavior>
    Helper `dec(id, estimate: [dayOne, monthly, running], actual: [dayOne | null, monthly | null, running | null])` builds a USD PastDecision.
    - fewer than 3 usable decisions → every figure has biasBasisPoints null; decisionsUsed reports the count (0, 1 or 2)
    - running costs: estimates 10_000 ×3, actuals 12_000 ×3 → running_costs { decisionsUsed: 3, biasBasisPoints: 2_000 } (20% higher)
    - actuals 8_000 ×3 → −2_000 (lower; signed)
    - mixed: estimates [10_000, 20_000, 5_000], actuals [11_000, 18_000, 5_500] → per-decision [1_000, −1_000, 1_000] → divideHalfUp(1_000, 3) === 333
    - an average of ratios, not a ratio of sums: estimates [1_000, 100_000, 100_000], actuals [2_000, 100_000, 100_000] → 3_333 (a ratio of sums would give about 100); the test states both numbers
    - an actual of null is left out; an estimate of 0 is left out (no ratio exists); both shrink decisionsUsed, and 2 usable of 4 decisions → null
    - a negative estimate is measured against its magnitude: running estimate −5_000, actual −4_000 (three such) → (−4_000 − −5_000) × 10_000 ÷ 5_000 = 2_000
    - per-decision half-up: estimate 3, actual 4 → divideHalfUp(1 × 10_000, 3) = 3_333; estimate 3, actual 2 → −3_333 (symmetric)
    - the three figures are independent: decisions with only running-cost actuals give day_one and monthly_payment null
    - the result order is ['day_one', 'monthly_payment', 'running_costs']
    - a decision in CAD when asked for USD → RangeError /^estimateBias: mixed currencies/; a non-integer amount → RangeError /^estimateBias: /
    - property (fast-check): if every actual equals its estimate (estimates non-zero, ≥ 3 decisions) every bias is 0; and scaling all estimates and actuals by the same positive integer leaves each bias unchanged within 1 basis point
  </behavior>
