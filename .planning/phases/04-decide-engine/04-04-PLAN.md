Implement exactly this loop (all bigint; `D = MONTHLY_RATE_DENOMINATOR`):
```
if balance < 0 → RangeError('simulateMinimum: balance must be >= 0')
bal = BigInt(balance); if bal === 0n → cleared {months 0, firstPayment 0, totalInterest 0, remainingBalance 0}
month = 0; totalInterest = 0n; first: bigint | null = null
while (bal > 0n) {
  if (month === SIMULATION_MONTH_CAP) return { outcome: 'exceeds_month_cap', months: SIMULATION_MONTH_CAP, firstPayment: first!, totalInterest, remainingBalance: bal }
  interest   = divideHalfUp(bal * apr, D)
  percentPart = divideHalfUp(bal * terms.minimumPercent, ONE_HUNDRED_PERCENT)
  base       = terms.interestAdded ? percentPart + interest : percentPart
  scheduled  = base > floor ? base : floor
  due        = bal + interest
  paid       = scheduled < due ? scheduled : due
  if (first === null) first = paid
  month += 1
  // D-17: explicit, per-month check, independent of the cap
  if (paid <= interest) return { outcome: 'never_clears', months: month, firstPayment: first, totalInterest: null, remainingBalance: bal }
  totalInterest += interest; bal = due - paid
}
return { outcome: 'cleared', months: month, firstPayment: first!, totalInterest, remainingBalance: 0 }
```
Convert every returned bigint with `minorFromBigInt(x, 'simulateMinimum')`.
