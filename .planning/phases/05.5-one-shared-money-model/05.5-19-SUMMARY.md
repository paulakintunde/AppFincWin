## Deviations from Plan
1. **[Rule 3 - blocking] Source types moved to `sourceTypes.ts`.** Plan 05.5-26 had left them in `buildSnapshot.ts` to be deleted here; 30 files import them, so they needed a new home.
2. **[Rule 1] I28 back-test no longer compares against the old engine.** `backtest.ts` used `oldAnswer` (toOld). The "false fits never above legacy" rules are replaced by the existing absolute ceiling (D-40, at most 25 in 100 fits false) applied to every family and overall. Passes. The comparison cannot exist without the old engine.
3. **Changed-answers test deleted.** `changedAnswers.test.ts` ran each fixture through old and new builders; with the old builder gone it cannot run. `changedAnswers.json` (the owner's approval record, 16 rows, all approved) stays in place as the record. Nothing reads it now.
4. **`legacyBaseline.test.ts` deleted** (it only checked the old-engine adapter mapped each scenario). `legacy-answers.json` deleted; `legacy-v1-inputs.json` stays (still used by adapters tests).
5. `planCard.test.ts` compared `salesTaxOf` with the deleted `salesTaxAmount`; replaced by fixed values and a range property.
6. `snapshotFixtures.ts` rewritten to the small `CurrencyBasis` the currency view reads (the old DecideSnapshot builders went with the engine).
