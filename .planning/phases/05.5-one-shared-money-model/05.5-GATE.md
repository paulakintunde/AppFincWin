## The 06.1 gate (D-02)

Run in the 05.5 worktree (Git Bash, `export MSYS_NO_PATHCONV=1`):

1. `git fetch origin`
2. `gh pr view 102 --json state -q .state` prints `MERGED`.
3. `grep -c "^06.1_SHIPPED:" .planning/phases/05.5-one-shared-money-model/05.5-PRECONDITIONS.md` prints 1 or more. The owner (or the orchestrator, on the owner's word) writes that line, `06.1_SHIPPED: <date> <OTA update id or preview build id>`, once the 06.1 release is on testers' phones.
4. The 05.5 branch contains merged main: `git merge-base --is-ancestor origin/main HEAD` exits 0. If not, merge `origin/main` into this worktree's branch only (never another worktree); on conflict, `git merge --abort` and stop.
5. For the plan's own `files_modified`, run `git log --oneline -3 origin/main -- <each file>` and re-read any file that changed since 2026-11-13 before editing it.

If 2, 3 or 4 fails: write `GATE_06.1_<plan id>_<YYYY-MM-DD>: not met (<which step>)` to the plan's own gate file `.planning/phases/05.5-one-shared-money-model/gates/<plan id>.gate` (one file per plan, so parallel plans never edit the same file), make no other edit, and end the plan with "gate not met". If all pass, write `GATE_06.1_<plan id>_<YYYY-MM-DD>: met` there. `05.5-PRECONDITIONS.md` holds only owner and release lines (`06.1_SHIPPED`, `05.5_RELEASE_SHAPE`, `05.5_RELEASED`, `BAND_B_*`, `CARRIED_*`).
