<feature>
  <name>Per-sentence copy guard</name>
  <files>src/i18n/copyGuard/*, src/i18n/__tests__/copyGuard.test.ts, src/i18n/__tests__/copyGuardRelease.test.ts</files>
  <behavior>
    - splitSentences('It fits. You have {{amount}} left!') -> ['It fits.', 'You have {{amount}} left!']; a decimal like '1.5%' does not split; an empty string -> [].
    - checkSentence('decide.v3.answer', 'You should wait.') -> one violation { rule: 'banned:you should', set: 'decide' }.
    - checkSentence('decide.v3.answer', 'This does not give advice.') -> violation 'banned:advice' (negated disclaimers are allowlisted entries, never silently passed).
    - checkSentence('grow.goals.x', 'The optimal plan.') -> violation 'banned:optimal' (grow set).
    - checkSentence('decide.v3.x', a 26-word sentence) -> 'limit:words'; a sentence with 4 numbers (digits or numeric placeholders such as {{amount}}) -> 'limit:numbers'; {{account}}, {{month}} and the other NOT_A_NUMBER placeholders do not count.
    - checkSentence('activity.list.empty', 'Nothing yet.') -> [] (general set has only /you should/, /recommend/, /we suggest/).
    - checkString(path, value) runs checkSentence over splitSentences(value) and tags each violation with { path, sentence, hash: hashSentence(sentence) }.
    - hashSentence is FNV-1a 32-bit over the sentence, hex, 8 chars; stable across runs.
    - isAllowed(violation, allowlist) true only when an entry matches path, hash and rule.
    - Stale entry: an allowlist entry that matches no current violation is reported by `staleEntries(violations, allowlist)`.
  </behavior>
  <implementation>
    rules.json: `{ "sets": [ { "name": "decide", "prefixes": ["decide.", "income.", "activity.incomeCard", "activity.incomeTag", "activity.refund", "legal.decide"], "banned": [<BANNED and V3_BANNED regex sources as strings with flags "i">], "limits": { "prefixes": ["decide.v3", "decide.screens", "legal.decide"], "maxWords": 25, "maxNumbers": 3 } }, { "name": "grow", "prefixes": ["grow."], "banned": ["\\b(advice|advise|recommend\\w*|should|best|better|optimal)\\b"] }, { "name": "general", "prefixes": [""], "banned": ["you should", "recommend", "we suggest"] } ], "notANumber": { <copied from decideSentences.test.ts> } }`. The first set whose prefix matches the path wins; "general" catches the rest.
    guard.cjs: plain CommonJS (`'use strict'; module.exports = { splitSentences, checkSentence, checkString, isAllowed, staleEntries, hashSentence }`), requires `./rules.json`, compiles regexes once. guard.d.cts: hand-written types (`export interface Violation { path: string; sentence: string; hash: string; rule: string; set: string }`, `export interface AllowEntry { path: string; sentenceHash: string; rule: string; dated: string; reason: string }`, function signatures). TypeScript callers import `'../copyGuard/guard.cjs'`. If `npm run typecheck` cannot resolve the `.cjs` import, add a `src/i18n/copyGuard/index.ts` that does `// eslint-disable-next-line @typescript-eslint/no-require-imports` `const g = require('./guard.cjs') as typeof import('./guard.cjs');` and re-exports, and record that in the SUMMARY.
    allowlist.json: `{ "dated": "2026-11-13", "emptyBy": "before any public release (CMP-F09)", "entries": [] }`.
    eslintRule.cjs: ESLint 9 rule object `{ meta: { type: 'problem', schema: [{ type: 'object', properties: { allowlist: { type: 'string' } } }], messages: { copy: '{{rule}} in "{{sentence}}" at {{path}} (05.5 copy guard; rewrite through owner wording sign-off or add a dated allowlist entry)' } }, create(context) { ... } }`. It visits `Property` nodes whose value is a `Literal` string or a `TemplateLiteral` with no expressions, builds the dotted key path by walking up parent `Property` keys of nested `ObjectExpression`s (root object of the default export), calls `checkString`, skips `isAllowed` hits, and reports the rest on the value node.
  </implementation>
</feature>
