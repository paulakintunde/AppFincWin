## Sampling Rate

- **After every task commit:** touched-folder jest plus `npm run lint` and `npm run typecheck` (no full local coverage per plan).
- **After every plan wave:** `npm run test:coverage`, `npm run depcruise`, `npm run verify:gates`, `npm run check:cache-version`, and `npm run lint:migrations` when migrations change.
- **Before `/gsd-verify-work`:** full CI green; 05.4-43 (mutation 90%) and 05.4-45 (three green nightlies) satisfied; reviewed-diff approved by owner; first green Maestro nightly; `supabase test db` green.
- **Max feedback latency:** 120 seconds for the quick command.
