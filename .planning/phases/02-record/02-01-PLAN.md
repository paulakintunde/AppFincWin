Exports (exact names):
```typescript
export const RECURRING_FREQS = ['weekly', 'fortnightly', 'monthly', 'quarterly', 'yearly'] as const;
export type RecurringFreq = (typeof RECURRING_FREQS)[number];
export interface RecurringSchedule {
  anchorDate: string;            // first occurrence, 'YYYY-MM-DD'
  freq: RecurringFreq;
  endDate: string | null;        // inclusive
  occurrenceCount: number | null; // occurrences n = 0 .. count-1
}
export const MAX_OCCURRENCES_PER_CALL = 1000;
export function isRecurringFreq(s: string): s is RecurringFreq;
export function daysInMonth(year: number, month: number): number; // month 1-12
export function occurrenceDate(anchorDate: string, freq: RecurringFreq, n: number): string;
export function occurrencesBetween(schedule: RecurringSchedule, fromInclusive: string, toInclusive: string): { n: number; date: string }[];
export function materialisationHorizon(today: string): string; // last day of the month after today's month (D-03)
export function projectOccurrences(schedule: RecurringSchedule, month: string, afterExclusive: string | null): string[];
```
Implementation rules:
- Validate every date input with `isValidLocalDate` and throw `RangeError` naming the function and the bad value; validate `n` with `Number.isInteger(n) && n >= 0`; validate freq with `isRecurringFreq`.
- Day-based freqs: parse Y/M/D, use `Date.UTC(y, m-1, d + stepDays*n)` and read back with `getUTCFullYear/Month/Date` (UTC only, so no local-zone dependency), format zero-padded.
- Month-based freqs: months = n * {monthly:1, quarterly:3, yearly:12}; total = (m - 1) + months; y2 = y + Math.floor(total / 12); m2 = (total % 12) + 1; d2 = Math.min(d, daysInMonth(y2, m2)).
- `occurrencesBetween`: iterate n from 0 while n < (occurrenceCount ?? Infinity) and results < MAX_OCCURRENCES_PER_CALL; stop once date > toInclusive or (endDate && date > endDate); skip dates < fromInclusive. For day-based freqs, start n at `max(0, floor(daysBetween(anchor, from) / stepDays))` rather than 0 so a distant `from` does not loop from the anchor; for month-based, start at `max(0, monthsBetween(anchor, from) - 1)`.
- `materialisationHorizon`: take today's year/month, add 2 months to the first of the month, subtract one day (use the same UTC arithmetic).
- `projectOccurrences`: `monthRange(month)` gives start/endExclusive; return occurrencesBetween(schedule, start, day before endExclusive) dates filtered to `date > afterExclusive` when afterExclusive is non-null.
