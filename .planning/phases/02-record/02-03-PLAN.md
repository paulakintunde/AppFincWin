```typescript
export type ColumnRole = 'date' | 'description' | 'amount' | 'debit' | 'credit' | 'currency';
export interface ColumnMapping {
  date: number | null; description: number | null; amount: number | null;
  debit: number | null; credit: number | null; currency: number | null;
}
export type MappingError = 'no-date' | 'no-description' | 'no-amount' | 'amount-and-debit-credit' | 'duplicate-column';
export const HEADER_KEYWORDS: Readonly<Record<ColumnRole, readonly string[]>>;
export function detectColumns(header: readonly string[], sample: readonly (readonly string[])[]): { mapping: ColumnMapping; confidence: 'high' | 'low' };
export function validateMapping(m: ColumnMapping): MappingError[];
```
HEADER_KEYWORDS (lowercase, matched against the trimmed, lowercased header with diacritics removed via `normalize('NFD').replace(/\p{M}/gu, '')`; a header matches a role when it equals a keyword or contains it as a whole word):
- date: 'date', 'transaction date', 'posted', 'posting date', 'value date', 'booking date', 'datum', 'fecha', 'data', 'buchungstag'
- description: 'description', 'details', 'payee', 'merchant', 'narrative', 'memo', 'name', 'reference', 'transaction', 'omschrijving', 'beschreibung', 'concepto', 'libelle', 'verwendungszweck'
- amount: 'amount', 'value', 'transaction amount', 'bedrag', 'betrag', 'importe', 'montant', 'importo'
- debit: 'debit', 'paid out', 'money out', 'withdrawal', 'withdrawals', 'out', 'spent'
- credit: 'credit', 'paid in', 'money in', 'deposit', 'deposits', 'in', 'received'
- currency: 'currency', 'ccy', 'valuta', 'wahrung', 'moneda', 'devise'
Headers containing 'balance', 'saldo' or 'solde' never take any role. Resolve roles in order date, debit, credit, amount, currency, description; each column takes at most one role; the first matching column wins. If both debit and credit found, amount stays null. Content sniffing for any role still null after header matching: date = first unused column where >= 80% of non-empty samples parse under some format of `parseCsvDate`; amount = first unused column where >= 80% of non-empty samples pass `parseDecimalString` after stripping sign/currency chars; description = first unused column with the longest average text length. confidence = 'high' when date, description and (amount or debit+credit) all came from headers, else 'low'.
validateMapping returns every applicable error in the order listed in the type.

```typescript
import type { MinorUnits } from '../money';
export type RowIssue = 'bad-date' | 'bad-amount' | 'zero-amount' | 'empty-description' | 'unknown-currency' | 'amount-too-large';
export interface CandidateRow {
  index: number;               // 0-based data row index
  localDate: string | null;    // 'YYYY-MM-DD'
  name: string;                // trimmed, <= 200 chars, raw bank text (D-20)
  amount: MinorUnits | null;   // signed: outflow negative
  currency: string;            // uppercase code
  issues: RowIssue[];
}
export interface MapOptions {
  mapping: ColumnMapping;
  dateFormat: DateFormat;
  decimalMark: DecimalMark;
  defaultCurrency: string;                        // target account currency (D-12)
  exponentFor: (code: string) => number | null;   // null = unknown currency
  locale: string;
  negate?: boolean;                               // 'flip signs' toggle
}
export const MAX_NAME_LENGTH = 200;
export type SignedParseResult = { ok: true; value: MinorUnits } | { ok: false; error: ParseError | 'too-large' };
export function parseSignedAmount(raw: string, opts: { decimalMark: DecimalMark; exponent: number; locale: string }): SignedParseResult;
export function mapRows(dataRows: readonly (readonly string[])[], opts: MapOptions): CandidateRow[];
```
parseSignedAmount: trim; negative if it starts with '-' or U+2212 or '+'-less '(' … ')' wrapper, or ends with '-', or ends with the token 'DR' (case-insensitive); 'CR' suffix forces positive; strip those markers, currency symbols (any char in the Unicode Sc category via `/\p{Sc}/gu`) and a leading/trailing 3-letter ISO code with whitespace; then call `parseAmount(rest, { locale, exponent, separators: separatorsFor(decimalMark) })`; map a parse failure to `{ ok: false, error }`; apply the sign with `minorUnits(-value)`.
mapRows per row: date via parseCsvDate (null -> 'bad-date'); name = cell trimmed, collapse internal whitespace runs to one space, slice(0, MAX_NAME_LENGTH) ('' -> 'empty-description'); currency = mapped cell uppercased if `exponentFor(code) !== null`, else defaultCurrency (+ 'unknown-currency' when the cell was non-empty); exponent = exponentFor(currency) (defaultCurrency is always known — throw RangeError if exponentFor(defaultCurrency) is null); amount from the amount column, or from debit/credit (debit parsed magnitude negated, credit magnitude positive, both present -> credit minus debit; both empty -> 'bad-amount'); parse failure 'too-large' -> 'amount-too-large', other failures -> 'bad-amount'; value 0 -> 'zero-amount'; `negate` flips the final sign. Never throw for row content.
Export from the barrel. Commits `test(02-03): …` then `feat(02-03): map CSV rows to candidate transactions`.
