Record-name column per entity for refusal copy: transactions.name, categories.name (plus builtin_key), recurring_series.name, accounts.name.
Response contract consumed by plan 02-12 (db/patches.ts, db/undoLog.ts):
```json
apply_patches    -> {"status":"applied","rows":[{"entity":"transactions","id":"…","version":4}]} | {"status":"conflict","conflict":{"entity","id","updated_by","record_name","builtin_key","reason":"changed"|"not-found"}}

rollback_undo_to -> {"status":"undone","undone":3} | {"status":"refused","undone":1,"step_id":"…","refusal":{…}} | {"status":"blocked","undone":0,"blocked_by":"…","refusal":{…}} | {"status":"not-found"}
```

Write `supabase/migrations/20260926000500_undo_log.sql` (header cites D-23..D-30):
1. Table:
```sql
create table public.undo_log (
  id uuid primary key,                                            -- client-generated at the moment of the action
  owner_id uuid not null default auth.uid() references auth.users(id) on delete cascade,
  label_key text not null check (label_key ~ '^[a-zA-Z]{1,40}$'),
  label_params jsonb not null default '{}'::jsonb check (jsonb_typeof(label_params) = 'object' and pg_column_size(label_params) <= 2048),
  ops jsonb not null check (jsonb_typeof(ops) = 'array' and jsonb_array_length(ops) between 1 and 6000),
  touched_ids uuid[] not null default '{}',
  status text not null default 'available' check (status in ('available','undone','refused')),
  refusal jsonb,
  created_at timestamptz not null default clock_timestamp(),
  resolved_at timestamptz
);
create index undo_log_owner_created_idx on public.undo_log (owner_id, created_at desc, id desc);
create index undo_log_touched_ids_idx on public.undo_log using gin (touched_ids);
```
2. BEFORE INSERT trigger `undo_log_fill()` (definer, search_path ''): `new.touched_ids := array(select distinct (e->>'id')::uuid from jsonb_array_elements(new.ops) e);` (server-derived; the client never supplies it).
3. AFTER INSERT trigger `undo_log_trim()` (definer): delete this owner's available/refused rows beyond the 12 newest by (created_at desc, id desc); then delete this owner's 'undone' rows older than the oldest retained row.
4. RLS: select using `owner_id = (select auth.uid())`; insert with check `owner_id = (select auth.uid()) and status = 'available' and refusal is null and resolved_at is null`. Grants: revoke all from anon; revoke insert, update, delete, truncate from authenticated; grant select to authenticated; `grant insert (id, label_key, label_params, ops) on public.undo_log to authenticated;`
5. `public.apply_patches(p_ops jsonb, p_undo_step jsonb default null) returns jsonb` (definer, search_path ''):
   - Validate: array of 1..6000 objects; entity in the four allowlisted tables; id castable to uuid; expectedVersion integer >= 1; patch a non-empty object whose every key is in that entity's allowlist (interfaces block); recurring_series_id/occurrence_date values must be JSON null. Any violation: `raise exception … using errcode = '22023'`.
   - Phase A (check, no writes): for each op in array order, `execute format('select version, updated_by, %s from public.%I where id = $1 for update', <scope/name cols>, entity) into …`. Scope: transactions/recurring_series/accounts require `household_id in (select public.user_household_ids())`; categories require `owner_id = (select auth.uid()) and not is_system`; otherwise raise 42501. Missing row: if the patch is exactly `{"deleted_at":"$now"}` or `{"archived_at":"$now"}` mark the op as skipped (removing something already gone is satisfied); else return `{"status":"conflict","conflict":{…,"reason":"not-found"}}`. Version mismatch: return `{"status":"conflict","conflict":{"entity","id","updated_by","record_name","builtin_key","reason":"changed"}}` immediately.
   - Phase B (apply): for each non-skipped op build the SET list from the allowlist only — `format('%I = ($2->>%L)::%s', col, col, type)`, or `%I = now()` when the value is the string '$now' on a timestamptz column, or `%I = null` for JSON null — and `execute format('update public.%I set %s where id = $1 returning version', entity, set_list) using id, patch into v_version`. Collect `{"entity","id","version"}`.
   - If p_undo_step is not null: validate its shape (id uuid, label_key text, label_params object, ops array length 1..6000) then `insert into public.undo_log (id, owner_id, label_key, label_params, ops) values (…, (select auth.uid()), …) on conflict (id) do nothing` — the forward write and its undo step commit together.
   - Return `{"status":"applied","rows":[…]}`.
6. `public.apply_undo_step(p_step_id uuid) returns jsonb` (definer): lock the caller's own step (`owner_id = (select auth.uid())`); missing -> not-found; 'undone' -> already-undone; 'refused' -> refused with stored refusal; else call `public.apply_patches(step.ops)`; on conflict set status 'refused', refusal, resolved_at now() and return refused; on applied set status 'undone', resolved_at now() and return undone with rows.
7. `public.rollback_undo_to(p_step_id uuid) returns jsonb` (definer): target must be the caller's; iterate the caller's steps with `(created_at, id) >= (target.created_at, target.id)` ordered newest first, `for update`; skip 'undone'; stop with 'blocked' at 'refused'; apply each via apply_patches; on conflict mark that step refused and return refused with the count undone so far (earlier undos stay committed — D-27); otherwise mark undone and continue; return undone with the count.
8. `public.purge_record_tombstones(p_older_than interval default interval '1 day') returns integer` (definer): hard-delete transactions with `deleted_at < now() - p_older_than` and `not exists (select 1 from public.undo_log u where u.status in ('available','refused') and u.touched_ids @> array[t.id])`; then recurring_series tombstones with the same rule and no remaining transaction referencing them; return the total.
9. Grants: revoke execute on all five functions from public, anon; grant execute on apply_patches, apply_undo_step, rollback_undo_to to authenticated; purge_record_tombstones to service_role only (revoke from authenticated).
10. `select cron.schedule('record-tombstone-purge-daily', '40 3 * * *', $$ select public.purge_record_tombstones(); $$);`

```sql
create or replace function public.account_balances(p_household_id uuid)
returns table (account_id uuid, currency text, paid_sum text, pending_sum text)
language sql stable security invoker set search_path = '' as $$
  select t.account_id, t.original_currency,
         coalesce(sum(t.original_amount) filter (where t.status = 'paid'), 0)::text,
         coalesce(sum(t.original_amount) filter (where t.status = 'pending'), 0)::text
  from public.transactions_active t
  where t.household_id = p_household_id
  group by t.account_id, t.original_currency
$$;
create or replace function public.transaction_months(p_household_id uuid)
returns table (month text, row_count integer)
language sql stable security invoker set search_path = '' as $$
  select to_char(t.local_date, 'YYYY-MM'), count(*)::integer
  from public.transactions_active t
  where t.household_id = p_household_id
  group by 1 order by 1 desc
$$;
revoke execute on function public.account_balances(uuid), public.transaction_months(uuid) from public, anon;
grant execute on function public.account_balances(uuid), public.transaction_months(uuid) to authenticated;
```
(security invoker: RLS on the underlying table still decides visibility; sums are text so they never pass through a JS float. transaction_months is shaped so a later archive phase (DAT-01) can add an `archived` column without breaking callers.)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client -> apply_patches / apply_undo_step (definer) | Ops and stored undo steps are client-authored JSON; the definer must not trust them |
| household member -> member | A member's undo must never overwrite another member's later change |

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
