- Date: device-local today (`localDateIn(new Date(), getDeviceTimeZone())`, as useRecordContext's `today`) captured when the change is made, so a queued offline change asks for the day the user made it.
- Household: the cached household id (`queryKeys.household(userId)`); if not cached the helper defers (persists) and the sweep resolves the household later.
- Size: <= 50 codes per ensure call (02-44/02-46 contract); more are split into chunks of 50, each including the new home. In the sweep each chunk takes one unit of the 10-call budget.
- Storage key (plan-checker blocker 4): `fincwin:fx-home-rate-check` — the `fincwin:` prefix is what `wipeDeviceData()` clears (`STORAGE_PREFIX` in src/services/storage/wipe.ts). Only the latest check is kept.
- Device-region default (useSetHomeCurrencyIfDefault): runs the same helper when it actually applied; for a brand-new user the used set is empty, so no call.
