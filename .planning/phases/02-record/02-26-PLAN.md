<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| device file system -> app | Untrusted file bytes of arbitrary encoding |
| app -> Supabase | Only converted rows and user-accepted patches leave the device; the file never does |
| engine -> error reporting | Anything thrown or recorded could reach Sentry through a scrubber that does not redact statement text |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-26-01 | Information Disclosure | statement file | mitigate | Bytes read on device; no upload code path (grep gate); cache copy deleted in finally; file name never kept (D-17) |
| T-02-26-02 | Denial of Service | large or hostile files | mitigate | 5 MB byte cap before reading; 5,000-row ceiling; OFX budgets (02-33); chunked commits |
| T-02-26-03 | Tampering (sign misread) | pipeline | mitigate | Preview requires a decided or user-chosen FormatProfile (type-enforced); reconciliation shown; raw strings kept (D-41, D-42, D-45) |
| T-02-26-04 | Tampering (silent drops/duplicates) | preview | mitigate | Duplicates flagged not dropped; same-file rows never compared; blocking issues visible; user controls every tick (D-47) |
| T-02-26-05 | Tampering (silent link / mark paid / limit) | suggestions | mitigate | All three are decisions the user accepts row by row; defaults off (D-48, D-52, D-55) |
| T-02-26-06 | Information Disclosure | errors | mitigate | Typed reasons and codes only; no console or thrown content (RESEARCH Security extension V7) |
| T-02-26-07 | Tampering | injected content | mitigate | Rows go through the same insert path, grants, checks (name <= 200, raw <= 64, amount bounds) and RLS as manual entry |
