# Phase 5.1 Plan 14: Quoted payment and plan card Summary

Quoted-payment check where the scored payment is max(computed, quoted), plus the exact whole-plan card numbers.

## What was built
- `checkQuoted` returns none / matches / differs (strict gap above tolerance, direction) / from_quote (implied APR via `impliedApr`, divided by `every` for every-N cadences; `above_max` or null passed through, no rate invented).
- `scoredPayment` takes the larger non-null value (I41), property-tested over 150 runs. It does not copy plan.ts:347.
- `planCard` gives price, tax, one-off fees, interest, fees, running monthly, total, `lines` (N x payment then final), monthly equivalent, first and end dates, source. `salesTaxOf` ports the `salesTaxAmount` arithmetic without importing checkInputs; the test checks parity against it.

Commits: 8a2cd9f6 (Task 1), 1e82bfb5 (Task 2).

## Deviations from Plan

**1. [Rule 1 - Bug] Interest not double counted**
- The plan said interest = totalInterest + pauseInterest, but `Schedule.totalInterest` already includes the pause interest (schedule.ts header). Adding it again would overstate the total. `interest = totalInterest`.
- A test with a deferred, interest-bearing plan checks that `card.total === schedule.totalPaid`.
