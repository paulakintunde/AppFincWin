Rules: count must be an integer 1..MAX_PLAN_PERIODS (else ok:false plan_count_missing for 0/null; RangeError for > 600 or non-integer). `today` → `amortiseDue(financed, scaledApr(apr,c), count, amortBase(c))`, firstDate = asOf. `one_period` → `amortise(...)`, firstDate = cadenceDate(asOf, c, 1). `deferred`: validate firstDate ≥ asOf; if interestDuringPause null → missing; let k = the largest n with cadenceDate(asOf, c, n) ≤ firstDate; if true and apr > 0, compound the financed amount k times at the per-period rate `scaledApr(apr,c) / rateDenominator(amortBase(c))` using `divideHalfUp(balance × num, den)` per period (bigint), pauseInterest = grown − financed; then `amortiseDue(grown, ...)` with firstDate as given (the first payment falls on firstDate).
