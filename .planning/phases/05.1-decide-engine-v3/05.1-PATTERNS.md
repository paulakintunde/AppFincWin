  while (hi - lo > 1) { const mid = lo + Math.floor((hi - lo) / 2); if (fits(minorUnits(mid))) lo = mid; else hi = mid; }

## Shared Patterns

### Money arithmetic (all engine files)
**Source:** `money/rounding.ts:10`, `payoff/types.ts:46-72`, `money/types.ts`.
- `MinorUnits` is a branded `number`. Do arithmetic as `BigInt(x)` and convert back with `minorFromBigInt(v, FN)`, which throws when out of range.
- `divideHalfUp(n: bigint, d: bigint)` is the only rounding function.
- `ceilDivide(n, d)` is for counts and level payments only, and throws if n < 0.
- Never `Number(bigint)` without a proven range comment (precedent: `pots.ts:6-8`).

### Validation / errors (all engine files)
**Source:** `pots.ts:17-34`, `amortise.ts:22-33`. Use `const FN = '<fn>'` and throw `RangeError` with a message of the form `${FN}: <field> ${value} must be …`. Check dates with `isValidLocalDate` from `time/localDate`. User-facing problems are **codes** in the result (reason codes, I29), never thrown errors.

### Header doc blocks (all engine files)
Every module opens with a `/** … */` block that names the D-numbers or invariants it implements, states "Pure: no I/O, no clock (the caller passes asOf)" where relevant, and names what it avoids importing (`cashPath.ts:13-14`: "this file imports schedule.ts, never `../recurring` or detect.ts").

### Coverage-ignore comments
`/* istanbul ignore … -- reason: <10+ chars> */` is the only accepted form inside `decide/`, enforced by `check:ignores`. Branch coverage of `v3/` and `snapshot/v3/` must be 100% (`jest.config.js:39-45`).

### Static grep tests
**Source:** `public-api.test.ts:247-307` and `outputs-are-codes.test.ts:555-576`. `fs.readFileSync` the file, strip comments, then use `expect(text).not.toContain(...)` or `not.toMatch(...)`. Use `it.each(files.map(f => [path.relative(root, f), f] as const))` so each file is its own named case.
