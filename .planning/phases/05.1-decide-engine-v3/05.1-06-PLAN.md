Add to series.ts:
```ts
export interface SeriesDrift { readonly seriesId: string; readonly current: MinorUnits; readonly suggested: MinorUnits; readonly fromMonth: YearMonth }

```
For each confirmed, non-dismissed series take its paid lines (by seriesId) sorted by date; if at least SERIES_DRIFT_LAST and each of the last SERIES_DRIFT_LAST satisfies `BigInt(Math.abs(a − s)) * BigInt(SERIES_DRIFT_DIVISOR) > BigInt(s)`, emit a drift with `suggested` = the latest amount and `fromMonth` = the month after the latest line (`addYearMonths(yearMonthOf(date), 1)`).
