## What was built
- `legacy.ts`: `upgradeInputs` (never throws; reasons always include `legacy_upgraded`, plus `legacy_method_mapped` for card and invest kinds), `legacyLimits` (debt_share, housing_share, unsecured_multiple; non-null valid value -> on, source `legacy`; null or invalid -> off, source `builtin`, default 36 / 28 / 12), `legacyStateOf`.
- `inputsV2.ts`: `parseCheckV2` (null unless `v === 2`; clamps and resets), `toStoredV2` (Percent as exact decimal text), `readStoredCheck`.
- `seen.ts`: `SeenV3`, `seenOf`, `changeSinceLooked`. Null, a legacy 4-state string or any unreadable value re-baselines with no change (C7). A code change returns exactly `['code_changed']`; with the same code, reasons are `ready_by_changed`, `unspent_changed` (more than 1 minor unit), `line_changed`. Reads `unspent_before_after` fact `values.after` and `line_crossed` fact `values.id`.

## Missing-`v` corpus outcome (orchestrator note)
The adapter treats a missing `v` as v1 and tolerates partial fields. A test runs every corpus entry with `v` stripped: all upgrade to a valid CheckV2 with `legacy_upgraded`, identical to the version with `v: 1`. Seed entries lack `counted` on running costs, so `counted` is treated as on unless it is `false`.

## Mapping decisions
- Price = advertised + counted on-the-day adjustments (adds minus takes_off), floored at 0 and clamped to 1e12; a counted adjustment with a valid `taxPercentText` becomes `taxPercent` (first one) and is not added to the price.
- Loan: monthly plan, count = termMonths, deposit, apr from aprText, `firstPayment` null (v1 loans have no first-payment field, so the user is asked, D-04). Promo and variable flags are not carried (`deferredInterestTerm` false).
- Instalment: freq weekly {week,1}, fortnightly {week,2}, monthly {month,1}, quarterly {month,3}; quotedPayment = amount; apr = typed rate only when `hasRate`, else 0; today -> today, next_period/next_month -> one_period, absent -> null.
- Card, lump, monthly and invest kind: card -> once; invest -> `legacyKind: 'invest'`.
- Running costs -> `extras['legacy:<category>']` (null category -> `legacy:other`); custom item type -> preset of `treatLike ?? 'general'`, name dropped.
- v1 `currency` is not mapped (`foreign` stays null): the adapter has no home currency. v1 household split maps to a household share with `myIndex` 0 (v1 was always personal until Phase 8).
