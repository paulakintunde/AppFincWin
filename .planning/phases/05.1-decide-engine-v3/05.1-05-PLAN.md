Export:
```ts
export interface DetectRow { readonly id: string; readonly name: string; readonly amount: number; readonly currency: string; readonly date: string; readonly isTransfer: boolean; readonly accountId: string | null }
export interface DetectContext { readonly dismissedKeys: ReadonlySet<string>; readonly linkedRowIds: ReadonlySet<string> }
export function detectCandidates(rows: readonly DetectRow[], ctx: DetectContext): readonly RecurringCandidate[]
export function twoDateClusters(dates: readonly string[]): { readonly days: readonly [number, number]; readonly members: readonly [readonly string[], readonly string[]] } | null
```
Algorithm: skip transfers and zero amounts; group key = `${offerKey(row.name, row.currency, row.amount)}|${row.accountId ?? ''}` (group by payee, direction and account, v3 §4.1); candidate `key` = the offerKey part (so one dismissal covers the payee in every account, same as selectOffers). Drop groups whose key is dismissed or that contain a linked row id. Sort rows by date (then id for ties). Then, in this order:
1. **Two fixed dates** (before any gap window): `twoDateClusters` takes the days of month; it succeeds when the days split into two clusters whose centres are at least 10 days apart, every day is within TWO_DATE_TOLERANCE_DAYS of its cluster centre (treat day 28-31 near day 1 of the next month as day 1 only when the date's month-end is within 3 days), each cluster has ≥ 3 rows, and each cluster's own consecutive gaps fall inside RECURRING_WINDOWS.monthly. Emit two candidates `{month,1}` with `payGroupKey = key + '#two-dates'`, each anchored on its cluster's latest date, amount = that cluster's lower median (detect.ts rule).
2. **Single cadence**: compute gaps; the first window in order weekly, fortnightly, monthly, quarterly, yearly containing every gap wins (windows never overlap); require RECURRING_MIN_REPEATS rows; amounts must pass `|a − m| × AMOUNT_TOLERANCE_DIVISOR ≤ |m|` with m = lower median. Map to Cadence: weekly {week,1}, fortnightly {week,2}, monthly {month,1}, quarterly {month,3}, yearly {month,12}.
`direction` = sign of amount ('in' for > 0); `amount` = `minorUnits(Math.abs(median))`. Output sorted by row count desc, then name, then key (deterministic).
Write the tests from the behavior list, named with their ids; include a fast-check property that shuffling rows (fc.shuffledSubarray of the full array with the same length) gives a deep-equal result (numRuns 100).
