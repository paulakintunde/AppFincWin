# Phase 05.1 Plan 11: Income by profile Summary

Money in for this month and the typical month by income profile (salary dates, match, spread, steady, balance, mix), never counting income that may not arrive.

## Commits
- 1247be71: feat(05.1-11): money in by income profile

## Decisions
- Rule split: pay series follow the salary rule (confirmed dates, 7-day overdue cut-off, line within 3 days early satisfies an occurrence) when there is no profile or a salary/mix part; a commission/freelance-only profile sends pay through the variable method too. Other income follows the variable method when the profile has a variable part (null variable = match), else is counted by its dates once marked available.
- In a variable profile, an income line with no kind and no mark counts as the profile's own income; any line with a kind needs an `available` mark. Pending lines count only under (a), only when `expected`, within the month, and not overdue past the grace.
- Steady replaces only the variable part (a mix keeps its salary part); steady with no amount falls back to match. Balance counts received only.
- Spread parts use divideHalfUp with the remainder on the last month, so parts sum to the line; looks across `history` plus `current` (deduped by month).
- Rough figures apply only when nothing is counted and there is no live confirmed pay series (a missed paycheque stays 0).
