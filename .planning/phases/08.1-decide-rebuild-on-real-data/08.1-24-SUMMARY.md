## Deviations

1. **[Rule 1] The spoken label has no double full stop.** The a11y sentence ends with "."; VerdictCard strips that one trailing stop before joining with ". ". It reads "Caution: … on June 14. Fits, …".
2. **The spoken and visible zero follow show-cents.** The plan's example reads "$0" / "Caution: dips below $0 on June 14." With show-cents on (the default), the visible words read "$0.00", the same text as the fact lines' {{zero}} as the plan asks. The spoken form reads "0.00 dollars", which is the app's spoken money via `formatMoneyA11y` (D-94). With cents off they read "$0" and "0 dollars". Both are tested and both are flagged for plan 14.
3. **Test technique.** The tests mock the `react-native-reanimated` module (wrapping withTiming / withSequence / cancelAnimation), the repo's existing pattern (saveMoment, Sheet.reducedMotion), instead of `jest.spyOn`. The module's exports are not spy-able getters.
4. **ExplainTip test is new.** The plan listed it as existing. It was created.
5. **The end-to-end case runs SN-32 and SN-34 through `prepare` + `judgeCheck`**, as `fixtures.ts` does, not through `evaluate`. depcruise allows the feature test to import the engine test helpers, which it already does.
