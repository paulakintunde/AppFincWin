# Phase 08.1 Plan 05: Decide server switch Summary

APP-21 "off fast": one `app_config.decide_off` update pauses Decide for everyone with no app release. The app reads it like `min_supported_version`, caches the last value in AsyncStorage (`fincwin:decide-off`), never turns Decide off on a failed read, and treats a first-ever failed read as on. "On slowly" stays on the existing per-account `profiles.decide_v3` and tester list.

## What was built
