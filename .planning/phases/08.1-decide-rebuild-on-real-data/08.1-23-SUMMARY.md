## Deviations

1. **[Rule 3] No `spendNoteOf` from plan 22.** The plan's interface named it; it did not exist. Built `spendRuleView.ts` (pure view over plan 22's `resolveSpendRule` / `defaultRuleFor` / `inferSetup`) and `spendNote.ts` (pure line choice) plus hooks `useSpendRule` / `useSpendNote`.
2. **Info icon gap (reported, not filled).** `src/ui/icons` has no info glyph (`check:icons`: 64 icons, none for info/help). Per the owner's fallback the tips reuse the app's existing tap-to-explain affordance (the Decide "Why?" link pattern) as a text link; no third-party icon, no emoji. If an info glyph is wanted it has to be drawn on the 06.2 boards first.
3. **Choice rows use the SplitRuleList radio pattern** (RadioDot, 64-high rows) instead of Pill radios: each choice carries a helper, a tag and its own tip, which the pill does not hold.
4. **Who pays line comes through `useHouseholdShare().spend`** (optional field) so the many tests that mock that module keep working; with no rule read yet the old helper shows.
5. **AccountSheet stays mounted after a joint save** and renders the purpose sheet in its place (the WeightsSheet offer pattern). The purpose Save waits while an account add/edit write is still in flight ("Saving the account first…"), so the RPC finds the new account.
6. **Test mocks added (Rule 3)** to suites that render the real AccountSheet or the real `useDecideV3` (accounts, accountsLife, accountRate, accountUseRow, decideV3, decideV3.shared, decideReads.count, pastReads, householdAnswer, useHouseholdScopeSource, SharedAccountsScreen).
