# Phase 02.2 Plan 32: Week start and home currency settings Summary

Week start (Monday/Sunday dropdown, no confirm) and an all-or-nothing home-currency change sheet in You -> Money, plus a FIFO `queueToast` so "Category caps converted" follows "Home currency is now X" instead of replacing it.

## Commits
- de5c513: queueToast (dismissToast shifts the next queued toast in; wipe and test reset clear the queue)
- a52113c: WeekStartRow, HomeCurrencyRow, HomeCurrencyChangeSheet, YouScreen wiring, tests

## Behaviour
- Sheet uses `useChangeHomeCurrency`; button reads "Getting rates…" and is disabled while pending; sheet cannot be dismissed mid-flight.
- ok: closes, `showToast` done, `queueToast` caps only when capsConverted > 0.
- reason `rates`: stays open, danger line "Home currency is unchanged. Try again."; reason `changed`: closes with no success toast (the hook already refetches prefs).
- Body says "Each line keeps the amount and currency it was entered in."; never claims stored amounts change.

## Deviations from Plan

- **RateAttribution not rendered.** The behaviour list says to show it on success, but `useChangeHomeCurrency` returns only `capsConverted` (no rate date or source), and the sheet closes on success, so there is nothing to attribute. The mandatory credits link remains on the You screen. Not wired to avoid inventing data.
- Test file for YouScreen mocks the record context and related hooks so the screen test needs no providers.
