# Phase 02.2 Plan 33: Sample figures experience Summary

Once-per-session "Clear the sample figures?" prompt fired from every real save path through a cache-only trigger, plus the Start fresh banner and the "Explore with sample figures" onboarding option (REC-23, D-09 to D-12).

## What was built
- `samplePrompt.ts`: external store, one request per session (reset on sign-out wipe).
- `maybeRequestSampleClearPrompt`: reads cached `sampleExists` and `recordPrefs` only; asks when samples exist and the prompt is unanswered.
- Trigger wired into `useAddTransaction.add`, `useEditTransaction.edit` (only when the cached row is `is_sample` and an owner id is known), `insertRowsAsOneStep` (clone and paste) and the `useStatementImport` commit (only when rows are written and the commit did not throw).
- `SampleBanner` (shown while `hasSamples`, Start fresh confirm, non-undoable clear) and `SampleClearPrompts` (Clear them / Keep for now, equal weight) mounted in `app/(app)/_layout.tsx`.
- `SetupHistoryScreen`: third option seeds samples and opens Activity; analytics `choice` union gains `'sample'`.

Jest: samplePromptTrigger, transactions, cloneMonth, pasteLines, useStatementImport, samples, setup suites pass. Typecheck, depcruise clean; lint has no errors (one pre-existing exhaustive-deps warning on `payMatchRows` in useStatementImport).
