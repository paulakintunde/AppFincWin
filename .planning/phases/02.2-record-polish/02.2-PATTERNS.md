### 1. Pure engine modules (`engine/activity/*`, `recurring/offer.ts`, `categorize/usage.ts`, `accounts/*`)

**Analog:** `src/engine/activity/totals.ts` (shape), `src/engine/activity/status.ts` (date handling), `src/engine/activity/balance.ts` (BigInt).

**Conventions to copy**
- File header comment names the decision IDs and states purity ("no `Date.now()`, no device time zone lookup").
- Inputs are small structural interfaces (`TotalsInput`), never DB rows. The caller maps rows to them.
- Only `import type` from siblings; engine imports no `db/state/services/ui/react`.
- Dates are `'YYYY-MM-DD'` / `'YYYY-MM'` strings; invalid dates throw `RangeError` via `assertLocalDate` (status.ts 10-14).
- Re-export from the folder `index.ts` (activity/index.ts is `export * from './status'; ...`). Add each new file there.

**Core pattern to extend** (`totals.ts` 28-85): loop rows; transfers `continue` first; skipped `continue`; null `amountHome` bumps `unconvertedCount`; accumulate `paidIn/paidOut/stillToCome`. `netOf` in `groups.ts` must be the single place this sign logic lives.

```typescript
// totals.ts 40-57: the refund change goes exactly here (RESEARCH "Refund-aware totals")

  if (row.isTransfer) { transferCount++; continue; }
  if (row.status === 'skipped') { continue; }
  if (row.amountHome === null) { unconvertedCount++; continue; }
  if (row.status === 'paid') {
    if (row.amountHome >= 0) paidIn += row.amountHome; else paidOut += row.amountHome;
  } else { stillToCome += row.amountHome; pendingCount++; }
}
```
Change: add optional `isRefund?: boolean` to `TotalsInput` (keep backward compatible), route `row.isRefund` to `paidOut` (user Q3: refunds sit under Money out as a negative reduction, excluded from Money in). Add `count`.

```typescript

// sums arrive as text; BigInt(leg.paidSum); overflow flag instead of a wrong number
```

**Month helpers to reuse, not rewrite:** `nextMonth` and `monthsForSwitcher` (status.ts 54-90; `monthsForSwitcher(dataMonths, today)` becomes `(dataMonths, today, horizonMonth)`), `daysInMonth(year, month)` (`recurring/schedule.ts` 42-45) for clone-day clamp and week bucketing, `monthOf`/`monthRange`/`isValidLocalDate` from `src/engine/time`.

### 19. Shared Patterns (cross-cutting)

**Money / strict parsing.** All amounts are integer minor units. Parse only via `engine/money/parseAmount.ts` / `parseNotatedAmount.ts` (never `parseFloat`/`Number(text)`). Applies to paste, keypad, cap field, clone.

**Engine boundary.** Applies to every `src/engine/**` file: no imports from `db/ state/ services/ ui/ react`. Verify with `npm run lint && npm run depcruise`.

**Server-only flags / grants.** `is_sample`, `recurring_series_id`, `occurrence_date`, FX stamp columns have no client grant (transactions migration lines 130-137 comment). Any client-writable column needs all of: SQL grant, `*_KEYS` const, row type, `apply_patches` allowlist + type map.

**Write queue discipline.** Every new write is `registerXMutations(qc)` default + `scope: WRITE_SCOPE` + `retry: shouldRetryWrite` + `guardSession/markSession` + optimistic `onMutate` + `void qc.invalidateQueries` in `onSuccess`. One user action = one undo step, minted via `newStepId()` before `mutate()`.

**Copy / i18n.** All strings through the typed catalogue `src/i18n/locales/en.ts` via `useT()`. Declarative voice; never "advice", "recommendation", "you should". Undo labels via `undoLabelText`.

**Design tokens.** Colours from `useTheme().colors` only, type from `textRole(pairing, role)`, spacing/radii from `@/theme/layout`. No new colours, shadows or icon sets (`CLAUDE.md`).

**Haptics.** Only `impactAsync`, `notificationAsync`, `selectionAsync` through `src/ui/haptics.ts`. `expo-haptics` is a new native dependency: first plan installs it with `npx expo install expo-haptics`; dev build rebuild required before device walkthrough.

**Supabase operations.** Do not use the Supabase MCP connector. `supabase db push` hits production: use `npm run supabase:preflight` then `npm run supabase:db:push` in a `[BLOCKING]` plan; migrations stay additive (`npm run lint:migrations`).
