# Phase 2.2 Plan 31: Account detail pending rows and delete/archive footer Summary

Account detail now shows the pending split (Coming in, Going out, After pending through {Month}, On the statement, Not ticked off) computed by the engine `pendingSplit`, and a footer that offers Delete only for a known-empty account and otherwise Archive with the reason.

## Tasks

1. Usage counts and pending-split rows - commit 8aa140e
2. Delete or archive footer and detail screen - commit 989dfa6

## Implementation notes

- `fetchAccountUsageCounts` runs three head counts (live lines from `transactions_active`; active series split into end_date null and end_date >= today), because the db test fake has no `.or()`.
- Month label is the later of next month and the household horizon month; only the month name is shown.
- Foreign account currency row shows the home figure via `projectionHomeAmount` (latest stored rate only) or "Waiting for a rate".
- `AccountRemoveRow` never renders a disabled Delete; unknown usage (loading, offline, error) shows Archive with no reason.
- Delete uses `useDeleteAccount().remove` then `router.back()`; archive uses `useEditAccount` with `archived_at: '$now'` and an undo toast.
- `AccountDetailScreen` passes `today` to `ActivityRow`.
