# Phase 02.2 Plan 28: Sample data and home-currency change actions Summary

Online-only hooks: `useSampleData` (seed, clear, decline) and `useChangeHomeCurrency`, which fetches and stores rates for the new home currency (old home included) before calling `change_home_currency`, so a failure changes nothing.

## Tasks

1. **Awaited rate fetch and home-currency change** (f246d08): `fetchRatesForHomeChange` (never persists a deferred check; fails on null/throw/throttle or missing next/previous codes); `useChangeHomeCurrency` returns `{ok:true,capsConverted}` or `{ok:false,reason:'rates'|'changed'}`; on success sets the money prefs cache and invalidates categories, fxLatest and transactions root.
2. **Sample data actions** (5e57c9b): `seed` and `clear` call the RPCs directly and resolve true/false; `clear` and `declinePrompt` mark the prompt answered via `markSamplePromptAnswered`; no undo step recorded.
