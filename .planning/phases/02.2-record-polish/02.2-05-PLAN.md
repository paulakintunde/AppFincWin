    ```typescript
    export interface ParsedLine { lineNo: number; name: string; amount: number /* signed minor units: income +, expense - */; localDate: string; direction: 'in' | 'out'; }
    export type PasteSkipReason = 'no-amount' | 'no-name' | 'bad-amount' | 'bad-date';
    export interface PasteSkip { lineNo: number; reason: PasteSkipReason; }
    export type PasteResult = { ok: true; rows: ParsedLine[]; skipped: PasteSkip[] } | { ok: false; error: 'too-many-lines'; limit: number };
    export interface PasteContext { locale: string; separators?: LocaleSeparators; currency: string; exponent: number; today: string; month: string /* viewed 'YYYY-MM' */; }
    export function parseLines(text: string, ctx: PasteContext): PasteResult;
    ```
    Cases (input -> expected):
    - 'Studio rent 1450' (GBP, exp 2, month 2026-10, today 2026-10-09) -> {name 'Studio rent', amount -145000, direction 'out', localDate '2026-10-09'}
    - '+ Freelance invoice 600 12 Oct' -> {name 'Freelance invoice', amount +60000, direction 'in', localDate '2026-10-12'}
    - '1450\tStudio rent' (tab, spreadsheet copy, amount first) -> name 'Studio rent', -145000
    - 'Groceries, 82.40, 2026-10-03' -> -8240 dated 2026-10-03
    - '"Smith, J", 20' (quoted name with comma) -> name 'Smith, J'
    - 'Coffee £3.50' -> -350 (a leading currency symbol on the amount token is stripped only when it is the symbol of ctx.currency or the ISO code)
    - 'Only words' -> skipped {reason 'no-amount'}; '12.50' alone -> skipped 'no-name'; 'Rent 1,2,3' -> skipped 'bad-amount'; 'Rent 50 31 Feb' -> skipped 'bad-date'
    - blank and whitespace-only lines are ignored (not skipped, not counted)
    - viewing 2026-12 while today is 2026-10-09: undated lines dated '2026-12-01'
    - 5001 non-blank lines -> { ok: false, error: 'too-many-lines', limit: 5000 }
    - JPY (exponent 0): 'Ramen 980' -> -980; '980.5' -> skipped 'bad-amount'
  </behavior>
  <implementation>
Header comment: linear scan per line, no backtracking regex over user content (tokenize.ts discipline); CONTEXT D-20/D-21; never parseFloat. Algorithm per non-blank line (lineNo is 1-based over the original text):
1. Trim; detect a leading '+' (direction 'in') and strip it.
2. Split: if the line contains a tab -> split on tabs; else if it contains a comma outside double quotes -> split on those commas honouring "..." quoting (reuse `tokenize(line)` from `../csv/tokenize` with a single line when it returns one row, else treat as unreadable 'bad-amount'); else split on runs of spaces.
3. Date: recognise, as a whole field or as the trailing (or leading) 1-3 space tokens, `YYYY-MM-DD` (validated with isValidLocalDate), `D Mon` / `D Month` / `Mon D` (English month names, year = the viewed month's year), or `D/M` only when unambiguous by value (D > 12). A token that looks like a date but is invalid -> 'bad-date'.
4. Amount: the remaining token that `parseAmount` accepts (after stripping one leading ctx.currency symbol/code). Prefer the last such token; if the first token is the only amount, amount-first order applies. An amount-like token (digits with separators) that parseAmount rejects -> 'bad-amount'. No amount-like token -> 'no-amount'. Zero amount -> 'bad-amount'. Negative input like '-20' is read as magnitude 20 with the '+' rule deciding direction (a pasted list carries no sign convention beyond '+').
5. Name: the remaining tokens joined with single spaces, trimmed, max 200 chars (truncate) ; empty -> 'no-name'.
6. Count non-blank lines first; above MAX_IMPORT_ROWS return the error result before parsing.
index.ts: `export * from './parseLines';`. jest.config.js: add `'paste'` to the FULL list on line 39 (same commit as the folder, per the config comment).
Tests (fast-check): `fc.string()` and `fc.fullUnicodeString()` never throw; `rows.length + skipped.length === nonBlankLineCount`; round-trip: generate {name from a safe alphabet, amount 1..10^9, optional ISO date in month, separator from ['\t', ', ', ' '], order name-first|amount-first, plus flag}, format as text with the amount written via a fixed '.'-decimal formatter for en-GB, parse -> recovers name, signed amount and date; every returned amount equals `parseAmount(token)` (never float-derived). Plus every behaviour case above as an example test.
  </implementation>
</feature>
