# Phase 02.2 — Security

> Per-phase security contract: threat register, accepted risks, and audit trail.

---

## Trust Boundaries

| Boundary | Description | Data Crossing |
|----------|-------------|---------------|
| Client to Supabase RPC/RLS | Mobile app calls security-definer RPCs and RLS-guarded tables (add_activity_month, seed/clear_sample_data, change_home_currency, create_recurring_series_batch, apply_patches) | Household financial rows, undo steps |
| Client to column grants | is_sample and horizon_month have no client grant; system keys writable only under fincwin.undo_replay | Server-owned flags |
| Pasted/imported text to engine parsers | Untrusted text parsed by strict parser with line and length ceilings | Names, amounts |
| Repo to production Supabase | Migration push via preflight-guarded script, PR-merged commit only | Schema |
| Device to EAS/OTA | Native change requires new development build, never OTA | App binary |
