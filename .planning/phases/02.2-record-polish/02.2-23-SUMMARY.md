# Phase 02.2 Plan 23: Record write hooks Summary

Four queued write hooks: add a month (server-recorded monthAdded step), soft-delete an account (apply_patches with accountDeleted inverse), dismiss series offers ("Not now", server-stored), and unconditional record prefs (week start, sample prompt marker).

## Accomplishments
- `useAddMonth().add` computes `addableMonth`, throws RangeError when null, mints the step id once, optimistically sets the horizon, shows the Undo toast; 22023 rolls back with a refusal; already-applied is success.
- `useDeleteAccount().remove` sends one `deleted_at: '$now'` op with the restoring inverse; account leaves the cache at once; 23514 restores it and shows a refusal.
- `useDismissOffers().dismiss` adds keys to the cache first, upserts with ignoreDuplicates, guards 1..50 keys, failed-write record carries counts only.
- `useUpdateRecordPrefs` copies the moneyPrefs shape: optimistic, no expected version, rollback on rejection.
- All four registered in `registerMutationDefaults` after the 02.2-20 block.
