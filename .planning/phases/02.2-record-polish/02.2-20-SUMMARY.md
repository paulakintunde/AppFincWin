# Phase 02.2 Plan 20: Batch write hooks Summary

Clone month, paste lines and mark-all-monthly now run on the paused-mutation write queue, each as exactly one undo step; `suggestionToSeries` moved out of the import pipeline so Activity can reuse it.

## What was built
- **batchInsert.ts**: `insertRowsAsOneStep` chunks at 500, collects returned versions, records one `cloned`/`pasted` step via `recordUndoStepSafely`; `registerBatchInsert` holds the shared defaults (optimistic month placement, derived-read invalidation, rate follow-up, count-only failed-write record, refusal toast). Replay inserts nothing (ON CONFLICT) and records no second step.
- **cloneMonth.ts / pasteLines.ts**: hooks mint client UUIDs and the step id up front, refuse 0 or more than MAX_UNDO_OPS (6000) with RangeError before any write.
- **markMonthly.ts**: one `create_recurring_series_batch` RPC per action (max 50), server records the `markedMonthly` step; no client undo write.
- **recurringSeries.ts**: `suggestionToSeries` relocated (account from anchor row, falls back to ctx), `is_automatic` carried by `seriesInputFromRow`, `seriesPatchFromOccurrenceEdit` and `suggestionToSeries`.
- All three registered in `index.ts`.
