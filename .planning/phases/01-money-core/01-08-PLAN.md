| Boundary | Description |
|----------|-------------|
| third-party FX APIs → fx-sync | untrusted JSON that becomes the rates every conversion uses |
| pg_cron → fx-sync | shared-secret invocation (unchanged) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-08-01 | Tampering | provider returns a wrong or spoofed rate | mitigate | Strict parsers (ISO codes, finite positive rates, EUR base only) plus the >10% quarantine and second-source confirmation (MON-11) |
| T-01-08-02 | Information Disclosure | held-rate leakage | mitigate | fx_rate_holds has no client policy and grants revoked; per_eur_rate never reads it; pgTAP asserts 42501 |
| T-01-08-03 | Spoofing | fx-sync endpoint | mitigate | Existing constant-time shared-secret check retained; verify_jwt stays false only for this cron-invoked function |
| T-01-08-04 | Denial of Service | both providers down | mitigate | 'sync-failed' alert row; staleness alert (01-11) is the backstop; existing rates keep serving |
