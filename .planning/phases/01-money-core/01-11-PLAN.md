<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app user → resolve-rate | client-invoked Edge Function that then uses the service-role key |
| pg_cron → fx-monitor | shared-secret invocation |
| fx-monitor → Resend | outbound email with operator-only content |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-11-01 | Elevation of Privilege | resolve-rate IDOR (another household's transaction id) | mitigate | verify_jwt = true; the row is first read with a user-scoped client under RLS; 404 before any service-role action |
| T-01-11-02 | Denial of Service | resolve-rate spam | mitigate | no-op for non-pending rows, one upstream fetch per call; per-user limits arrive with ACC-13 |
| T-01-11-03 | Spoofing | fx-monitor endpoint | mitigate | constant-time shared-secret header, verify_jwt false only because pg_cron is the caller |
| T-01-11-04 | Information Disclosure | digest email | mitigate | contains currency codes, rates and counts only; no user identifiers or amounts |
| T-01-11-05 | Information Disclosure | Resend API key | mitigate | Edge Function secret only, never EXPO_PUBLIC_, never in a migration; grep gate on the migration |
| T-01-11-06 | Tampering | auto-accepting a bad rate | mitigate | operator emailed on hold and on auto-accept; fx_drop_hold runbook within the window |
</threat_model>
