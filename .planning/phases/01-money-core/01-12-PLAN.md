## Trust Boundaries

| Boundary | Description |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-12-01 | Tampering | replayed edit overwriting a newer server version | mitigate | Every edit is version-conditional; conflict keeps the server copy and parks the attempt (D-18) |
| T-01-12-02 | Tampering | provisional client rate persisted as truth | mitigate | Provisional values live only in the local cache; insert payload carries no rate columns; the server stamp replaces them (D-16, D-17) |
| T-01-12-03 | Repudiation | silently lost entry | mitigate | Permanent failures roll back visibly and are recorded in the encrypted failed list (D-19) |
| T-01-12-04 | Information Disclosure | queued writes at rest | mitigate | Paused mutations persist inside the LargeSecureStore-encrypted cache (01-07) |
</threat_model>
