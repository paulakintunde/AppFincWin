`export function FabQuickMenu(): React.JSX.Element` — `const { quickMenuOpen, closeQuickMenu, quickActions } = useFab(); const pending = useRef<(() => void) | null>(null);`
```tsx
<SheetContainer visible={quickMenuOpen} riseDuration={DURATION.entrance} accessibilityLabel={t('shell.quick.title')}
  onDismiss={() => { closeQuickMenu(); const run = pending.current; pending.current = null; run?.(); }}>
  <Text accessibilityRole="header" style={{ fontFamily: fonts.body[600], fontSize: fontSize.sheetTitle, letterSpacing: fontSize.sheetTitle * -0.01, color: colors.ink, marginBottom: space.gapSm }}>{t('shell.quick.title')}</Text>
  {quickActions.map((a) => (
    <Pressable key={a.id} accessibilityRole="button" accessibilityLabel={a.label} onPress={() => { pending.current = a.run; closeQuickMenu(); }}
      style={{ minHeight: space.touchMin, paddingVertical: space.rowPad, justifyContent: 'center' }}>
      <Text style={{ ...textRole(pairing, 'body'), color: colors.ink }}>{a.label}</Text>
    </Pressable>
  ))}
</SheetContainer>
```
Running the action after dismissal means an entry sheet never opens underneath a closing menu.
