Create `src/shell/backHistory/BackHistoryProvider.tsx` (header: "D-05/D-06/D-07/D-08: observes Expo Router's navigation state and keeps the one app-wide 8-deep history. It is the ONLY writer: every change — tab tap, push, native swipe pop, re-tap pop-to-root, or our own goBack — is recorded by observing the resulting state, never by the caller. goBack only navigates and marks the next observed change as a back step (pendingBack)."):
```ts
export interface BackHistoryContextValue {
  history: readonly Location[];
  current: Location | null;
  canGoBack: boolean;               // history.length > 0 (prototype canBack, html 4880)
  goBack(): boolean;                // false only when the system should exit (D-06 step 4)
  registerTabSwitcher(fn: ((tab: TabId) => void) | null): void; // the TabBar registers navigation.navigate({ name, merge: true })
}
export const BackHistoryContext = createContext<BackHistoryContextValue | null>(null);
export function BackHistoryProvider({ children }: { children: React.ReactNode }): React.JSX.Element;
export function useBackHistory(): BackHistoryContextValue;
```
Implementation: `const navState = useRootNavigationState(); const pathname = usePathname(); const current = useMemo(() => locationFromNavState(navState as unknown as NavStateLike, pathname), [navState, pathname]);` State `history` (useState<Location[]>), refs `historyRef`, `currentRef`, `prevRef`, `pendingBackRef`, `switcherRef` (kept in sync each render). Effect on `current`: if null return; if prevRef.current && sameLocation(prevRef.current, current) return; `setHistory(h => applyTransition(h, prevRef.current, current, pendingBackRef.current))`; then `pendingBackRef.current = false; prevRef.current = current`.
`goBack` (useCallback, stable): local `h = historyRef.current`; loop at most MAX_HISTORY + 1 times over `decideBack(currentRef.current, h, HOME_TAB)`: 'discardEntry' -> `h = h.slice(0, -1)` and continue; 'stackBack' -> commit h, if `!router.canGoBack()` return false, set pendingBackRef true, `router.back()`, return true; 'switchTab' -> commit h, pendingBackRef true, `switcherRef.current ? switcherRef.current(action.tab as TabId) : router.navigate(('/' + action.tab) as Href)`, return true; 'exit' -> commit h, return false. `commit(h)` calls setHistory(h) only if h !== historyRef.current. Value wrapped in useMemo. Tests per <behavior> with `jest.mock('expo-router', ...)` and `renderHook` + `rerender`; build fixtures with small helpers `tabState(tab, depth)` / `outerState(depth)` returning `{ routes: [{ name: '(app)', state: {...} }] }`.
