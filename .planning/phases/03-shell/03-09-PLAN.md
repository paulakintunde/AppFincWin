Create `src/shell/sheet/SheetContainer.tsx` (header: "NAV-04 / D-12 / D-13 / D-18 / D-20 / D-21. One container for every short task (entry add/edit, settle up, cap, filter, Pro gate, quick menu). Drag-to-dismiss uses the library's pan-down; the unsaved-changes guard follows the dismiss-then-restore pattern (03-RESEARCH Pitfall 5): the modal is kept mounted on close (enableDismissOnClose={false}) so that when a dirty sheet reaches index -1 by gesture we snap it back to index 0 with its content state intact and show the dialog, rather than intercepting the gesture mid-flight.
```ts
export interface SheetContainerProps {
  visible: boolean;
  onDismiss(): void;              // called once after the sheet has fully closed, by any path
  accessibilityLabel: string;     // the sheet's title, announced on open (D-20)
  dirty?: boolean;                // D-13: true while the content has unsaved changes
  riseDuration?: number;          // fw-up duration; default DURATION.tabSlide (260ms); the FAB quick menu passes DURATION.entrance (220ms, UI-SPEC Animations)
  children: React.ReactNode;
}
export function SheetContainer(props: SheetContainerProps): React.JSX.Element;
```
Implementation:
- `ref = useRef<BottomSheetModal>(null)`, `closingRef = useRef<'programmatic' | null>(null)`, `dirtyRef` synced from props, `[confirming, setConfirming] = useState(false)`, `idRef = useRef(uniqueId)` (e.g. a module counter).
- `close()` = `closingRef.current = 'programmatic'; setConfirming(false); ref.current?.dismiss();`
- `requestDismiss()` = `dirtyRef.current ? setConfirming(true) : close()`.
- Effect on `visible`: true -> `closingRef.current = null; ref.current?.present(); const unregister = register({ id, requestDismiss }); AccessibilityInfo.announceForAccessibility(accessibilityLabel); return unregister`-style (keep the unregister in a ref so onDismiss can call it too; unregister is idempotent); false -> `if presented: close()`.
- `onChange(index)`: `if (index === -1 && closingRef.current !== 'programmatic') { if (dirtyRef.current) { ref.current?.snapToIndex(0); setConfirming(true); } else { closingRef.current = 'programmatic'; hapticSheetDragClose(); ref.current?.dismiss(); } }`.
- `onDismiss` (library): unregister; `closingRef.current = null; setConfirming(false); props.onDismiss()`.
- Render:
```tsx
<BottomSheetModal ref={ref} enablePanDownToClose enableDismissOnClose={false} onChange={onChange} onDismiss={handleDismiss}
  animationConfigs={useBottomSheetTimingConfigs({ duration: riseDuration ?? DURATION.tabSlide, easing: EASING })}
  backdropComponent={(p) => <BottomSheetBackdrop {...p} appearsOnIndex={0} disappearsOnIndex={-1} opacity={0.4} pressBehavior="none" onPress={requestDismiss} style={[p.style, { backgroundColor: colors.ink }]} />}
  backgroundStyle={{ backgroundColor: colors.surface, borderTopLeftRadius: radii.sheetTop, borderTopRightRadius: radii.sheetTop }}
  handleIndicatorStyle={{ backgroundColor: colors.line2, width: size.sheetHandleW, height: size.sheetHandleH, borderRadius: radii.pill }}
  keyboardBehavior="interactive" android_keyboardInputMode="adjustResize" accessibilityLabel={accessibilityLabel}>
  <BottomSheetView accessibilityViewIsModal style={{ paddingHorizontal: space.sheetCornerPad, paddingBottom: space.sheetPadBottom + insets.bottom }}>
    {children}
    {confirming ? <DiscardChangesDialog onDiscard={close} onKeepEditing={() => setConfirming(false)} /> : null}
  </BottomSheetView>
</BottomSheetModal>
```
