<objective>
Build the tab bar: the five bespoke glyphs, the custom `tabBar` component (availability, selection colours, capped labels, accessibility, re-tap, blur, height reporting, back-step switcher registration), and the shell-driven directional slide (`tabSlide` store + `TabSlideIn` screen-layout wrapper).

Revised 2026-10-13: D-05 now requires every back step to slide in reverse, which the JS Tabs `sceneStyleInterpolator` (progress -1/0/1 by index) cannot express, so the old `tabTransition.ts` is replaced by a small store that remembers the last focused tab and whether the next change is a back step; each tab root animates itself on focus. Tabs are imported from `expo-router/js-tabs` (the `expo-router` export is deprecated in 57.0.22). D-22 removes tab stacks, so a re-tap only scrolls to top.
</objective>
