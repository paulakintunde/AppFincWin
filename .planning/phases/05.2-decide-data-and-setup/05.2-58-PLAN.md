<objective>
Allow Stopped / Paused from a series' first day (F-13).

Root cause: Stopped from date F writes end_date = F - 1 (seriesStatusPatch). For F = anchor_date that is the day before the start, which both the client rule (`addDays(from, -1) < row.anchor_date` -> 'tooEarly') and the table check `recurring_series_end_after_anchor (end_date is null or end_date >= anchor_date)` (20260926000300) refuse. Fixing only the client would make the write fail on the server, so the check is widened by exactly one day in a new migration.
Output: migration 20261028001400 + pgTAP 73, the client rule, tests. No production push here (05.2-59).
</objective>
