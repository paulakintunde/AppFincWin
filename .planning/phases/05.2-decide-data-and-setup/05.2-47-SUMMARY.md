# Phase 05.2 Plan 47: Stopped or paused on the setup steps Summary

The Regular payments, Pay and Other income steps now show a "Stopped or paused" link on every saved series and list paused bills and paused income read-only under "Paused" with "Paused since {date}", so Resume (05.2-44 in-place branch) is reachable for both.

## What was built

- `SeriesStatusLink` and `PausedSeriesList` in `income/steps/shared.tsx`: gated by `useDecideAccess().v3`, call `openSeriesStatus` only (nothing written), theme tokens, existing `record.seriesStatus.*` copy, date made non-breaking, a11y labels `{name}, Stopped or paused` / `a11yStatus`.
- `useRegularCandidates`: now returns `paused` (non-deleted expense series, status paused); a payee whose only series is paused is not offered again as a candidate; "Regular" now requires a live series.
- `RegularStep`: link on Regular-state rows only; Paused section before the add link.
- `PayStep` / `OtherStep`: link on each saved card; Paused list after the live cards; `save()` unaffected by paused series.
- `seriesHelpers`: `liveSeriesOfKind`, `pausedIncomeSeries`.

## Deviations from Plan

**1. The steps now use new `liveSeriesOfKind` (status live) and the Regular hook matches live series only, which is what the plan's "stopped is not listed (unchanged)" requires. `seriesOfKind` itself is unchanged (used by settings and setup facts).

**2. [Rule 3 - Blocking] Test mocks.** `shared.tsx` now imports `useDecideAccess`, which loads the Supabase client and env check at module load, so 12 existing suites that import the income shared module (setup steps and income) mock `useDecideAccess` (same pattern as 05.2-44). The plan's fallback (taking `v3` from props) was not needed: depcruise has no rule against features/income importing features/decide.

**3. Placement.** The link and list are shared components in `income/steps/shared.tsx` (already imported by RegularStep) rather than copied into each step. The Paused list in Other is limited to the Other income kinds (not salary).

**4. Task commits.** Because both tasks share `shared.tsx`, the shared components and the mock edits are in the Task 1 commit.
