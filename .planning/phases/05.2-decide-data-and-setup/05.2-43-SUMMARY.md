# Phase 05.2 Plan 43: Loan and card sheet Summary

Loans "Edit" and "Add a loan or card" now open a real sheet (add, edit, Paid off), each save a queued, offline-safe write with one Undo, replacing the "editor unavailable" toast.

## Commits

- bf1a7e8b: add, edit and paid-off debt mutations with Undo
- 452f10e5: loan and card sheet (DebtSheet, debtSheetHost store) with add, edit and Paid off
- 0c2962fa: register editDebt and addDebt in the setup host, mount DebtSheetHost in SetupRoute

## What was built

- `useAddDebt`, `useEditDebt`, `useSetDebtPaidOff` in `src/data/mutations/debts.ts`, registered in `registerDebtMutations` (scope WRITE_SCOPE, retry shouldRetryWrite). Add copies the addPot insert-with-undo pattern (duplicate id read back, inverse soft-deletes). Edit and paid-off share one version-conditional patch default; conflict parks a failed write with field names only.
- Validation before mutate: name 1-80, minor units safe integers 0..10^13, apr null or 0-100 with at most 2 decimals; edit refuses empty patch, keys outside the five editable ones (including paid_off_on), and pays_in_full on non-cards; paid off refuses a future date, a malformed date, and an already-paid-off debt.
- `DebtSheet.tsx`: name, balance, rate (decimal pad), minimum, card pays-in-full chips; edit saves only changed fields; add prefills the kind label and maps kinds (card -> card; car, student, personal, mortgage -> loan; bnpl, other -> other; secured for car and mortgage). Paid off: secondary pill, date row (default today), body line, own Save, future date disabled; already-paid-off debts show "Paid off {date}" (non-breaking date). Gated on `useDecideAccess().v3`.
- Host: `editDebt` / `addDebt` call `openDebtSheet`; `DebtSheetHost` mounted in `SetupRoute`.

## Deviations from Plan

3. The rate field is a local TextInput styled like `Box` (the shared Box has no decimal keyboard), rather than editing shared stepUi.
