## Task 1: cause of the order dependence
Leaked state was not a store or mock. The tests called `fireEvent.press(...)` without `await`. With this RNTL version `fireEvent` is async, so the "+ Link a refund" test left an overlapping `act()` scope open ("overlapping act() calls" console error). Every test that ran after it then timed out on `findByText`/`getByText`. In file order that test was last, which hid the problem. Fix, all in the test file: await every `fireEvent.press`, and an async `afterEach` that unmounts inside `act` and calls `jest.clearAllMocks()`. No production file changed.
