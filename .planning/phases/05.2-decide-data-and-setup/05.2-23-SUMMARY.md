2. **[Plan 22 follow-up] PrefillTile replaced.** `PayStep` now uses `PrefillNote` (identical look) and the local `PrefillTile.tsx` is removed. Income tests still pass.
3. **Copy key names.** Plan wording named `savedToast`; the shipped en.ts keys are `toastSaved` / `toastLater`, used as is.
4. **Reanimated, not Animated.** The rise and rail fill use react-native-reanimated (the project's animation library); RN `Animated` produced act warnings in tests.
5. **Back from the first step of standalone mode** closes with `notNow` (there is no Welcome in standalone).
6. **`setup_done_at` is written when Done is pressed on Summary** (full mode, only if still null), silently with no toast. Finish later does not write it.
7. **Welcome header** shows no section name; the title is drawn in the body as `display`.
8. `meta` text role does not exist in the theme; the reason line uses the label role at `fontSize.meta` (12.5).
