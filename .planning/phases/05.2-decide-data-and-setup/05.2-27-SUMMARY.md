# Phase 05.2 Plan 27: Emergency fund step and sheet Summary

The emergency fund step and sheet share one body. The fund is an amount, or an account (the amount follows its balance), or not set with an optional goal. Picking an account whose use is not already "kept for the emergency fund" or "a mix" asks once, inline, whether it also holds money you spend. A preview line shows the result before saving.

## Behaviour
- `useEmergencyFundForm(variant)` holds the draft, computes `linkUse` with `emergencyLinkUse`, and saves or removes through plan 14's `useSaveEmergencyFund`. One save call; nothing changed returns null.
- Step: Yes / Not yet ChoiceCards (solid dark when selected); the amount field or "Or pick the account that holds it" (a stacked Sheet radio list with balances); read-only "follows this account" amount; goal field with the three-month hint (3 x (regular payments + everyday) from `evaluation.month`, hidden when unknown); shield info tile. The step pre-fills an account already kept for the fund, with the prefill note.
- Sheet: three ChoiceCards, Save emergency fund, Remove emergency fund (no confirm). Toasts "Emergency fund saved", "... {Account} is now kept for it." (only when the use changed), "Emergency fund removed. Nothing moved in the bank." each with Undo. Used line is prop-driven and draws nothing without it.

## Deviations from Plan
1. [Copy] Added `decide.setup.emergency.noAccount` ("No account, just an amount") so a user can step back from an account to an amount in the picker. No other copy was added.
2. [Design call] The Yes/No spend question starts on No, so the preview line is always visible and Next never waits on it. The preview and toast name the account (T-05.2-27-01).
3. [Limitation] With an account chosen, the stored `reserve` is the account's balance at save time (the engine reads `reserve` as an amount). It is not re-synced when the balance later changes; the UI shows the live balance. A live follow needs an engine or snapshot change.
4. [Limitation] The shield glyph is hand-drawn with react-native-svg (no shield glyph existed).
5. Not registered in the step table or sheet host; the shell and Settings wiring are outside this plan. Nothing needed from `setupSheetHost`.
