# Phase 05.2 Plan 35: Test-account setup page and engine readout Summary

Switch-on accounts now see a setup status card, a three-row card (Decide settings, Unspent money, Emergency fund) and a plain readout of what the engine receives on the Decide tab; everyone else still sees Coming soon.

## What was built

- `readoutRows(inputs, evaluation, answers, fmt)`: accounts counted, income profile, pattern / expected income, typical month, unspent, emergency fund, envelopes, held back, refunds linked, pay arrivals, next question. Rows with nothing to say are omitted. "Next question" is the first setup question in the engine's own D-59 order, shown as its existing `decide.v3.missing.*` copy with placeholders filled from the engine notices. Codes about one purchase (no price, plan terms and so on) are ignored.
- Status card: not started, rough (chip, steps left by name, Finish setup opening at the first), done (success check, Change an answer).
- Readout card: fill1, selectable text, inkMuted labels and ink values, stacks via the shared D-76 rule S.
- Page: busy skeleton while loading, shipped "Your figures didn’t load" / "Try again" on error, cached data offline.
- `decide.tsx`: `DECIDE_OPEN ? home : access.v3 ? setup page : coming soon`; `__DEV__` shadow block unchanged; `DECIDE_V3` not named; `DECIDE_OPEN` still false.
