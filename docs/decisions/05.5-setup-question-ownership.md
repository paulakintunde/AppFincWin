## The rule

A setup question is asked in one form and saved in one place. Where Decide needs the answer, it either reads the saved value or opens the home form (inside its own setup frame, or as a sheet). It never keeps a second copy.

Store names are read from `src/db/*` and `supabase/migrations/*` as of base commit 8865ffa7, plus the six Decide setup items and their answered flags that 06.1 adds (`feat/06.1-decide-screens`, PR #102).
