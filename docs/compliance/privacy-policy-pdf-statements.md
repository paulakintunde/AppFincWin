# PDF statements — paragraph for fincwin.com/privacy (draft, awaiting owner review)

When you import a PDF bank or card statement, the file is sent over an encrypted connection to our server, operated by Supabase in the United States (AWS us-west-2), where it is read and then deleted straight after — usually within seconds. If an upload is interrupted, the file is deleted automatically within two hours. We keep no copy of the file and nothing from it except the transactions you choose to import. If the PDF has a password, it is used once to open the file and is never stored. CSV and OFX statement files are read on your phone and never leave it.

- The upload notice, key `importCsv.pdf.consent`.
