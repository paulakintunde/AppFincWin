# 05.5 tester note

This is version 0.2.0. Install it as a new APK; it does not arrive as an automatic update.

What you will notice:
- Home has a new small line under the big figure: what is left after the month's plans.
- A category limit set in Decide is now the same limit you see in Activity.
- The Decide setup forms are shared with Activity, so a bill or pay you add in one shows in the other.
- Some Decide answers may move slightly. Each move was reviewed.

If Decide misbehaves, tell us; there is no switch back to the old Decide.
