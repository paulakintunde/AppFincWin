# Statement PDF fixtures

Every file in this folder is synthetic. They are generated by `npm run fixtures:pdf` from fictional ledgers in `scripts/fixtures/make-statement-pdfs.mjs`, using the zero-dependency writer in `scripts/fixtures/pdf-writer.mjs`.

- "Example Bank", "ALEX SAMPLE", the address, the sort code, the account numbers and every payee are fictional.
- No real institution's statement, branding or layout was copied (Phase 2.1 RESEARCH Pitfall 5). There is no logo and no drawn mark.
- Licence: authored by this project, same licence as the repository.

Matching expected ledgers (dates, stored-sign amounts, balances, uncertain-row flags, reconciliation outcome) are written by the same generator to `src/engine/statement/pdf/__tests__/fixtures/*.expected.json`.

| File | Purpose |
|------|---------|
| `current-account.pdf` | Running balance, overdraft ("OD"), wrapped description, undated row, off-centre amount resolved by balance change |
| `savings.pdf` | Signed amounts, no running balance, opening and closing in the top block |
| `credit-card.pdf` | CR payments, foreign-currency purchase with its fee line, stated limit |
| `year-end.pdf` | Statement spanning 31 December to 1 January, dates with no year |
| `no-balances.pdf` | No balances anywhere, one genuinely ambiguous column |
| `multi-account.pdf` | Two accounts in one file |
| `scanned.pdf` | No text layer |
| `encrypted.pdf` | Password protected; the user password is `fincwin-test` (a test value, not a secret) |
| `too-many-pages.pdf` | 26 pages, one over the page limit |

The `_fixtures` prefix keeps this folder out of Supabase function deploys.

## Worst-case file

The 25-page file just under the 10 MB cap is never committed. Generate it on demand into a scratch directory:

```
node scripts/fixtures/make-statement-pdfs.mjs --worst-case <scratch dir>
```

Run `deno run --allow-read --node-modules-dir=none supabase/functions/_fixtures/tools/smoke-statement-pdfs.ts` to check the committed fixtures parse with the same pdf.js build the Edge Function uses.
